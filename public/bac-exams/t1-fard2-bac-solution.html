التمرين الأول (5 نقاط) — دراسة شاملة لدالة

السؤال 1) 0.75 نقطة

النهايات:
- $f(x) = (x^2 - 2x + 1)(x + 2) = x^3 + 2x^2 - 2x^2 - 4x + x + 2 = x^3 - 3x + 2$
- $\lim_{+\infty} f = +\infty$, $\lim_{-\infty} f = -\infty$

السؤال 2) 1.5 نقطة

الاشتقاق:
$$f'(x) = 2(x - 1)(x + 2) + (x - 1)^2 = (x - 1)[2(x + 2) + (x - 1)] = (x - 1)(3x + 3) = 3(x - 1)(x + 1)$$

إشارة $f'$:
- $f'(x) = 0 \iff x = 1$ أو $x = -1$
- $f' > 0$ على $(-\infty, -1) \cup (1, +\infty)$
- $f' < 0$ على $(-1, 1)$

جدول التغيّرات:

| $x$ | $-\infty$ | $-1$ | $1$ | $+\infty$ |
|---|---|---|---|---|
| $f'$ | $+$ | $0$ | $0$ | $+$ |
| | $\nearrow$ | $\searrow$ | $\nearrow$ | |

- $f(-1) = 4 \cdot 1 = 4$ (عظمى)
- $f(1) = 0 \cdot 3 = 0$ (صغرى)

السؤال 3) 1.25 نقطة

حل المعادلة:
$$f(x) = (x - 1)^2 (x + 2) = 0 \iff x = 1 \text{ (جذر مزدوج)} \text{ أو } x = -2$$

إشارة $f$:
- $(x - 1)^2 \geq 0$ دائمًا
- $\text{sgn}(f) = \text{sgn}(x + 2)$
- $f(x) > 0$ على $(-2, +\infty) \setminus \{1\}$
- $f(x) < 0$ على $(-\infty, -2)$
- $f(x) = 0$ عند $x = -2, 1$

السؤال 4) 0.75 نقطة

الحساب:
- $f(0) = 1 \cdot 2 = 2$ ✓ ($A$ على المنحنى)
- $f'(0) = 3(0 - 1)(0 + 1) = -3$

المماس: $y = -3x + 2$.

السؤال 5) 0.75 نقطة

عناصر الرسم:
- النقاط: $(-2, 0)$, $(-1, 4)$, $(1, 0)$, $(0, 2)$
- المنحنى يمر من $-\infty$, يرتفع إلى $(-1, 4)$ (عظمى)
- ينخفض إلى $(1, 0)$ (صغرى), يلامس المحور السيني عند $x = 1$
- يرتفع نحو $+\infty$

الشكل: منحنى مع نقطة عظمى ثم صغرى (تلامس).

التمرين الثاني (5 نقاط) — متتالية عودية + مساعدة

السؤال 1) 0.75 نقطة

الحسابات:
- $u_1 = \frac{2 + 1}{2} = \frac{3}{2}$
- $u_2 = \frac{3/2 + 1}{2} = \frac{5/2}{2} = \frac{5}{4}$
- $u_3 = \frac{5/4 + 1}{2} = \frac{9/4}{2} = \frac{9}{8}$

السؤال 2) 1 نقطة

التهيئة ($n = 0$): $u_0 = 2 \in (1, 2]$ ✓

الفرضية: نفرض $1 < u_n \leq 2$.

النتيجة: $u_{n+1} = \frac{u_n + 1}{2}$
- من $u_n > 1$: $u_n + 1 > 2$, إذن $u_{n+1} > 1$ ✓
- من $u_n \leq 2$: $u_n + 1 \leq 3$, إذن $u_{n+1} \leq 3/2 \leq 2$ ✓

إذن $1 < u_{n+1} \leq 2$ ✓

الخلاصة: بالتراجع, $1 < u_n \leq 2$ لكل $n$.

السؤال 3) 1 نقطة

الحساب:
$$u_{n+1} - u_n = \frac{u_n + 1}{2} - u_n = \frac{1 - u_n}{2}$$

بما أن $u_n > 1$ (من السؤال 2): $1 - u_n < 0$, إذن $u_{n+1} - u_n < 0$.

$(u_n)$ متناقصة.

التقارب:
- متناقصة + محدودة سفلًا بـ 1
- إذن متقاربة (نظرية الرتابة المحدودة)

السؤال 4) 1 نقطة

الحساب:
$$v_{n+1} = u_{n+1} - 1 = \frac{u_n + 1}{2} - 1 = \frac{u_n - 1}{2} = \frac{v_n}{2}$$

إذن $(v_n)$ متتالية هندسية أساسها $q = \frac{1}{2}$.

- حدّها الأول: $v_0 = u_0 - 1 = 1$

السؤال 5) 1.25 نقطة

الصيغ الصريحة:
- $v_n = v_0 \cdot q^n = 1 \cdot \left(\frac{1}{2}\right)^n = \frac{1}{2^n}$
- $u_n = v_n + 1 = 1 + \frac{1}{2^n}$

النهاية:
- $\lim \frac{1}{2^n} = 0$ (لأن $|1/2| < 1$)
- إذن $\lim u_n = 1$ ✓

التمرين الثالث (5 نقاط) — الاستمرارية + مبرهنة القيم الوسيطة

السؤال 1) 2 نقطة

أ) الاتصال عند 1:
$$\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = \lim_{x \to 1} (x + 1) = 2$$

للاتصال: $g(1) = a = 2$, إذن $\boxed{a = 2}$.

ب) القابلية للاشتقاق:
$$\lim_{x \to 1} \frac{g(x) - g(1)}{x - 1} = \lim_{x \to 1} \frac{\frac{x^2 - 1}{x - 1} - 2}{x - 1} = \lim \frac{(x^2 - 1) - 2(x - 1)}{(x - 1)^2} = \lim \frac{x^2 - 2x + 1}{(x - 1)^2} = \lim \frac{(x-1)^2}{(x-1)^2} = 1$$

إذن $g'(1) = 1$ (موجودة), $g$ قابلة للاشتقاق عند $1$ ✓.

السؤال 2) 1.5 نقطة

التطبيق:
- $h$ متصلة على $[0, 1]$ (دالة كثيرية الحدود)
- $h(0) = 0 - 0 + 1 = 1 > 0$
- $h(1) = 1 - 3 + 1 = -1 < 0$
- $0 \in [h(1), h(0)] = [-1, 1]$

حسب مبرهنة القيم الوسيطة (IVT), يوجد $c \in [0, 1]$ بحيث $h(c) = 0$ ✓.

ملاحظة: الحل $c \approx 0.347$ (يحسب بالتنصيف).

السؤال 3) 1.5 نقطة

الدراسة:
- $f(x) = x^5 - 3x + 1$
- $f'(x) = 5x^4 - 3$
- $f'(x) = 0 \iff x^4 = 3/5 \iff x = \pm (3/5)^{1/4}$
- النقاط الحرجة: $x_1 = -0,880$ و $x_2 = 0,880$ (تقريبًا)

قيم $f$ عند النقاط الحرجة:
- $f(-\infty) = -\infty$, $f(+\infty) = +\infty$
- $f(x_1) \approx -1,46 + 2,64 + 1 = 2,18 > 0$ (عظمى محلية)
- $f(x_2) \approx 0,55 - 2,64 + 1 = -1,09 < 0$ (صغرى محلية)

التطبيق:
- على $(-\infty, x_1)$: $f$ تزايد من $-\infty$ إلى $2,18$ → حل وحيد $\alpha_1 < x_1$
- على $(x_1, x_2)$: $f$ تناقص من $2,18$ إلى $-1,09$ → حل وحيد $\alpha_2 \in (x_1, x_2)$
- على $(x_2, +\infty)$: $f$ تزايد من $-1,09$ إلى $+\infty$ → حل وحيد $\alpha_3 > x_2$

إذن المعادلة يقبل 3 حلول ✓.

التمرين الرابع (5 نقاط) — مبرهنة رول + لاغرنج

السؤال 1) 1.5 نقطة

شروط رول:
1. $f$ متصلة على $[-2, 2]$ ✓ (دالة كثيرية الحدود)
2. $f$ قابلة للاشتقاق على $(-2, 2)$ ✓
3. $f(-2) = 0 = f(2)$ ✓

إذن يوجد $c \in (-2, 2)$ بحيث $f'(c) = 0$.

العثور على $c$:
$f'(x) = 2x$, $f'(c) = 0 \iff c = 0$ ✓ ($c = 0 \in (-2, 2)$)

السؤال 2) 1.5 نقطة

شروط لاغرنج:
1. $g$ متصلة على $[1, e]$ ✓
2. $g$ قابلة للاشتقاق على $(1, e)$ ✓

التطبيق:
$$\frac{g(e) - g(1)}{e - 1} = g'(c)$$
$$\frac{\ln e - \ln 1}{e - 1} = \frac{1}{c}$$
$$\frac{1 - 0}{e - 1} = \frac{1}{c}$$
$$c = e - 1 \approx 1,718 \in (1, e)$$ ✓

السؤال 3) 2 نقطة

الفكرة: نطبّق لاغرنج على $f(t) = \ln(t + 1)$ على $[0, x]$.

- $f$ متصلة على $[0, x]$ و قابلة للاشتقاق على $(0, x)$
- $f'(t) = \frac{1}{t + 1}$

حسب لاغرنج: يوجد $c \in (0, x)$ بحيث:
$$\frac{f(x) - f(0)}{x - 0} = f'(c) = \frac{1}{c + 1}$$
$$\frac{\ln(x + 1) - 0}{x} = \frac{1}{c + 1}$$
$$\ln(x + 1) = \frac{x}{c + 1}$$

الترتيب:
- $0 < c < x \Rightarrow 1 < c + 1 < x + 1$
- $\frac{1}{x + 1} < \frac{1}{c + 1} < 1$
- $\frac{x}{x + 1} < \frac{x}{c + 1} < x$
- $\frac{x}{x + 1} < \ln(x + 1) < x$ ✓
