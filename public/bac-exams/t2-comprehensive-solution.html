التمرين الأول (5 نقاط) — دراسة دالة أسية + تكامل بالتجزئة + مبرهنة

السؤال 1) 1 نقطة

عند $+\infty$:
- $\lim (x + 1) = +\infty$, $\lim e^{-x} = 0$
- المنتج: $\frac{x+1}{e^x} \to 0$ (الأسية تتفوق على القوة)
- $\lim f = 0$

عند $-\infty$:
- $\lim (x + 1) = -\infty$, $\lim e^{-x} = +\infty$
- المنتج: $-\infty \cdot +\infty = -\infty$
- $\lim f = -\infty$

تفسير هندسي: $y = 0$ مقارب أفقي عند $+\infty$.

السؤال 2) 1.25 نقطة

الاشتقاق:
$$f'(x) = e^{-x} - (x + 1) e^{-x} = (1 - x - 1) e^{-x} = -x \cdot e^{-x}$$

الإشارة:
- $e^{-x} > 0$ دائمًا
- $\text{sgn}(f') = \text{sgn}(-x)$
- $f' > 0$ على $(-\infty, 0)$, $f' < 0$ على $(0, +\infty)$

جدول التغيّرات:

| $x$ | $-\infty$ | | $0$ | | $+\infty$ |
|---|---|---|---|---|---|
| $f'$ | | $+$ | $0$ | $-$ | |
| $f$ | $-\infty$ | $\nearrow$ | $1$ | $\searrow$ | $0$ |

القيمة العظمى: $f(0) = 1$.

السؤال 3) 0.75 نقطة

الحساب:
- $f(1) = 2 \cdot e^{-1} = 2/e$
- $f'(1) = -1 \cdot e^{-1} = -1/e$

المماس: $y = -\frac{1}{e}(x - 1) + \frac{2}{e} = -\frac{x}{e} + \frac{3}{e} = \frac{-x + 3}{e}$.

السؤال 4) 1.5 نقطة

التجزئة: $u = x + 1$, $v' = e^{-x}$
- $u' = 1$, $v = -e^{-x}$

$$I = [-(x+1) e^{-x}]_0^1 + \int_0^1 e^{-x}\, dx$$
$$= (-2e^{-1} - (-1)) + [-e^{-x}]_0^1$$
$$= 1 - \frac{2}{e} + (-e^{-1} + 1) = 2 - \frac{3}{e}$$

النتيجة: $I = 2 - \frac{3}{e} \approx 0,896$.

السؤال 5) 0.5 نقطة

الفكرة: $\int (x + 1) e^{-x}\, dx = \int x e^{-x}\, dx + \int e^{-x}\, dx$

إذن:
$$\int_0^1 x e^{-x}\, dx = I - \int_0^1 e^{-x}\, dx$$

$$= \left(2 - \frac{3}{e}\right) - \left(1 - \frac{1}{e}\right) = 1 - \frac{2}{e}$$

النتيجة: $\int_0^1 x e^{-x}\, dx = 1 - \frac{2}{e}$.

التمرين الثاني (5 نقاط) — معادلات أسية و لوغاريتمية + نهايات

السؤال 1) 2 نقطة

أ) نضع $X = e^x$ ($X > 0$): $X^2 - 5X + 6 = 0 \Rightarrow (X-2)(X-3) = 0 \Rightarrow X = 2$ أو $3$.
- الحلول: $x = \ln 2$ أو $x = \ln 3$

ب) شروط: $x > 2$.
- $\ln[(x+1)(x-2)] = \ln 6 \iff (x+1)(x-2) = 6$
- $x^2 - x - 2 = 6 \iff x^2 - x - 8 = 0$
- $\Delta = 1 + 32 = 33$, $x = \frac{1 \pm \sqrt{33}}{2}$
- نختار $x > 2$: $x = \frac{1 + \sqrt{33}}{2} \approx 3,37$

ج) نضع $Y = \ln x$: $Y^2 - 4Y + 3 = 0 \Rightarrow (Y-1)(Y-3) = 0 \Rightarrow Y = 1$ أو $3$.
- الحلول: $x = e$ أو $x = e^3$

د) نضع $X = e^x$ ($X > 0$): $X + 1/X = 3 \iff X^2 - 3X + 1 = 0$
- $X = \frac{3 \pm \sqrt{5}}{2}$ (كلاهما موجب)
- الحلول: $x_1 = \ln\frac{3+\sqrt{5}}{2}$, $x_2 = \ln\frac{3-\sqrt{5}}{2}$

السؤال 2) 1.5 نقطة

أ) الأسية تتفوق على القوة: $\lim \frac{e^x}{x^2} = +\infty$.

ب) القوة تتفوق على اللوغاريتم: $\lim \frac{\ln x}{x} = 0$.

ج) شهيرة: $\lim_{x \to 0^+} x \ln x = 0$.

د) نكتب $\left(1 + \frac{2}{x}\right)^x = e^{x \ln(1 + 2/x)}$.
- $\ln(1 + 2/x) \sim 2/x$ قرب $+\infty$
- $x \ln(1 + 2/x) \sim x \cdot 2/x = 2$
- إذن $\lim = e^2$.

السؤال 3) 1.5 نقطة

أ) $\int_1^e \frac{1}{x}\, dx = [\ln x]_1^e = 1 - 0 = 1$

ب) نضع $u = \ln x$, $du = dx/x$:
- عند $x = 1$: $u = 0$; عند $x = e$: $u = 1$
- $\int_1^e \frac{\ln x}{x}\, dx = \int_0^1 u\, du = [u^2/2]_0^1 = 1/2$

ج) نضع $u = 1 + e^x$, $du = e^x\, dx$:
- عند $x = 0$: $u = 2$; عند $x = \ln 2$: $u = 3$
- $\int_0^{\ln 2} \frac{e^x}{1 + e^x}\, dx = \int_2^3 \frac{du}{u} = [\ln u]_2^3 = \ln 3 - \ln 2 = \ln(3/2)$

التمرين الثالث (5 نقاط) — أعداد مركبة + هندسة في المستوي المركب

السؤال 1) 1 نقطة

أ):
- $|z| = \sqrt{(\sqrt{3})^2 + 1^2} = \sqrt{3 + 1} = 2$
- $\arg(z) = \arctan\left(\frac{1}{\sqrt{3}}\right) = \frac{\pi}{6}$ (الربع الأول)

ب): $z = 2 e^{i\pi/6}$

السؤال 2) 1 نقطة

الشكل الأسي (صيغة موافري):
$$z^6 = 2^6 \cdot e^{i 6\pi/6} = 64 \cdot e^{i\pi} = -64$$

الشكل الجبري: $-64 + 0i = -64$.

السؤال 3) 1.5 نقطة

الصيغة الأسيّة: $-8i = 8 e^{-i\pi/2}$

نبحث عن $z = re^{i\theta}$ بحيث $z^3 = r^3 e^{3i\theta} = 8 e^{-i\pi/2}$.
- $r^3 = 8 \Rightarrow r = 2$
- $3\theta = -\pi/2 + 2k\pi \Rightarrow \theta = -\pi/6 + \frac{2k\pi}{3}$, $k \in \mathbb{Z}$

الحلول الثلاثة ($k = 0, 1, 2$):
- $k = 0$: $z_0 = 2 e^{-i\pi/6} = \sqrt{3} - i$
- $k = 1$: $z_1 = 2 e^{i(-\pi/6 + 2\pi/3)} = 2 e^{i\pi/2} = 2i$
- $k = 2$: $z_2 = 2 e^{i(-\pi/6 + 4\pi/3)} = 2 e^{i7\pi/6} = -\sqrt{3} - i$

التحقق: $z_0^3 = (\sqrt{3} - i)^3 = 2^3 e^{-i\pi/2} = -8i$ ✓

السؤال 4) 0.75 نقطة

أ):
- $A(\sqrt{3}; 1)$
- $OA = |z| = 2$

ب): $\widehat{(\vec{u}, \vec{OA})} = \arg(z) = \pi/6 \text{ rad} = 30°$.

السؤال 5) 0.75 نقطة

أ):
$$z^2 = (\sqrt{3} + i)^2 = 3 + 2i\sqrt{3} - 1 = 2 + 2i\sqrt{3}$$
$B(2; 2\sqrt{3})$

ب):
$$AB = |z^2 - z| = |z(z - 1)| = |z| \cdot |z - 1|$$
$$= 2 \cdot \sqrt{(\sqrt{3} - 1)^2 + 1} = 2\sqrt{3 - 2\sqrt{3} + 1 + 1} = 2\sqrt{5 - 2\sqrt{3}}$$

ج):
- $OA = |z| = 2$
- $OB = |z^2| = |z|^2 = 4$
- لكن $AB = 2\sqrt{5 - 2\sqrt{3}} \approx 2,09 \neq 2 \neq 4$

ملاحظة: المثلث $OAB$ ليس متساوي الأضلاع (النتيجة تحتاج مراجعة — لكن المنهجية صحيحة).

بالفعل: $OA = 2$, $OB = 4$, $AB \approx 2,09$. المثلث ليس متساوي الأضلاع.

التمرين الرابع (5 نقاط) — احتمالات + توزيع ذي الحدين + متغيرات عشوائية

السؤال 1) 1 نقطة

أ) جدول التوزيع:

| | $P$ | $\bar{P}$ | المجموع |
|---|:---:|:---:|:---:|
| $R$ | 8 | 10 | 18 |
| $\bar{R}$ | 7 | 5 | 12 |
| المجموع | 15 | 15 | 30 |

الحساب:
- $R \cap P$: 8
- $R \cap \bar{P}$: 18 - 8 = 10
- $\bar{R} \cap P$: 15 - 8 = 7
- $\bar{R} \cap \bar{P}$: 30 - 18 - 15 + 8 = 5

ب):
- $P(R) = 18/30 = 3/5$
- $P(P) = 15/30 = 1/2$
- $P(R \cap P) = 8/30 = 4/15$

السؤال 2) 1 نقطة

أ):
$$P(R \cup P) = P(R) + P(P) - P(R \cap P) = \frac{18}{30} + \frac{15}{30} - \frac{8}{30} = \frac{25}{30} = \frac{5}{6}$$

ب) الاستقلال:
- $P(R) \cdot P(P) = \frac{3}{5} \cdot \frac{1}{2} = \frac{3}{10} = 0.3$
- $P(R \cap P) = \frac{4}{15} \approx 0.267 \neq 0.3$

إذن $R$ و $P$ غير مستقلتين.

السؤال 3) 1 نقطة

أ):
$$P_R(P) = \frac{P(R \cap P)}{P(R)} = \frac{8/30}{18/30} = \frac{8}{18} = \frac{4}{9}$$

ب):
$$P_{\bar{P}}(R) = \frac{P(R \cap \bar{P})}{P(\bar{P})} = \frac{10/30}{15/30} = \frac{10}{15} = \frac{2}{3}$$

السؤال 4) 1.25 نقطة

أ) النوع: $X \sim \mathcal{B}(3, 0.6)$ (توزيع ذي الحدين, $n = 3$, $p = 18/30 = 0.6$).

ب):
- $P(X = 3) = (0.6)^3 = 0.216$
- $P(X = 0) = (0.4)^3 = 0.064$

ج):
- $E(X) = np = 3 \cdot 0.6 = 1.8$
- $V(X) = np(1-p) = 3 \cdot 0.6 \cdot 0.4 = 0.72$

السؤال 5) 0.75 نقطة

الحساب:
$$P(X \geq 2) = P(X = 2) + P(X = 3)$$

$$P(X = 2) = \binom{3}{2}(0.6)^2(0.4) = 3 \cdot 0.36 \cdot 0.4 = 0.432$$

$$P(X \geq 2) = 0.432 + 0.216 = 0.648$$

أي $64,8\%$.
