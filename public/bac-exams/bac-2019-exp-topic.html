الجزء الأول: المتتاليات العددية (13 نقطة)

السؤال 1) 0 نقطة

لتكن $(u_n)$ المتتالية المعرفة بـ $u_0 = 3$ و $u_{n+1} = \frac{1}{2}u_n + 1$ لكل $n \in \mathbb{N}$.

احسب $u_1, u_2, u_3$.

السؤال 2) 0 نقطة

لتكن $(v_n)$ المتتالية المعرفة بـ $v_n = u_n - 2$.

برهن أن $(v_n)$ متتالية هندسية، وحدد أساسها.

السؤال 3) 0 نقطة

اكتب $v_n$ ثم $u_n$ بدلالة $n$.

السؤال 4) 0 نقطة

احسب نهاية المتتالية $(u_n)$ عندما $n \to +\infty$.

السؤال 5) 0 نقطة

لتكن $S_n = v_0 + v_1 + \cdots + v_n$. احسب $S_n$ بدلالة $n$.

السؤال 1) 0 نقطة

احسب احتمال الحصول على:
(a) كرتين حمراء
(b) كرة حمراء ثم بيضاء

السؤال 2) 0 نقطة
