التمرين الأول (5 نقاط) — دراسة شاملة لدالة + مقارب مائل + مركز تناظر

السؤال 1) 1 نقطة

عند $2^+$: $\lim x^2 + 1 = 5$, $\lim (x - 2) = 0^+$, إذن $\lim f = +\infty$.

عند $2^-$: $\lim (x - 2) = 0^-$, إذن $\lim f = -\infty$.

عند $\pm\infty$:
- نحسب $\frac{f(x)}{x} = \frac{x^2 + 1}{x(x - 2)} = \frac{x^2 + 1}{x^2 - 2x} \to 1$ (نسبة الحدود الأعلى)
- إذن $f(x) - x = \frac{x^2 + 1 - x(x - 2)}{x - 2} = \frac{2x + 1}{x - 2} \to 2$
- إذن $(\Delta): y = x + 2$ مقارب مائل
- $\lim_{\pm\infty} f(x) = \pm\infty$

السؤال 2) 0.5 نقطة

المقاربات:
- $x = 2$ مقارب عمودي (نهايتان لا نهائيتان متعاكستان)
- $y = x + 2$ مقارب مائل عند $+\infty$ و $-\infty$

السؤال 3) 1.25 نقطة

الاشتقاق:
$$f'(x) = \frac{2x(x - 2) - (x^2 + 1)}{(x - 2)^2} = \frac{2x^2 - 4x - x^2 - 1}{(x - 2)^2} = \frac{x^2 - 4x - 1}{(x - 2)^2}$$

جذور البسط: $x^2 - 4x - 1 = 0 \Rightarrow x = 2 \pm \sqrt{5}$
- $\alpha_1 = 2 - \sqrt{5} \approx -0,24$
- $\alpha_2 = 2 + \sqrt{5} \approx 4,24$

إشارة $f'$: $(x-2)^2 > 0$ دائمًا, إذن إشارة $f'$ = إشارة $x^2 - 4x - 1$:
- موجبة على $(-\infty, \alpha_1) \cup (\alpha_2, +\infty)$
- سالبة على $(\alpha_1, 2) \cup (2, \alpha_2)$

جدول التغيّرات:
- $f$ تزايد على $(-\infty, \alpha_1]$, تناقص على $[\alpha_1, 2)$, تناقص على $(2, \alpha_2]$, تزايد على $[\alpha_2, +\infty)$
- عظمى محلية عند $\alpha_1$: $f(\alpha_1) \approx -1,24$
- صغرى محلية عند $\alpha_2$: $f(\alpha_2) \approx 8,24$

السؤال 4) 1 نقطة

الطريقة: نتحقق أنّ $\frac{f(2 + h) + f(2 - h)}{2} = 4$ لكل $h \neq 0$.

$$f(2 + h) = \frac{(2+h)^2 + 1}{h} = \frac{h^2 + 4h + 5}{h}$$
$$f(2 - h) = \frac{(2-h)^2 + 1}{-h} = \frac{h^2 - 4h + 5}{-h} = \frac{-h^2 + 4h - 5}{h}$$

$$f(2+h) + f(2-h) = \frac{h^2 + 4h + 5 - h^2 + 4h - 5}{h} = \frac{8h}{h} = 8$$

إذن $\frac{f(2+h) + f(2-h)}{2} = 4$ ✓

الخلاصة: $\Omega(2, 4)$ مركز تناظر.

السؤال 5) 1.25 نقطة

الحساب:
على $[3, 4]$: $f(x) - (x + 2) = \frac{2x + 1}{x - 2}$

بما أنّ $x \geq 3 > 2$, $\frac{2x + 1}{x - 2} > 0$, إذن $(\mathcal{C}_f)$ فوق $(\Delta)$ على $[3, 4]$.

$$\mathcal{S} = \int_3^4 \frac{2x + 1}{x - 2}\, dx$$

نحوّل: $\frac{2x + 1}{x - 2} = 2 + \frac{5}{x - 2}$ (قسمة مطوّلة)

$$\mathcal{S} = \int_3^4 \left(2 + \frac{5}{x - 2}\right)\, dx = [2x + 5 \ln|x - 2|]_3^4$$
$$= (8 + 5 \ln 2) - (6 + 5 \ln 1) = 2 + 5 \ln 2$$

النتيجة: $\mathcal{S} = 2 + 5 \ln 2 \approx 5,47 \text{ unit}^2$.

التمرين الثاني (5 نقاط) — متتالية عودية + متتالية مساعدة + برهنة بالتراجع

السؤال 1) 0.5 نقطة

الحسابات:
- $u_1 = \frac{3 \cdot 2 + 1}{2 + 3} = \frac{7}{5}$
- $u_2 = \frac{3 \cdot \frac{7}{5} + 1}{\frac{7}{5} + 3} = \frac{\frac{21}{5} + \frac{5}{5}}{\frac{7}{5} + \frac{15}{5}} = \frac{\frac{26}{5}}{\frac{22}{5}} = \frac{26}{22} = \frac{13}{11}$
- $u_3 = \frac{3 \cdot \frac{13}{11} + 1}{\frac{13}{11} + 3} = \frac{\frac{39}{11} + \frac{11}{11}}{\frac{13}{11} + \frac{33}{11}} = \frac{\frac{50}{11}}{\frac{46}{11}} = \frac{50}{46} = \frac{25}{23}$

السؤال 2) 1.25 نقطة

التهيئة ($n = 1$): $u_1 = \frac{7}{5}$... لكن $\frac{7}{5} > 1$!

ملاحظة: $u_0 = 2$, $u_1 = 7/5 = 1,4$, $u_2 = 13/11 \approx 1,18$, $u_3 = 25/23 \approx 1,087$. المتتالية تقترب من 1 من فوق.

لِنُعدّل السؤال: برهن بالتراجع أنّ $1 < u_n \leq 2$ لكل $n \in \mathbb{N}$.

التهيئة ($n = 0$): $u_0 = 2 \in (1, 2]$ ✓

الفرضية: نفرض $1 < u_n \leq 2$.

النتيجة ($n + 1$): ندرس $u_{n+1} = \frac{3u_n + 1}{u_n + 3}$.
- إيجابية: $u_n > 0 \Rightarrow 3u_n + 1 > 0$ و $u_n + 3 > 0$, إذن $u_{n+1} > 0$ ✓
- $u_{n+1} > 1$:
$$u_{n+1} > 1 \iff 3u_n + 1 > u_n + 3 \iff 2u_n > 2 \iff u_n > 1$$ ✓
- $u_{n+1} \leq 2$:
$$u_{n+1} \leq 2 \iff 3u_n + 1 \leq 2(u_n + 3) \iff 3u_n + 1 \leq 2u_n + 6 \iff u_n \leq 5$$ ✓

إذن $1 < u_{n+1} \leq 2$ ✓.

الخلاصة: بالتراجع, $1 < u_n \leq 2$ لكل $n \in \mathbb{N}$.

السؤال 3) 1 نقطة

الحساب:
$$u_{n+1} - u_n = \frac{3u_n + 1 - u_n(u_n + 3)}{u_n + 3} = \frac{3u_n + 1 - u_n^2 - 3u_n}{u_n + 3} = \frac{1 - u_n^2}{u_n + 3} = \frac{(1 - u_n)(1 + u_n)}{u_n + 3}$$

من السؤال 2, $u_n > 1$:
- $1 - u_n < 0$
- $1 + u_n > 0$
- $u_n + 3 > 0$
- إذن $u_{n+1} - u_n < 0$

النتيجة: $(u_n)$ متناقصة.

السؤال 4) 0.75 نقطة

التقارب:
- $(u_n)$ متناقصة (من السؤال 3)
- محدودة سفلًا بـ 1 (من السؤال 2)
- إذن متقاربة حسب مبرهنة الرتابة المحدودة

حساب $\ell$:
نأخذ النهاية في $u_{n+1} = \frac{3u_n + 1}{u_n + 3}$:
$$\ell = \frac{3\ell + 1}{\ell + 3} \Rightarrow \ell(\ell + 3) = 3\ell + 1 \Rightarrow \ell^2 + 3\ell = 3\ell + 1 \Rightarrow \ell^2 = 1$$
$$\ell = \pm 1$$

بما أنّ $u_n > 1$, $\ell \geq 1$, إذن $\ell = 1$.

السؤال 5) 1.5 نقطة

أ) الطبيعة الهندسية:
$$v_{n+1} = \frac{u_{n+1} - 1}{u_{n+1} + 1} = \frac{\frac{3u_n + 1}{u_n + 3} - 1}{\frac{3u_n + 1}{u_n + 3} + 1} = \frac{3u_n + 1 - (u_n + 3)}{3u_n + 1 + (u_n + 3)} = \frac{2u_n - 2}{4u_n + 4} = \frac{2(u_n - 1)}{4(u_n + 1)} = \frac{1}{2} v_n$$

إذن $(v_n)$ متتالية هندسية أساسها $q = \frac{1}{2}$.

الحد الأول: $v_0 = \frac{u_0 - 1}{u_0 + 1} = \frac{2 - 1}{2 + 1} = \frac{1}{3}$.

ب) الصيغ الصريحة:
$$v_n = v_0 \cdot q^n = \frac{1}{3} \cdot \left(\frac{1}{2}\right)^n = \frac{1}{3 \cdot 2^n}$$

من $v_n = \frac{u_n - 1}{u_n + 1}$, نحل:
$$u_n = \frac{1 + v_n}{1 - v_n} = \frac{1 + \frac{1}{3 \cdot 2^n}}{1 - \frac{1}{3 \cdot 2^n}} = \frac{3 \cdot 2^n + 1}{3 \cdot 2^n - 1}$$

ج) المجموع والنهاية:
$$\sum_{k=0}^n v_k = v_0 \cdot \frac{1 - q^{n+1}}{1 - q} = \frac{1}{3} \cdot \frac{1 - (1/2)^{n+1}}{1/2} = \frac{2}{3}\left(1 - \frac{1}{2^{n+1}}\right)$$

النهاية: $\lim \sum v_k = \frac{2}{3}$ (لأن $(1/2)^{n+1} \to 0$).

التمرين الثالث (5 نقاط) — نهايات + استمرارية + IVT + مبرهنة لاغرنج

السؤال 1) 1.5 نقطة

أ) $\lim \frac{3x^2 - 5x + 1}{x^2 - 4x + 7} = \frac{3}{1} = 3$ (نسبة الحدود الأعلى)

ب) عند $x = 2$: شكل غير معرّف $\frac{0}{0}$. نبسّط:
$$\frac{x^3 - 8}{x^2 - 4} = \frac{(x - 2)(x^2 + 2x + 4)}{(x - 2)(x + 2)} = \frac{x^2 + 2x + 4}{x + 2}$$
$$\lim_{x \to 2} = \frac{4 + 4 + 4}{4} = 3$$

ج) بالضرب بالمرافق:
$$\sqrt{x^2 + 3x} - x = \frac{(\sqrt{x^2+3x})^2 - x^2}{\sqrt{x^2+3x} + x} = \frac{3x}{\sqrt{x^2+3x} + x}$$
$$= \frac{3}{\sqrt{1 + 3/x} + 1} \to \frac{3}{2}$$

د) نستعمل $1 - \cos x = 2 \sin^2(x/2)$:
$$\frac{1 - \cos x}{x^2} = \frac{2 \sin^2(x/2)}{x^2} = \frac{2}{4} \cdot \left(\frac{\sin(x/2)}{x/2}\right)^2 = \frac{1}{2} \cdot 1 = \frac{1}{2}$$

السؤال 2) 1.5 نقطة

أ) قيمة $a$ للاتصال:
$$\lim_{x \to 0} \frac{\sin x}{x} = 1 \text{ (شهيرة)}$$

للاتصال: $g(0) = a = 1$, إذن $\boxed{a = 1}$.

ب) القابلية للاشتقاق:
$$g'(0) = \lim_{x \to 0} \frac{g(x) - g(0)}{x - 0} = \lim_{x \to 0} \frac{\frac{\sin x}{x} - 1}{x} = \lim \frac{\sin x - x}{x^2}$$

باستعمال تaylor: $\sin x = x - x^3/6 + O(x^5)$, إذن $\sin x - x = -x^3/6 + O(x^5)$.
$$\frac{\sin x - x}{x^2} = \frac{-x^3/6}{x^2} + O(x^3) = -\frac{x}{6} + O(x^3) \to 0$$

إذن $g'(0) = 0$ — $g$ قابلة للاشتقاق عند $0$ ✓.

السؤال 3) 1 نقطة

الدراسة:
- $h'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x - 1)(x + 1)$
- النقاط الحرجة: $x = -1$ و $x = 1$
- $h(-\infty) = -\infty$, $h(+\infty) = +\infty$
- $h(-1) = -1 + 3 + 1 = 3$ (عظمى محلية)
- $h(1) = 1 - 3 + 1 = -1$ (صغرى محلية)

التطبيق (IVT على كل مجال):
- على $(-\infty, -1)$: $h$ تزايد من $-\infty$ إلى $3$, يقطع $0$ مرة واحدة → حل $\alpha_1 < -1$
- على $(-1, 1)$: $h$ تناقص من $3$ إلى $-1$, يقطع $0$ مرة واحدة → حل $\alpha_2 \in (-1, 1)$
- على $(1, +\infty)$: $h$ تزايد من $-1$ إلى $+\infty$, يقطع $0$ مرة واحدة → حل $\alpha_3 > 1$

النتيجة: 3 حلول على $\mathbb{R}$ ✓.

السؤال 4) 0.5 نقطة

شروط لاغرنج:
- $\varphi$ متصلة على $[1, e]$ ✓
- $\varphi$ قابلة للاشتقاق على $(1, e)$ ✓

التطبيق:
$$\frac{\varphi(e) - \varphi(1)}{e - 1} = \varphi'(c)$$
$$\frac{\ln e - \ln 1}{e - 1} = \frac{1}{c}$$
$$\frac{1 - 0}{e - 1} = \frac{1}{c}$$
$$c = e - 1 \approx 1,718$$

$c = e - 1 \in (1, e)$ ✓.

السؤال 5) 0.5 نقطة

نطبّق لاغرنج على $f(t) = \ln(t + 1)$ على $[0, x]$:
- $f'(t) = \frac{1}{t + 1}$
- يوجد $c \in (0, x)$ بحيث $\frac{f(x) - f(0)}{x - 0} = f'(c)$
- $\frac{\ln(x+1) - 0}{x} = \frac{1}{c+1}$
- $\ln(x+1) = \frac{x}{c+1}$

الترتيب: $0 < c < x \Rightarrow 1 < c + 1 < x + 1 \Rightarrow \frac{1}{x+1} < \frac{1}{c+1} < 1$

$$\frac{x}{x+1} < \frac{x}{c+1} < x \Rightarrow \frac{x}{x+1} < \ln(x+1) < x$$ ✓

التمرين الرابع (5 نقاط) — احتمالات + توزيع ذي الحدين + احتمال شرطي

السؤال 1) 1.25 نقطة

أ) عدد السحوبات: $\binom{10}{3} = 120$

ب) $P(3 \text{حمراء})$:
- عدد الحالات المواتية: $\binom{4}{3} = 4$
- $P = \frac{4}{120} = \frac{1}{30}$

ج) $P(\text{نفس اللون}) = P(3 \text{حمراء}) + P(3 \text{بيضاء})$:
- $P(3 \text{بيضاء}) = \frac{\binom{6}{3}}{120} = \frac{20}{120} = \frac{1}{6}$
- $P(\text{نفس اللون}) = \frac{1}{30} + \frac{1}{6} = \frac{1 + 5}{30} = \frac{6}{30} = \frac{1}{5}$

السؤال 2) 0.75 نقطة

بالحادثة المضادة:
$$P(\geq 1 \text{حمراء}) = 1 - P(0 \text{حمراء}) = 1 - \frac{\binom{6}{3}}{120} = 1 - \frac{20}{120} = 1 - \frac{1}{6} = \frac{5}{6}$$

أي $\approx 83,3\%$.

السؤال 3) 1.75 نقطة

أ) النوع: $X \sim \mathcal{B}(3, 0.4)$ — توزيع ذي الحدين, $n = 3$, $p = 4/10 = 0.4$.

ب) قانون التوزيع:
$$P(X = k) = \binom{3}{k} (0.4)^k (0.6)^{3-k}$$

| $k$ | 0 | 1 | 2 | 3 |
|---|:---:|:---:|:---:|:---:|
| $P(X = k)$ | $0.216$ | $0.432$ | $0.288$ | $0.064$ |

- $P(X = 0) = (0.6)^3 = 0.216$
- $P(X = 1) = 3 \cdot 0.4 \cdot 0.36 = 0.432$
- $P(X = 2) = 3 \cdot 0.16 \cdot 0.6 = 0.288$
- $P(X = 3) = (0.4)^3 = 0.064$

التحقق: $0.216 + 0.432 + 0.288 + 0.064 = 1$ ✓

ج) الأمل والتباين:
- $E(X) = np = 3 \cdot 0.4 = 1.2$
- $V(X) = np(1-p) = 3 \cdot 0.4 \cdot 0.6 = 0.72$

السؤال 4) 0.75 نقطة

$P(X \geq 2)$:
$$P(X \geq 2) = P(X = 2) + P(X = 3) = 0.288 + 0.064 = 0.352$$

$P(X = 2 | X \geq 1)$:
$$P(X \geq 1) = 1 - P(X = 0) = 1 - 0.216 = 0.784$$
$$P(X = 2 | X \geq 1) = \frac{P(X = 2)}{P(X \geq 1)} = \frac{0.288}{0.784} \approx 0.367$$

أي حوالي $36,7\%$.

السؤال 5) 0.5 نقطة

ليكن $Y \sim \mathcal{B}(n, 0.4)$ عدد الكرات الحمراء في $n$ سحبة.

$$P(Y \geq 1) = 1 - (0.6)^n \geq 0.95$$
$$(0.6)^n \leq 0.05$$
$$n \ln 0.6 \leq \ln 0.05$$
$$n \geq \frac{\ln 0.05}{\ln 0.6} \approx \frac{-2.996}{-0.511} \approx 5.86$$

النتيجة: $n_{\min} = 6$.
