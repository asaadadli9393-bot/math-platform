التمرين الأول (5 نقاط) — دراسة دالة + مساحة

السؤال 1) 1 نقطة

عند $0^+$: $\ln x \to -\infty$, $1/x \to +\infty$, المنتج $\to -\infty$.

عند $+\infty$: $\frac{\ln x}{x} \to 0$ (شهيرة).

السؤال 2) 1 نقطة

الاشتقاق:
$$f'(x) = \frac{1 \cdot x - \ln x \cdot 1}{x^2} = \frac{1 - \ln x}{x^2}$$

الإشارة:
- $x^2 > 0$ على $(0, +\infty)$
- $f'(x) \geq 0 \iff 1 - \ln x \geq 0 \iff \ln x \leq 1 \iff x \leq e$
- $f$ تزايد على $(0, e]$, تناقص على $[e, +\infty)$

السؤال 3) 0.5 نقطة

القيمة العظمى: عند $x = e$:
$$f(e) = \frac{\ln e}{e} = \frac{1}{e}$$

النقطة: $(e, 1/e)$.

السؤال 4) 1 نقطة

الحساب:
$$\int_1^e \frac{\ln x}{x}\, dx = \left[\frac{(\ln x)^2}{2}\right]_1^e = \frac{(\ln e)^2}{2} - \frac{(\ln 1)^2}{2} = \frac{1}{2} - 0 = \frac{1}{2}$$

النتيجة: $\frac{1}{2}$.

السؤال 5) 1.5 نقطة

الرتابة (لـ $n \geq 3$):
$$u_{n+1} - u_n = \frac{\ln(n+1)}{n+1} - \frac{\ln n}{n} = \frac{n \ln(n+1) - (n+1)\ln n}{n(n+1)}$$

البسط: $\ln\frac{(n+1)^n}{n^{n+1}} = \ln\frac{(1 + 1/n)^n}{n}$.

لـ $n \geq 3$: $(1 + 1/n)^n < e < n$, إذن البسط $< 0$, $u_{n+1} < u_n$.

$(u_n)$ متناقية لـ $n \geq 3$.

النهاية: $\lim u_n = 0$ (القوة تتفوق على اللوغاريتم).

التمرين الثاني (5 نقاط) — متتالية + برهنة بالتراجع

السؤال 1) 0.5 نقطة

الحساب:
- $u_1 = \sqrt{1 + 2} = \sqrt{3} \approx 1.73$
- $u_2 = \sqrt{\sqrt{3} + 2} \approx 1.93$
- $u_3 \approx 1.97$

السؤال 2) 1 نقطة

التهيئة: $u_0 = 1 \in (0, 2)$ ✓

الفرضية: $0 < u_n < 2$.

النتيجة: $u_{n+1} = \sqrt{u_n + 2}$
- $u_n > 0 \Rightarrow u_n + 2 > 2 \Rightarrow \sqrt{u_n + 2} > \sqrt{2} > 0$ ✓
- $u_n < 2 \Rightarrow u_n + 2 < 4 \Rightarrow \sqrt{u_n + 2} < 2$ ✓

إذن $0 < u_{n+1} < 2$ ✓.

الخلاصة: بالتراجع, $0 < u_n < 2$ لكل $n$.

السؤال 3) 1 نقطة

الحساب:
$$u_{n+1} - u_n = \sqrt{u_n + 2} - u_n$$

الإشارة: $\sqrt{u_n + 2} \geq u_n \iff u_n + 2 \geq u_n^2 \iff u_n^2 - u_n - 2 \leq 0 \iff (u_n - 2)(u_n + 1) \leq 0$

على $[-1, 2]$: $\leq 0$. بما أن $u_n \in (0, 2)$, $u_{n+1} - u_n \geq 0$.

$(u_n)$ متزايدة.

السؤال 4) 1 نقطة

التقارب: متزايدة + محدودة علويًا بـ 2 → متقاربة.

النهاية:
$$\ell = \sqrt{\ell + 2} \Rightarrow \ell^2 = \ell + 2 \Rightarrow \ell^2 - \ell - 2 = 0 \Rightarrow (\ell - 2)(\ell + 1) = 0$$

نختار الموجب: $\ell = 2$.

السؤال 5) 1.5 نقطة

الحساب:
نضع $v_n = u_n - 2$. نحسب:
$$v_{n+1} = u_{n+1} - 2 = \sqrt{u_n + 2} - 2 = \frac{(u_n + 2) - 4}{\sqrt{u_n + 2} + 2} = \frac{u_n - 2}{\sqrt{u_n + 2} + 2} = \frac{v_n}{\sqrt{u_n + 2} + 2}$$

إذن $\frac{v_{n+1}}{v_n} = \frac{1}{\sqrt{u_n + 2} + 2}$.

عند $n \to +\infty$: $u_n \to 2$, إذن $\sqrt{u_n + 2} + 2 \to \sqrt{4} + 2 = 4$.

النتيجة: $\lim = \frac{1}{4}$.

التمرين الثالث (5 نقاط) — هندسة في الفضاء

السؤال 1) 0.5 نقطة

الإحداثيات:
- $\vec{AB} = (-1; -1; -2)$
- $\vec{AC} = (1; -2; -4)$

السؤال 2) 1.5 نقطة

الجداء الشعاعي:
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ -1 & -1 & -2 \\ 1 & -2 & -4 \end{vmatrix}$$

$$= \vec{i}((-1)(-4) - (-2)(-2)) - \vec{j}((-1)(-4) - (-2)(1)) + \vec{k}((-1)(-2) - (-1)(1))$$
$$= \vec{i}(4 - 4) - \vec{j}(4 + 2) + \vec{k}(2 + 1)$$
$$= 0\vec{i} - 6\vec{j} + 3\vec{k} = (0; -6; 3)$$

النتيجة: $\vec{AB} \wedge \vec{AC} = (0; -6; 3)$.

السؤال 3) 1 نقطة

المتجه العادي: $\vec{n} = (0; -6; 3)$ أو مبسّط $(0; -2; 1)$

المعادلة: $-2y + z + d = 0$, بـ $A(1; 2; 3)$: $-4 + 3 + d = 0 \Rightarrow d = 1$

النتيجة: $-2y + z + 1 = 0$.

السؤال 4) 1 نقطة

الصيغة:
$$\mathcal{S} = \frac{1}{2}|\vec{AB} \wedge \vec{AC}| = \frac{1}{2}\sqrt{0 + 36 + 9} = \frac{1}{2}\sqrt{45} = \frac{3\sqrt{5}}{2}$$

النتيجة: $\mathcal{S} = \frac{3\sqrt{5}}{2} \approx 3,35$.

السؤال 5) 1 نقطة

الصيغة:
$$d(O, (ABC)) = \frac{|-2 \cdot 0 + 0 + 1|}{\sqrt{0 + 4 + 1}} = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}$$

النتيجة: $\frac{\sqrt{5}}{5} \approx 0,45$.

التمرين الرابع (5 نقاط) — احتمالات + توزيع

السؤال 1) 1.5 نقطة

أ) النوع: $X \sim \mathcal{B}(4, 1/6)$ (توزيع ذي الحدين, $n = 4$, $p = 1/6$).

ب) الأمل: $E(X) = 4 \cdot 1/6 = 2/3 \approx 0,667$

التباين: $V(X) = 4 \cdot 1/6 \cdot 5/6 = 20/36 = 5/9 \approx 0,556$

السؤال 2) 1 نقطة

$P(X = 0)$:
$$P(X = 0) = (5/6)^4 = 625/1296 \approx 0,482$$

$P(X = 4)$:
$$P(X = 4) = (1/6)^4 = 1/1296 \approx 0,00077$$

السؤال 3) 0.75 نقطة

بالحادثة المضادة:
$$P(X \geq 1) = 1 - P(X = 0) = 1 - 0.482 = 0.518$$

أي حوالي $51,8\%$.

السؤال 4) 1 نقطة

الحساب:
$$P(X = 2) = \binom{4}{2} (1/6)^2 (5/6)^2 = 6 \cdot \frac{1}{36} \cdot \frac{25}{36} = \frac{150}{1296} = \frac{25}{216} \approx 0,116$$

النتيجة: $\approx 11,6\%$.

السؤال 5) 0.75 نقطة

الصيغة:
$$P(X = 2 | X \geq 1) = \frac{P(X = 2)}{P(X \geq 1)} = \frac{0.116}{0.518} \approx 0.224$$

أي حوالي $22,4\%$.
