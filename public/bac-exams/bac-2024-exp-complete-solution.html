التمرين الأول (5 نقاط) — دراسة شاملة لدالة أسية

السؤال 1) 1 نقطة

عند $+\infty$:
- $\lim (x - 2) = +\infty$, $\lim e^x = +\infty$
- المنتج $\to +\infty$, $\lim f(x) = +\infty$

عند $-\infty$:
- نضع $X = -x \to +\infty$
- $f(x) = (-X - 2) e^{-X} + 3 = -\frac{X + 2}{e^X} + 3$
- $\lim \frac{X + 2}{e^X} = 0$ (الأسية تتفوق على القوة)
- إذن $\lim f(x) = 3$

التفسير الهندسي: المستقيم $y = 3$ مقارب أفقي لـ $(\mathcal{C})$ عند $-\infty$.

السؤال 2) 0.5 نقطة

الاشتقاق:
$$f'(x) = e^x + (x - 2) e^x = (1 + x - 2) e^x = (x - 1) e^x$$

النتيجة: $f'(x) = (x - 1) e^x$ ✓

السؤال 3) 1 نقطة

إشارة $f'(x)$:
- $e^x > 0$ دائمًا على $\mathbb{R}$
- إذن $\text{sgn}(f'(x)) = \text{sgn}(x - 1)$
- $f'(x) < 0$ على $(-\infty, 1)$
- $f'(x) = 0$ عند $x = 1$
- $f'(x) > 0$ على $(1, +\infty)$

جدول التغيّرات:

| $x$ | $-\infty$ | | $1$ | | $+\infty$ |
|---|---|---|---|---|---|
| $f'(x)$ | | $-$ | $0$ | $+$ | |
| $f$ | $3$ | $\searrow$ | $f(1) = 2 + e^{-1}$ | $\nearrow$ | $+\infty$ |

حيث $f(1) = (1 - 2) e^1 + 3 = -e + 3 \approx 0,282$ (قيمة صغرى).

السؤال 4) 0.75 نقطة

الحساب:
- $f(0) = (0 - 2) \cdot 1 + 3 = -2 + 3 = 1$, النقطة $\Omega(0, 1)$
- $f'(0) = (0 - 1) \cdot 1 = -1$, معامل التوجيه = $-1$

معادلة المماس:
$$y = f'(0)(x - 0) + f(0) = -x + 1$$

إذن $(T): y = -x + 1$.

السؤال 5) 0.75 نقطة

الحساب:
$$f(x) - (-x + 1) = (x - 2) e^x + 3 + x - 1 = (x - 2) e^x + x + 2$$

نضع $h(x) = (x - 2) e^x + x + 2$.

- $h(0) = -2 + 0 + 2 = 0$ ✓ (نقطة تقاطع عند $\Omega$)
- $h'(x) = e^x + (x - 2) e^x + 1 = (x - 1) e^x + 1$
- $h'(0) = -1 + 1 = 0$, إذن $\Omega$ نقطة تماس
- $h''(x) = e^x + (x - 1) e^x = x e^x$, $h''(0) = 0$
- ندرس قرب $\Omega$: $h$ يغير إشارته أو لا — يتم ذلك بدراسة إشارة $h$.

بالتقريب:
- لـ $x$ قريب من 0 موجب صغير: $h(x) > 0$ (المنحنى فوق المماس)
- لـ $x$ قريب من 0 سالب صغير: $h(x) < 0$ (المنحنى تحت المماس)

الإشارة لا تتغير عند $\Omega$ — تقاطع بترتيب 3 (الأكثر شيوعًا).

السؤال 6) 1 نقطة

عناصر الرسم:
- القيمة الصغرى: $(1, 0,282)$
- نقطة التقاطع مع المحور الصادي: $(0, 1)$
- المماس $(T): y = -x + 1$
- المقاربة الأفقية: $y = 3$ (عند $-\infty$)
- عند $+\infty$: المنحنى يرتفع نحو $+\infty$

المنحنى:
- من $y = 3$ عند $-\infty$, ينخفض قليلاً
- يصل القيمة الصغرى $(1, 0,282)$
- ثم يصعد نحو $+\infty$ عند $+\infty$

التمرين الثاني (5 نقاط) — متتاليات + برهنة بالتراجع

السؤال 1) 0.75 نقطة

الحسابات المباشرة:
- $u_1 = \frac{1/3}{1 + 1/3} = \frac{1/3}{4/3} = \frac{1}{4}$
- $u_2 = \frac{1/4}{1 + 1/4} = \frac{1/4}{5/4} = \frac{1}{5}$
- $u_3 = \frac{1/5}{1 + 1/5} = \frac{1/5}{6/5} = \frac{1}{6}$

ملاحظة: نلاحظ أنّ $u_n = \frac{1}{n + 3}$ (猜想 سيُثبت بالتراجع).

السؤال 2) 1.5 نقطة

التهيئة ($n = 0$):
- $u_0 = \frac{1}{0 + 3} = \frac{1}{3}$ ✓ (مطابق للمعطى)

الفرضية: نفرض $u_n = \frac{1}{n + 3}$ لـ $n$ معيّن.

النتيجة ($n + 1$):
$$u_{n+1} = \frac{u_n}{1 + u_n} = \frac{\frac{1}{n + 3}}{1 + \frac{1}{n + 3}} = \frac{\frac{1}{n + 3}}{\frac{n + 4}{n + 3}} = \frac{1}{n + 4}$$

إذن $u_{n+1} = \frac{1}{(n + 1) + 3}$ ✓

الخلاصة: بالتراجع، $u_n = \frac{1}{n + 3}$ لكل $n \in \mathbb{N}$.

السؤال 3) 0.5 نقطة

بما أن $u_n = \frac{1}{n + 3}$:

$$\lim_{n \to +\infty} u_n = \lim_{n \to +\infty} \frac{1}{n + 3} = 0$$

لأن المقام $n + 3 \to +\infty$.

السؤال 4) 1.5 نقطة

الحساب:
$$S_n = \sum_{k=0}^n u_k = \sum_{k=0}^n \frac{1}{k + 3} = \sum_{j=3}^{n+3} \frac{1}{j}$$

حيث $j = k + 3$ (تغيير المؤشر).

باستعمال المجموع الجزئي للمتوالية harmony:
$$\sum_{j=1}^{N} \frac{1}{j} = H_N \quad (العدد harmonic)$$

إذن:
$$S_n = H_{n+3} - H_2 = H_{n+3} - 1 - \frac{1}{2} = H_{n+3} - \frac{3}{2}$$

النهاية:
- $H_N \sim \ln N + \gamma$ (حيث $\gamma$ ثابت أويلر)
- $\lim_{n \to +\infty} H_{n+3} = +\infty$
- إذن $\lim_{n \to +\infty} S_n = +\infty$

ملاحظة: المتتالية harmonic $\sum \frac{1}{n}$ متشعّبة (نهايتها $+\infty$).

السؤال 5) 0.75 نقطة

الرتابة:
$$v_{n+1} - v_n = \frac{n+1}{n+4} - \frac{n}{n+3} = \frac{(n+1)(n+3) - n(n+4)}{(n+4)(n+3)} = \frac{n^2 + 4n + 3 - n^2 - 4n}{(n+4)(n+3)} = \frac{3}{(n+4)(n+3)}$$

بما أن $n \geq 0$, $v_{n+1} - v_n > 0$, إذن $(v_n)$ متزايدة.

النهاية:
$$\lim_{n \to +\infty} v_n = \lim \frac{n}{n + 3} = 1$$

(نسبة الحدود الأعلى).

التمرين الثالث (5 نقاط) — الاحتمالات + التوزيع ذي الحدين

السؤال 1) 0.5 نقطة

عدد السحوبات: $\binom{10}{3} = 120$.

التفصيل: $\binom{10}{3} = \frac{10 \cdot 9 \cdot 8}{3!} = \frac{720}{6} = 120$.

السؤال 2) 1.5 نقطة

أ) 3 حمراء:
$$P(3 \text{حمراء}) = \frac{\binom{4}{3}}{\binom{10}{3}} = \frac{4}{120} = \frac{1}{30}$$

ب) 3 بيضاء:
$$P(3 \text{بيضاء}) = \frac{\binom{6}{3}}{\binom{10}{3}} = \frac{20}{120} = \frac{1}{6}$$

ج) 3 من نفس اللون:
$$P(\text{نفس اللون}) = P(3 \text{ح}) + P(3 \text{ب}) = \frac{1}{30} + \frac{1}{6} = \frac{1 + 5}{30} = \frac{6}{30} = \frac{1}{5}$$

السؤال 3) 1 نقطة

الحادثة المضادة:
$$P(\geq 1 \text{حمراء}) = 1 - P(0 \text{حمراء}) = 1 - \frac{\binom{6}{3}}{\binom{10}{3}} = 1 - \frac{20}{120} = 1 - \frac{1}{6} = \frac{5}{6}$$

أي $\approx 83,3\%$.

السؤال 4) 2 نقطة

أ) نوع التوزيع:
- تجارب بيرنولي مستقلة (3 مرات)
- $p = 4/10 = 0.4$ (احتمال أحمر في كل سحب)
- إذن $X \sim \mathcal{B}(3, 0.4)$ (توزيع ذي الحدين)

ب) قانون التوزيع:
$$P(X = k) = \binom{3}{k} (0.4)^k (0.6)^{3-k}$$

| $X = k$ | 0 | 1 | 2 | 3 |
|---|:---:|:---:|:---:|:---:|
| $P(X = k)$ | $0.216$ | $0.432$ | $0.288$ | $0.064$ |

- $P(X = 0) = (0.6)^3 = 0.216$
- $P(X = 1) = \binom{3}{1}(0.4)(0.6)^2 = 3 \cdot 0.144 = 0.432$
- $P(X = 2) = \binom{3}{2}(0.4)^2(0.6) = 3 \cdot 0.096 = 0.288$
- $P(X = 3) = (0.4)^3 = 0.064$

التحقق: $0.216 + 0.432 + 0.288 + 0.064 = 1$ ✓

ج) الأمل والتباين:
- $E(X) = np = 3 \cdot 0.4 = 1.2$
- $V(X) = np(1-p) = 3 \cdot 0.4 \cdot 0.6 = 0.72$

التمرين الرابع (5 نقاط) — التكامل بالتجزئة + تغيير المتغير

السؤال 1) 1.5 نقطة

التكامل بالتجزئة:
- نضع $u = x$, $v' = e^{-x}$
- $u' = 1$, $v = -e^{-x}$

$$I = [-x e^{-x}]_0^1 + \int_0^1 e^{-x}\, dx$$
$$= (-1 \cdot e^{-1} - 0) + [-e^{-x}]_0^1$$
$$= -e^{-1} + (-e^{-1} + 1)$$
$$= 1 - 2 e^{-1} = 1 - \frac{2}{e}$$

النتيجة: $I = 1 - \frac{2}{e} \approx 0,264$.

السؤال 2) 1.5 نقطة

التكامل بالتجزئة المتكررة:
- نضع $u = x^2$, $v' = e^{-x}$
- $u' = 2x$, $v = -e^{-x}$

$$J = [-x^2 e^{-x}]_0^1 + 2 \int_0^1 x e^{-x}\, dx$$
$$= -e^{-1} + 2I$$
$$= -\frac{1}{e} + 2\left(1 - \frac{2}{e}\right)$$
$$= -\frac{1}{e} + 2 - \frac{4}{e}$$
$$= 2 - \frac{5}{e}$$

النتيجة: $J = 2 - \frac{5}{e} \approx 0,161$.

السؤال 3) 1 نقطة

تغيير المتغير:
- نضع $u = 1 + e^x$, $du = e^x\, dx$
- عند $x = 0$: $u = 2$
- عند $x = \ln 2$: $u = 1 + 2 = 3$

$$K = \int_2^3 \frac{1}{u}\, du = [\ln u]_2^3 = \ln 3 - \ln 2 = \ln\frac{3}{2}$$

النتيجة: $K = \ln\frac{3}{2} \approx 0,405$.

السؤال 4) 1 نقطة

التغيير:
- نضع $u = \cos x$, $du = -\sin x\, dx$
- $\sin^2 x = 1 - \cos^2 x = 1 - u^2$
- عند $x = 0$: $u = 1$
- عند $x = \pi/2$: $u = 0$

$$L = \int_0^{\pi/2} \sin x \cdot \sin^2 x\, dx = \int_0^{\pi/2} \sin x (1 - \cos^2 x)\, dx$$
$$= -\int_1^0 (1 - u^2)\, du = \int_0^1 (1 - u^2)\, du = \left[u - \frac{u^3}{3}\right]_0^1 = 1 - \frac{1}{3} = \frac{2}{3}$$

النتيجة: $L = \frac{2}{3}$.
