التمرين الأول (5 نقاط) — دراسة دالة + معادلة

السؤال 1) 1.5 نقطة

أ): $x^2 - 1 = (x-1)(x+1)$. لـ $x \neq 1$:
$$f(x) = \frac{x - 1}{(x - 1)(x + 1)} = \frac{1}{x + 1}$$

ملاحظة: على $\mathbb{R} \setminus \{\pm 1\}$, $f(x) = \frac{1}{x + 1}$.

ب):
- عند $1$: $f(1)$ غير معرّف, لكن $\lim_{x \to 1} f(x) = \frac{1}{2}$ (بالتبسيط)
- عند $-1^+$: $\lim = +\infty$
- عند $-1^-$: $\lim = -\infty$
- عند $\pm\infty$: $\lim = 0$

السؤال 2) 1 نقطة

الاشتقاق: $f(x) = \frac{1}{x + 1}$, إذن $f'(x) = -\frac{1}{(x + 1)^2}$

الإشارة: $(x+1)^2 > 0$, إذن $f'(x) < 0$ على $\mathbb{R} \setminus \{-1\}$.

جدول التغيّرات: $f$ تناقص على $(-\infty, -1)$ و على $(-1, +\infty)$.

السؤال 3) 0.5 نقطة

المقاربات:
- $x = -1$ مقارب عمودي
- $y = 0$ مقارب أفقي عند $\pm\infty$

السؤال 4) 1 نقطة

على $[0, 1)$: $f(x) = \frac{1}{x + 1}$ متصلة.

$$\int_0^1 \frac{1}{x + 1}\, dx = [\ln|x + 1|]_0^1 = \ln 2 - \ln 1 = \ln 2$$

النتيجة: $\ln 2 \approx 0.693$.

السؤال 5) 1 نقطة

$f(x) = 1 \iff \frac{1}{x + 1} = 1 \iff x + 1 = 1 \iff x = 0$.

في الواقع, $f(0) = 1$ ✓ — إذن المعادلة يقبل حلًّا وحيدًا $x = 0$.

ملاحظة: السؤال به خطأ — الحل موجود.

التمرين الثاني (5 نقاط) — متتالية + برهنة

السؤال 1) 0.5 نقطة

الحسابات:
- $u_1 = \frac{3}{2 + 1} = 1$
- $u_2 = \frac{3}{2 + 1} = 1$
- $u_3 = 1$

المتتالية ثابتة عند 1 (نقطة ثابتة).

السؤال 2) 1 نقطة

التهيئة: $u_0 = 1 > 0$ ✓

الفرضية: $u_n > 0$.

النتيجة: $u_{n+1} = \frac{3}{2 + u_n}$.
- $u_n > 0 \Rightarrow 2 + u_n > 2 > 0$
- $\Rightarrow u_{n+1} = \frac{3}{2 + u_n} > 0$ ✓

الخلاصة: بالتراجع, $u_n > 0$ لكل $n$.

السؤال 3) 1 نقطة

التهيئة: $u_0 = 1 < 2$ ✓

الفرضية: $u_n < 2$.

النتيجة: $u_{n+1} = \frac{3}{2 + u_n}$.
- $u_n < 2 \Rightarrow 2 + u_n < 4$
- $\Rightarrow u_{n+1} = \frac{3}{2 + u_n} > \frac{3}{4}$ — لا يكفي!

نُعيد: $u_{n+1} < 2 \iff 3 < 2(2 + u_n) \iff 3 < 4 + 2u_n$, صحيح دائمًا (لأن $2u_n > 0$).

إذن $u_{n+1} < 2$ ✓.

الخلاصة: بالتراجع, $0 < u_n < 2$ لكل $n$.

السؤال 4) 1.25 نقطة

الحساب:
$$u_{n+1} - u_n = \frac{3}{2 + u_n} - u_n = \frac{3 - u_n(2 + u_n)}{2 + u_n} = \frac{3 - 2u_n - u_n^2}{2 + u_n} = \frac{-(u_n^2 + 2u_n - 3)}{2 + u_n}$$

نحلل: $u_n^2 + 2u_n - 3 = (u_n + 3)(u_n - 1)$.

بما أنّ $u_n > 0$: $u_n + 3 > 0$. إذن:
- إذا $u_n < 1$: $u_n - 1 < 0 \Rightarrow u_{n+1} - u_n > 0$ (تزايد)
- إذا $u_n = 1$: $u_{n+1} = u_n$ (ثابت)
- إذا $u_n > 1$: $u_n - 1 > 0 \Rightarrow u_{n+1} - u_n < 0$ (تناقص)

في حالتنا $u_0 = 1$, إذن $(u_n)$ ثابتة عند 1.

التقارب: الثبات يدل على التقارب بـ $\ell = 1$.

السؤال 5) 1.25 نقطة

إذا كانت $(u_n)$ متقاربة إلى $\ell$, فإن:
$$\ell = \frac{3}{2 + \ell} \Rightarrow \ell(2 + \ell) = 3 \Rightarrow \ell^2 + 2\ell - 3 = 0$$

الجذور:
$$\Delta = 4 + 12 = 16, \quad \ell = \frac{-2 \pm 4}{2}$$
- $\ell = 1$ أو $\ell = -3$

بما أنّ $u_n > 0$, $\ell \geq 0$, إذن $\ell = 1$.

النتيجة: $\lim u_n = 1$.

التمرين الثالث (5 نقاط) — أعداد مركبة

السؤال 1) 1.25 نقطة

أ):
- $|z| = \sqrt{2 + 2} = 2$
- $\arg(z) = \arctan(\sqrt{2}/\sqrt{2}) = \arctan(1) = \pi/4$ (الربع الأول)

ب): $z = 2 e^{i\pi/4}$.

السؤال 2) 1 نقطة

الأسي: $z^4 = 2^4 \cdot e^{i4\pi/4} = 16 \cdot e^{i\pi} = -16$

الجبري: $-16 + 0i = -16$.

السؤال 3) 1.5 نقطة

الصيغة الأسيّة: $-16 = 16 e^{i\pi}$

نبحث عن $z = re^{i\theta}$ بحيث $z^4 = r^4 e^{4i\theta} = 16 e^{i\pi}$.
- $r^4 = 16 \Rightarrow r = 2$
- $4\theta = \pi + 2k\pi \Rightarrow \theta = \pi/4 + \frac{k\pi}{2}$, $k = 0, 1, 2, 3$

الحلول الأربعة:
- $k = 0$: $z_0 = 2 e^{i\pi/4} = \sqrt{2} + i\sqrt{2}$
- $k = 1$: $z_1 = 2 e^{i3\pi/4} = -\sqrt{2} + i\sqrt{2}$
- $k = 2$: $z_2 = 2 e^{i5\pi/4} = -\sqrt{2} - i\sqrt{2}$
- $k = 3$: $z_3 = 2 e^{i7\pi/4} = \sqrt{2} - i\sqrt{2}$

(الحلول متناظرة بالنسبة للأصل.)

السؤال 4) 1.25 نقطة

أ) إثبات المربّع:
- كل $z_k = 2 e^{i(\pi/4 + k\pi/2)}$, أي النقاط على دائرة半径2 حول الأصل, بفروق زاوية $\pi/2$ (90°).
- إذن النقاط الأربع رؤوس مربّع inscrit في الدائرة.

ب) طول الضلع:
$$AB = |z_1 - z_0| = |2 e^{i3\pi/4} - 2 e^{i\pi/4}| = 2|e^{i\pi/4}||e^{i\pi/2} - 1| = 2 \cdot |i - 1| = 2\sqrt{2}$$

النتيجة: طول الضلع $= 2\sqrt{2}$.

التمرين الرابع (5 نقاط) — هندسة في الفضاء

السؤال 1) 0.75 نقطة

الإحداثيات:
- $\vec{AB} = (-1; 1; 0)$
- $\vec{AC} = (-1; 0; 1)$
- $\vec{AD} = (0; 1; 1)$

السؤال 2) 1 نقطة

الجداءات السلمية:
- $\vec{AB} \cdot \vec{AC} = (-1)(-1) + (1)(0) + (0)(1) = 1 + 0 + 0 = 1$
- $\vec{AB} \cdot \vec{AD} = (-1)(0) + (1)(1) + (0)(1) = 0 + 1 + 0 = 1$
- $\vec{AC} \cdot \vec{AD} = (-1)(0) + (0)(1) + (1)(1) = 0 + 0 + 1 = 1$

ملاحظة: كل الجداءات = 1 → لا توجد عمودية.

السؤال 3) 1.5 نقطة

الجداء الشعاعي:
$$\vec{AB} \wedge \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ -1 & 1 & 0 \\ -1 & 0 & 1 \end{vmatrix}$$
$$= \vec{i}(1) - \vec{j}(-1) + \vec{k}(1) = (1; 1; 1)$$

المتجه العادي: $\vec{n} = (1; 1; 1)$

معادلة المستوي $(ABC)$: $x + y + z + d = 0$. بـ $A(1; 0; 0)$: $1 + 0 + 0 + d = 0 \Rightarrow d = -1$.

المعادلة: $\boxed{x + y + z - 1 = 0}$

التحقق:
- $B(0, 1, 0)$: $0 + 1 + 0 - 1 = 0$ ✓
- $C(0, 0, 1)$: $0 + 0 + 1 - 1 = 0$ ✓

السؤال 4) 0.75 نقطة

الصيغة:
$$d(D, (ABC)) = \frac{|1 + 1 + 1 - 1|}{\sqrt{1 + 1 + 1}} = \frac{2}{\sqrt{3}} = \frac{2\sqrt{3}}{3}$$

النتيجة: $\frac{2\sqrt{3}}{3} \approx 1.155$.

السؤال 5) 1 نقطة

الجداء المختلط:
$$[\vec{AB}, \vec{AC}, \vec{AD}] = (\vec{AB} \wedge \vec{AC}) \cdot \vec{AD} = (1; 1; 1) \cdot (0; 1; 1) = 0 + 1 + 1 = 2$$

حجم الرباعي:
$$V = \frac{|2|}{6} = \frac{1}{3}$$

النتيجة: $V = \frac{1}{3}$ وحدة حجم.
