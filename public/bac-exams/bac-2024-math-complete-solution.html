التمرين الأول (5 نقاط) — دراسة دالة + معادلة

السؤال 1) 1 نقطة

عند $0^+$:
- $\lim x^2 + 1 = 1$
- $\lim x = 0^+$
- $\lim f(x) = +\infty$

تفسير هندسي: المستقيم $x = 0$ (المحور الصادي) مقارب عمودي لـ $(\mathcal{C}_f)$.

عند $+\infty$:
- $f(x) = \frac{x^2 + 1}{x} = x + \frac{1}{x}$
- $\lim \frac{1}{x} = 0$
- إذن $\lim f(x) = +\infty$

السؤال 2) 0.75 نقطة

إثبات الفردية:
- مجال التعريف $\mathbb{R}^*$ متماثل حول $0$
- $f(-x) = \frac{(-x)^2 + 1}{-x} = \frac{x^2 + 1}{-x} = -f(x)$

إذن $f$ فردية ✓.

الاستنتاج: منحناها البياني متماثل بالنسبة لنقطة الأصل $O$.

السؤال 3) 1 نقطة

الاشتقاق:
$$f'(x) = \frac{2x \cdot x - (x^2 + 1)}{x^2} = \frac{2x^2 - x^2 - 1}{x^2} = \frac{x^2 - 1}{x^2}$$

الإشارة:
- $x^2 > 0$ على $\mathbb{R}^*$
- $f'(x) \geq 0 \iff x^2 - 1 \geq 0 \iff |x| \geq 1 \iff x \leq -1 \text{ أو } x \geq 1$
- $f'(x) < 0$ على $(-1, 0)$ و $(0, 1)$
- $f'(\pm 1) = 0$

جدول التغيّرات (نظراً للفردية):

| $x$ | $-\infty$ | $-1$ | $0$ | $1$ | $+\infty$ |
|---|---|---|---|---|---|
| $f'$ | $+$ | $0$ | $||$ | $0$ | $+$ |
| $f$ | $-\infty$ | $-2$ | $||$ | $+2$ | $+\infty$ |

القيمة الصغرى على $(0, +\infty)$ عند $x = 1$: $f(1) = 2$.
القيمة العظمى على $(-\infty, 0)$ عند $x = -1$: $f(-1) = -2$.

السؤال 4) 1 نقطة

المقارب المائل:
$$f(x) - x = \frac{x^2 + 1}{x} - x = \frac{x^2 + 1 - x^2}{x} = \frac{1}{x}$$

- $\lim_{x \to +\infty} \frac{1}{x} = 0$, إذن $(D): y = x$ مقارب مائل عند $+\infty$ ✓

الوضع النسبي:
- $f(x) - x = \frac{1}{x} > 0$ على $(0, +\infty)$
- إذن $(\mathcal{C}_f)$ فوق $(D)$ على $(0, +\infty)$

بسبب الفردية، $(\mathcal{C}_f)$ تحت $(D)$ على $(-\infty, 0)$.

السؤال 5) 1.25 نقطة

المساحة:
على $[1, 2]$: $(\mathcal{C}_f)$ فوق $(D)$ (لأن $f - x = 1/x > 0$).

$$\mathcal{S} = \int_1^2 (f(x) - x)\, dx = \int_1^2 \frac{1}{x}\, dx = [\ln x]_1^2 = \ln 2 - \ln 1 = \ln 2$$

النتيجة: $\mathcal{S} = \ln 2 \text{ unit}^2 \approx 0,693 \text{ unit}^2$.

التمرين الثاني (5 نقاط) — متتالية عودية + متتالية مساعدة + برهنة

السؤال 1) 0.75 نقطة

الحسابات:
- $u_1 = \frac{2 \cdot 2 + 1}{2 + 2} = \frac{5}{4}$
- $u_2 = \frac{2 \cdot \frac{5}{4} + 1}{\frac{5}{4} + 2} = \frac{\frac{10}{4} + \frac{4}{4}}{\frac{5}{4} + \frac{8}{4}} = \frac{\frac{14}{4}}{\frac{13}{4}} = \frac{14}{13}$
- $u_3 = \frac{2 \cdot \frac{14}{13} + 1}{\frac{14}{13} + 2} = \frac{\frac{28}{13} + \frac{13}{13}}{\frac{14}{13} + \frac{26}{13}} = \frac{\frac{41}{13}}{\frac{40}{13}} = \frac{41}{40}$

السؤال 2) 1 نقطة

التهيئة ($n = 0$): $u_0 = 2 \in (0, 2]$ ✓.

الفرضية: نفرض $0 < u_n \leq 2$.

النتيجة: ندرس $u_{n+1} = \frac{2u_n + 1}{u_n + 2}$.

- إيجابية: $u_n > 0 \Rightarrow 2u_n + 1 > 0$ و $u_n + 2 > 0$, إذن $u_{n+1} > 0$ ✓
- الحد الأعلى:
$$u_{n+1} \leq 2 \iff 2u_n + 1 \leq 2(u_n + 2) \iff 2u_n + 1 \leq 2u_n + 4 \iff 1 \leq 4$$ ✓

إذن $0 < u_{n+1} \leq 2$.

الخلاصة: بالتراجع، $0 < u_n \leq 2$ لكل $n$.

السؤال 3) 0.75 نقطة

الحساب:
$$u_{n+1} - u_n = \frac{2u_n + 1}{u_n + 2} - u_n = \frac{2u_n + 1 - u_n(u_n + 2)}{u_n + 2} = \frac{2u_n + 1 - u_n^2 - 2u_n}{u_n + 2} = \frac{1 - u_n^2}{u_n + 2}$$

بما أن $0 < u_n \leq 2$ (من السؤال 2):
- $u_n + 2 > 0$
- $u_n > 1 \Rightarrow u_n^2 > 1 \Rightarrow 1 - u_n^2 < 0 \Rightarrow u_{n+1} - u_n < 0$
- $u_n < 1 \Rightarrow 1 - u_n^2 > 0 \Rightarrow u_{n+1} - u_n > 0$
- $u_n = 1 \Rightarrow u_{n+1} = u_n = 1$ (نقطة ثابتة)

النتيجة:
- إذا $u_0 > 1$: $(u_n)$ متناقصة
- إذا $u_0 = 1$: $(u_n)$ ثابتة
- إذا $u_0 < 1$: $(u_n)$ متزايدة

في حالتنا ($u_0 = 2 > 1$): $(u_n)$ متناقصة.

السؤال 4) 0.75 نقطة

التقارب:
- $(u_n)$ متناقصة (من $u_0 = 2 > 1$)
- محدودة سفلًا بـ 0 (أو بـ 1 لأنها تقترب من 1)
- إذن متقاربة (نظرية الرتابة المحدودة)

حساب $\ell$:
نأخذ النهاية في $u_{n+1} = \frac{2u_n + 1}{u_n + 2}$:
$$\ell = \frac{2\ell + 1}{\ell + 2}$$
$$\ell(\ell + 2) = 2\ell + 1$$
$$\ell^2 + 2\ell = 2\ell + 1$$
$$\ell^2 = 1$$
$$\ell = \pm 1$$

بما أن $u_n > 0$, إذن $\ell \geq 0$, إذن $\ell = 1$.

السؤال 5) 1.75 نقطة

أ) الطبيعة الهندسية:
$$v_{n+1} = \frac{u_{n+1} - 1}{u_{n+1} + 1} = \frac{\frac{2u_n + 1}{u_n + 2} - 1}{\frac{2u_n + 1}{u_n + 2} + 1} = \frac{2u_n + 1 - (u_n + 2)}{2u_n + 1 + (u_n + 2)} = \frac{u_n - 1}{3u_n + 3} = \frac{u_n - 1}{3(u_n + 1)} = \frac{1}{3} v_n$$

إذن $(v_n)$ هندسية أساسها $q = \frac{1}{3}$ و حدّها الأول:
$$v_0 = \frac{u_0 - 1}{u_0 + 1} = \frac{2 - 1}{2 + 1} = \frac{1}{3}$$

ب) الصيغ الصريحة:
$$v_n = v_0 \cdot q^n = \frac{1}{3} \cdot \left(\frac{1}{3}\right)^n = \frac{1}{3^{n+1}}$$

من $v_n = \frac{u_n - 1}{u_n + 1}$: $u_n = \frac{1 + v_n}{1 - v_n}$, إذن:
$$u_n = \frac{1 + \frac{1}{3^{n+1}}}{1 - \frac{1}{3^{n+1}}} = \frac{3^{n+1} + 1}{3^{n+1} - 1}$$

ج) المجموع:
$$\sum_{k=0}^n v_k = v_0 \cdot \frac{1 - q^{n+1}}{1 - q} = \frac{1}{3} \cdot \frac{1 - (1/3)^{n+1}}{2/3} = \frac{1 - 1/3^{n+1}}{2}$$

النهاية:
$$\lim_{n \to +\infty} \sum v_k = \frac{1}{2}$$

(لأن $(1/3)^{n+1} \to 0$).

التمرين الثالث (5 نقاط) — الأعداد المركبة + هندسة

السؤال 1) 1 نقطة

أ) المقدار:
$$|z| = \sqrt{(\sqrt{3})^2 + (-1)^2} = \sqrt{3 + 1} = 2$$

العلّة:
$$\arg(z) = \arctan\left(\frac{-1}{\sqrt{3}}\right) = -\frac{\pi}{6} \quad [2\pi]$$

(العدد في الربع الرابع لأن $\Re z > 0$ و $\Im z < 0$.)

ب) الشكل الأسي:
$$z = 2 e^{-i\pi/6}$$

السؤال 2) 1.25 نقطة

$z^2$ (صيغة موافري):
$$z^2 = (2 e^{-i\pi/6})^2 = 4 e^{-i\pi/3}$$

الجبري: $4(\cos(-\pi/3) + i\sin(-\pi/3)) = 4(1/2 - i\sqrt{3}/2) = 2 - 2i\sqrt{3}$.

$z^6$:
$$z^6 = (2 e^{-i\pi/6})^6 = 64 e^{-i\pi} = 64 \cdot (-1) = -64$$

(الشكل الجبري: $-64 + 0i$.)

السؤال 3) 1.25 نقطة

الصيغة الأسيّة:
- $-8i = 8 e^{-i\pi/2}$
- نبحث عن $z = re^{i\theta}$ حيث $z^3 = r^3 e^{3i\theta} = 8 e^{-i\pi/2}$
- $r^3 = 8 \Rightarrow r = 2$
- $3\theta = -\pi/2 + 2k\pi \Rightarrow \theta = -\pi/6 + \frac{2k\pi}{3}$, $k \in \mathbb{Z}$

الحلول الثلاثة ($k = 0, 1, 2$):
- $z_0 = 2 e^{-i\pi/6} = \sqrt{3} - i$
- $z_1 = 2 e^{i(-\pi/6 + 2\pi/3)} = 2 e^{i\pi/2} = 2i$
- $z_2 = 2 e^{i(-\pi/6 + 4\pi/3)} = 2 e^{i7\pi/6} = -\sqrt{3} - i$

التحقق: $(\sqrt{3} - i)^3 = -8i$ ✓ (من السؤال 1 و 2).

السؤال 4) 1.5 نقطة

أ) الإحداثيات:
- $A(\sqrt{3}; -1)$
- $B(2; -2\sqrt{3})$

ب) إثبات القائم في $A$:
نحسب:
$$\vec{OA} = (\sqrt{3}, -1), \quad \vec{AB} = (2 - \sqrt{3}, -2\sqrt{3} + 1) = (2 - \sqrt{3}, 1 - 2\sqrt{3})$$

$$\vec{OA} \cdot \vec{AB} = \sqrt{3}(2 - \sqrt{3}) + (-1)(1 - 2\sqrt{3})$$
$$= 2\sqrt{3} - 3 - 1 + 2\sqrt{3} = 4\sqrt{3} - 4$$

ملاحظة: هذا لا يساوي صفرًا, إذن المثلث ليس قائمًا في $A$.

نتحقق في $O$:
$$\vec{OA} \cdot \vec{OB} = \sqrt{3} \cdot 2 + (-1) \cdot (-2\sqrt{3}) = 2\sqrt{3} + 2\sqrt{3} = 4\sqrt{3} \neq 0$$

ليس قائمًا في $O$. نتأكد من $B$:
$$\vec{BA} = -\vec{AB} = (-2 + \sqrt{3}, -1 + 2\sqrt{3})$$
$$\vec{BO} = (-2, 2\sqrt{3})$$
$$\vec{BA} \cdot \vec{BO} = (-2 + \sqrt{3})(-2) + (-1 + 2\sqrt{3})(2\sqrt{3})$$
$$= 4 - 2\sqrt{3} - 2\sqrt{3} + 4 \cdot 3 = 4 - 4\sqrt{3} + 12 = 16 - 4\sqrt{3} \neq 0$$

ملاحظة: المثلث ليس قائمًا. لنحسب الزوايا و الأضلاع.

ج) الزاوية $\widehat{AOB}$:
$$\cos \widehat{AOB} = \frac{\vec{OA} \cdot \vec{OB}}{|OA| \cdot |OB|} = \frac{4\sqrt{3}}{2 \cdot 4} = \frac{\sqrt{3}}{2}$$
$$\widehat{AOB} = \pi/6 \text{ rad} = 30°$$

ملاحظة: ناتج السؤال يحتاج تصحيح — المثلث ليس قائمًا, لكن الزاوية $\widehat{AOB} = 30°$.

التمرين الرابع (5 نقاط) — معادلة تفاضلية + الحساب (نظرية فيرما)

السؤال 1) 0.75 نقطة

المعادلة الموافقة: $y' = -y$ (معادلة تفاضلية من الدرجة الأولى ذات معامل ثابت).

الحل العام:
$$y(x) = C e^{-x}, \quad C \in \mathbb{R}$$

السؤال 2) 1.25 نقطة

حساب $g'$:
$$g'(x) = a e^{-x} - (ax + b) e^{-x} = (a - ax - b) e^{-x}$$

التعبير في $(E')$:
$$g'(x) + g(x) = (a - ax - b) e^{-x} + (ax + b) e^{-x} = a e^{-x}$$

نريد $g' + g = e^{-x}$, أي $a e^{-x} = e^{-x}$, إذن $a = 1$.

$b$ حرّ (أي قيمة), ولتكن $b = 0$ للحلّ الأساسي:
$$g(x) = x e^{-x}$$

الحل العام لـ $(E')$:
$$y(x) = x e^{-x} + C e^{-x} = (x + C) e^{-x}$$

السؤال 3) 0.75 نقطة

تطبيق الشرط:
- $f(0) = (0 + C) e^0 = C = 1$
- إذن $C = 1$

الحل الوحيد:
$$f(x) = (x + 1) e^{-x}$$

السؤال 4) 1.5 نقطة

البرهنة (فكرة عامة):

نعتبر الأعداد $1, 2, 3, \ldots, p-1$. هذه تشكّل عناصر $\mathbb{Z}/p\mathbb{Z}^*$ (مجموعة الأعداد المعاكسة ضريبيًّا لـ $p$).

الخطوة 1: نضرب هذه الأعداد في $a$:
$$a \cdot 1, a \cdot 2, a \cdot 3, \ldots, a \cdot (p-1)$$

الخطوة 2: نظهر أنّ هذه $(p-1)$ نتيجة كلها مختلفة mód $p$:
- لو كان $a \cdot k_1 \equiv a \cdot k_2 \pmod{p}$, إذن $p | a(k_1 - k_2)$
- بما أن $\gcd(a, p) = 1$ (نظرية گاوس), $p | (k_1 - k_2)$
- لكن $|k_1 - k_2| < p$, إذن $k_1 = k_2$ ✓

الخطوة 3: إذن مجموعة $\{a \cdot 1, a \cdot 2, \ldots, a \cdot (p-1)\}$ تبديل لـ $\{1, 2, \ldots, p-1\}$ mód $p$.

الخطوة 4: نضرب كل الأعداد:
$$\prod_{k=1}^{p-1} (a k) \equiv \prod_{k=1}^{p-1} k \pmod{p}$$
$$a^{p-1} \cdot (p-1)! \equiv (p-1)! \pmod{p}$$

بما أنّ $\gcd((p-1)!, p) = 1$ (لأن $p$ أولي و $p \nmid (p-1)!$), نختصر:
$$a^{p-1} \equiv 1 \pmod{p}$$ ✓

الخلاصة: نظرية فيرما الصغرية مثبتة.

السؤال 5) 0.75 نقطة

التطبيق:
- $p = 7$ (أولي), $a = 2$ ($\gcd(2, 7) = 1$)
- نظرية فيرما: $2^{7-1} = 2^6 \equiv 1 \pmod{7}$

تفكيك $2^{100}$:
- $100 = 6 \times 16 + 4$
- إذن $2^{100} = (2^6)^{16} \cdot 2^4 = 1^{16} \cdot 16 \equiv 16 \equiv 2 \pmod{7}$

(لأن $16 = 2 \times 7 + 2$.)

النتيجة: باقي قسمة $2^{100}$ على 7 هو $2$.
