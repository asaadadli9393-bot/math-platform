التمرين الأول (5 نقاط) — دراسة دالة أسية

السؤال 1) 1 نقطة

عند $+\infty$: $\lim (x-1) = +\infty$, $\lim e^{x-2} = +\infty$, إذن $f \to +\infty$.

عند $-\infty$:
- نضع $X = -x \to +\infty$
- $f(x) = (-X - 1) e^{-X - 2} = -(X + 1) e^{-X} \cdot e^{-2}$
- $\lim (X+1)/e^X = 0$ (الأسية تتفوق)
- إذن $f(x) \to 0$

السؤال 2) 1 نقطة

الاشتقاق:
$$f'(x) = e^{x-2} + (x - 1) e^{x-2} = x \cdot e^{x-2}$$

الإشارة:
- $e^{x-2} > 0$ دائمًا
- $f'(x) \geq 0 \iff x \geq 0$
- $f' < 0$ على $(-\infty, 0)$, $f' > 0$ على $(0, +\infty)$

السؤال 3) 1 نقطة

جدول التغيّرات:
- $f$ تناقص على $(-\infty, 0]$, تزايد على $[0, +\infty)$
- القيمة الصغرى: $f(0) = (-1) \cdot e^{-2} = -e^{-2} \approx -0,135$

السؤال 4) 1 نقطة

الحساب:
- $f(1) = 0 \cdot e^{-1} = 0$, $A(1, 0)$
- $f'(1) = 1 \cdot e^{-1} = 1/e$

المماس: $y = \frac{1}{e}(x - 1)$, أي $y = \frac{x - 1}{e}$.

السؤال 5) 1 نقطة

الحل:
$$f(x) = 0 \iff (x - 1) e^{x - 2} = 0$$

بما أنّ $e^{x-2} > 0$ دائمًا, $f(x) = 0 \iff x - 1 = 0 \iff x = 1$.

النتيجة: حل وحيد $\alpha = 1$.

التمرين الثاني (5 نقاط) — معادلات أسية ولوغاريتمية

السؤال 1) 1 نقطة

التحويل:
نضع $X = e^x$ ($X > 0$):
$$X^2 - 5X + 6 = 0 \Rightarrow (X - 2)(X - 3) = 0 \Rightarrow X = 2 \text{ أو } X = 3$$

الحلول:
- $x = \ln 2$ أو $x = \ln 3$

السؤال 2) 1.5 نقطة

شروط الوجود:
- $x + 1 > 0 \Rightarrow x > -1$
- $x - 2 > 0 \Rightarrow x > 2$
- إذن $x > 2$

الحل:
$$\ln[(x + 1)(x - 2)] = \ln 6 \iff (x + 1)(x - 2) = 6$$
$$x^2 - x - 2 = 6 \iff x^2 - x - 8 = 0$$
$$\Delta = 1 + 32 = 33, \quad x = \frac{1 \pm \sqrt{33}}{2}$$

نختار $x > 2$: $x = \frac{1 + \sqrt{33}}{2} \approx 3,37$ ✓
(الحل الآخر $\frac{1 - \sqrt{33}}{2} \approx -2,37$ مرفوض)

السؤال 3) 1 نقطة

التحويل:
نضع $Y = \ln x$ ($Y \in \mathbb{R}$):
$$Y^2 - 4Y + 3 = 0 \Rightarrow (Y - 1)(Y - 3) = 0 \Rightarrow Y = 1 \text{ أو } Y = 3$$

الحلول:
- $\ln x = 1 \Rightarrow x = e$
- $\ln x = 3 \Rightarrow x = e^3$

السؤال 4) 1 نقطة

التحويل:
نضع $X = e^x$ ($X > 0$):
$$X + \frac{1}{X} = 3 \iff X^2 - 3X + 1 = 0$$

الجذور:
$$\Delta = 9 - 4 = 5, \quad X = \frac{3 \pm \sqrt{5}}{2}$$

كلاهما موجب, إذن:
- $x_1 = \ln\left(\frac{3 + \sqrt{5}}{2}\right)$
- $x_2 = \ln\left(\frac{3 - \sqrt{5}}{2}\right)$

السؤال 5) 0.5 نقطة

الحساب:
$$\ln 6 + \ln 4 - \ln 8 = \ln\left(\frac{6 \cdot 4}{8}\right) = \ln\left(\frac{24}{8}\right) = \ln 3$$

النتيجة: $\ln 3$.

التمرين الثالث (5 نقاط) — متتالية هندسية ذات أساس $e$

السؤال 1) 1.5 نقطة

أ) الطبيعة الهندسية:
$$\frac{u_{n+1}}{u_n} = \frac{e^{2(n+1)}}{e^{2n}} = e^2$$

إذن $(u_n)$ متتالية هندسية أساسها $q = e^2$.

ب) الحدود:
- $u_0 = e^0 = 1$
- $u_1 = e^2 \approx 7,39$
- $u_2 = e^4 \approx 54,6$

السؤال 2) 1 نقطة

مجموع المتتالية الهندسية:
$$S_n = u_0 \cdot \frac{1 - q^{n+1}}{1 - q} = \frac{1 - (e^2)^{n+1}}{1 - e^2} = \frac{1 - e^{2(n+1)}}{1 - e^2} = \frac{e^{2(n+1)} - 1}{e^2 - 1}$$

(نستعمل $1 - e^2 = -(e^2 - 1)$ لتبسيط الإشارة.)

السؤال 3) 0.75 نقطة

النهاية:
- $e^{2(n+1)} \to +\infty$ (الأسية تتفوق)
- إذن $S_n \to +\infty$

النتيجة: $\lim S_n = +\infty$ (المجموع متشعّب).

السؤال 4) 1 نقطة

الحساب:
$$v_n = \ln u_n = \ln e^{2n} = 2n$$

النتيجة: $v_n = 2n$, إذن $(v_n)$ متتالية حسابية أساسها $r = v_{n+1} - v_n = 2$ و حدّها الأول $v_0 = 0$.

السؤال 5) 0.75 نقطة

مجموع المتتالية الحسابية:
$$\sum_{k=0}^n v_k = \frac{(n + 1)(v_0 + v_n)}{2} = \frac{(n + 1)(0 + 2n)}{2} = n(n + 1)$$

النتيجة: $\sum_{k=0}^n v_k = n(n + 1)$.

التمرين الرابع (5 نقاط) — تكاليل الدالة الأسية

السؤال 1) 0.75 نقطة

الحساب:
$$\int_0^1 e^{2x}\, dx = \left[\frac{e^{2x}}{2}\right]_0^1 = \frac{e^2 - e^0}{2} = \frac{e^2 - 1}{2}$$

النتيجة: $\frac{e^2 - 1}{2}$.

السؤال 2) 1.25 نقطة

التكامل بالتجزئة:
- $u = x$, $v' = e^x$
- $u' = 1$, $v = e^x$

$$\int_0^1 x e^x\, dx = [x e^x]_0^1 - \int_0^1 e^x\, dx = (e - 0) - (e - 1) = 1$$

النتيجة: $1$.

السؤال 3) 1.5 نقطة

التكامل بالتجزئة (مرة 1):
- $u = x^2$, $v' = e^x$
- $\int x^2 e^x\, dx = x^2 e^x - \int 2x e^x\, dx = x^2 e^x - 2 \int x e^x\, dx$

استعمال النتيجة السابقة:
$$\int_0^1 x^2 e^x\, dx = [x^2 e^x]_0^1 - 2 \int_0^1 x e^x\, dx = e - 0 - 2 \cdot 1 = e - 2$$

النتيجة: $e - 2 \approx 0,718$.

السؤال 4) 1 نقطة

تغيير المتغير:
- $u = 1 + e^x$, $du = e^x\, dx$
- عند $x = 0$: $u = 2$
- عند $x = \ln 2$: $u = 1 + 2 = 3$

$$\int_0^{\ln 2} \frac{e^x}{1 + e^x}\, dx = \int_2^3 \frac{1}{u}\, du = [\ln u]_2^3 = \ln 3 - \ln 2 = \ln\frac{3}{2}$$

النتيجة: $\ln\frac{3}{2}$.

السؤال 5) 0.5 نقطة

تغيير المتغير:
- $u = -x^2$, $du = -2x\, dx$
- $x\, dx = -\frac{du}{2}$
- عند $x = 0$: $u = 0$
- عند $x = 1$: $u = -1$

$$\int_0^1 x e^{-x^2}\, dx = -\frac{1}{2}\int_0^{-1} e^u\, du = \frac{1}{2}\int_{-1}^0 e^u\, du = \frac{1}{2}[e^u]_{-1}^0 = \frac{1}{2}(1 - e^{-1}) = \frac{e - 1}{2e}$$

النتيجة: $\frac{e - 1}{2e}$.
