التمرين الأول (5 نقاط) — دراسة دالة + مقارب مائل

السؤال 1) 1 نقطة

عند $1^+$: $\frac{2}{0^+} = +\infty$, إذن $f \to +\infty$.
عند $1^-$: $\frac{2}{0^-} = -\infty$, إذن $f \to -\infty$.
عند $\pm\infty$: $\frac{2}{x - 1} \to 0$, إذن $f \sim x + 1 \to \pm\infty$.

السؤال 2) 0.5 نقطة

المقاربات:
- $x = 1$ مقارب عمودي (نهايتان لا نهائيتان متعاكستان)
- $y = x + 1$ مقارب مائل (لأن $\lim f(x) - (x + 1) = \lim 2/(x-1) = 0$ عند $\pm\infty$)

السؤال 3) 1.5 نقطة

الاشتقاق:
$$f'(x) = 1 - \frac{2}{(x - 1)^2} = \frac{(x - 1)^2 - 2}{(x - 1)^2} = \frac{x^2 - 2x - 1}{(x - 1)^2}$$

الجذور: $x^2 - 2x - 1 = 0 \Rightarrow x = 1 \pm \sqrt{2}$
- $\alpha_1 = 1 - \sqrt{2} \approx -0,41$
- $\alpha_2 = 1 + \sqrt{2} \approx 2,41$

إشارة $f'$: موجبة على $(-\infty, \alpha_1) \cup (\alpha_2, +\infty)$, سالبة على $(\alpha_1, 1) \cup (1, \alpha_2)$.

جدول التغيّرات: $f$ تزايد ثم تناقص ثم تزايد على فروعها.

السؤال 4) 1 نقطة

الوضع النسبي:
$$f(x) - (x + 1) = \frac{2}{x - 1}$$

عند $+\infty$:
- $\frac{2}{x - 1} > 0$ (لأن $x > 1$) → $(\mathcal{C})$ فوق المقارب
- لا يمكن رؤيته عند $-\infty$ بسهولة لأن $x < 1$ → سالب → $(\mathcal{C})$ تحت

السؤال 5) 1 نقطة

الطريقة: نتحقق أنّ $\Omega(1, 2)$ مركز تناظر.

$$\frac{f(1 + h) + f(1 - h)}{2} = \frac{1 + h + 1 + \frac{2}{h} + 1 - h + 1 + \frac{2}{-h}}{2} = \frac{4}{2} = 2$$ ✓

إذن $\Omega(1, 2)$ مركز تناظر (وهي تقاطع المقاربتين).

التمرين الثاني (5 نقاط) — متتالية + برهنة بالتراجع

السؤال 1) 0.75 نقطة

الحسابات:
- $u_1 = \frac{3 \cdot 3 + 2}{3 + 3} = \frac{11}{6}$
- $u_2 = \frac{3 \cdot 11/6 + 2}{11/6 + 3} = \frac{33/6 + 12/6}{11/6 + 18/6} = \frac{45/6}{29/6} = \frac{45}{29}$
- $u_3 = \frac{3 \cdot 45/29 + 2}{45/29 + 3} = \frac{135/29 + 58/29}{45/29 + 87/29} = \frac{193/29}{132/29} = \frac{193}{132}$

السؤال 2) 1 نقطة

التهيئة: $u_0 = 3 \not< 1$.

ملاحظة: القيمة الأولية لا تنطبق. لِنُعدّل: $u_0 = 1/2$.
- $u_0 = 1/2 \in (0, 1)$ ✓

الفرضية: $0 < u_n < 1$.

النتيجة: $u_{n+1} = \frac{3u_n + 2}{u_n + 3}$. نتحقق:
- إيجابية: $u_n > 0 \Rightarrow 3u_n + 2 > 0$ و $u_n + 3 > 0$, إذن $u_{n+1} > 0$ ✓
- $u_{n+1} < 1 \iff 3u_n + 2 < u_n + 3 \iff 2u_n < 1 \iff u_n < 1/2$

ملاحظة: الشرط $u_n < 1/2$ أقوى من $u_n < 1$, لا يكفي. نُصحّح: $0 < u_n \leq 1$.

بالأحرى, النتيجة هي $0 < u_n \leq 1$ (نضعف الشرط):
- $u_{n+1} \leq 1 \iff 3u_n + 2 \leq u_n + 3 \iff 2u_n \leq 1 \iff u_n \leq 1/2$

ملاحظة: $u_0 = 3$, $u_1 = 11/6 \approx 1.83$, $u_2 = 45/29 \approx 1.55$, $u_3 = 193/132 \approx 1.46$. المتتالية تقترب من 1 من فوق.

لِنُعدّل السؤال: برهن أنّ $1 < u_n \leq 3$.

التهيئة: $u_0 = 3 \in (1, 3]$ ✓.

الفرضية: $1 < u_n \leq 3$.

النتيجة:
- $u_{n+1} > 1 \iff 3u_n + 2 > u_n + 3 \iff 2u_n > 1 \iff u_n > 1/2$ ✓
- $u_{n+1} \leq 3 \iff 3u_n + 2 \leq 3(u_n + 3) \iff 2 \leq 9$ ✓

إذن $1 < u_{n+1} \leq 3$ ✓.

الخلاصة: بالتراجع, $1 < u_n \leq 3$ لكل $n$.

السؤال 3) 1 نقطة

الحساب:
$$u_{n+1} - u_n = \frac{3u_n + 2 - u_n(u_n + 3)}{u_n + 3} = \frac{3u_n + 2 - u_n^2 - 3u_n}{u_n + 3} = \frac{2 - u_n^2}{u_n + 3} = \frac{(\sqrt{2} - u_n)(\sqrt{2} + u_n)}{u_n + 3}$$

بما أن $1 < u_n \leq 3$:
- $u_n + 3 > 0$
- $\sqrt{2} + u_n > 0$
- $\sqrt{2} \approx 1.41$, إذن $\sqrt{2} - u_n < 0$ (لأن $u_n > 1$)

إذن $u_{n+1} - u_n < 0$, $(u_n)$ متناقصة.

السؤال 4) 1 نقطة

التقارب:
- متناقصة + محدودة سفلًا بـ 1 → متقاربة

حساب $\ell$:
$$\ell = \frac{3\ell + 2}{\ell + 3} \Rightarrow \ell(\ell + 3) = 3\ell + 2 \Rightarrow \ell^2 = 2 \Rightarrow \ell = \sqrt{2}$$

(نختار الموجب لأن $u_n > 1 > 0$.)

السؤال 5) 1.25 نقطة

الحساب:
$$v_{n+1} = \frac{u_{n+1} - 1}{u_{n+1} + 1} = \frac{\frac{3u_n + 2}{u_n + 3} - 1}{\frac{3u_n + 2}{u_n + 3} + 1} = \frac{3u_n + 2 - (u_n + 3)}{3u_n + 2 + (u_n + 3)} = \frac{2u_n - 1}{4u_n + 5}$$

ملاحظة: النتيجة ليست بالضرورة $v_n \cdot q$. نتحقق:
$$\frac{v_{n+1}}{v_n} = \frac{\frac{2u_n - 1}{4u_n + 5}}{\frac{u_n - 1}{u_n + 1}} = \frac{(2u_n - 1)(u_n + 1)}{(4u_n + 5)(u_n - 1)}$$

لِنعدّل بوضع $w_n = \frac{u_n - \sqrt{2}}{u_n + \sqrt{2}}$.

بما أن $\ell = \sqrt{2}$, نأخذ $w_n = \frac{u_n - \ell}{u_n + \ell}$:
$$w_{n+1} = \frac{u_{n+1} - \sqrt{2}}{u_{n+1} + \sqrt{2}} = \frac{\frac{3u_n + 2}{u_n + 3} - \sqrt{2}}{\frac{3u_n + 2}{u_n + 3} + \sqrt{2}} = \frac{3u_n + 2 - \sqrt{2}(u_n + 3)}{3u_n + 2 + \sqrt{2}(u_n + 3)}$$

نستعمل $\sqrt{2}^2 = 2$:
$$= \frac{(3 - \sqrt{2})u_n + (2 - 3\sqrt{2})}{(3 + \sqrt{2})u_n + (2 + 3\sqrt{2})}$$

هذا معقد. نحاول بالقسمة:
إذا قسم $u_{n+1} - \sqrt{2}$ على $u_n - \sqrt{2}$:
$$u_{n+1} - \sqrt{2} = \frac{3u_n + 2 - \sqrt{2}(u_n + 3)}{u_n + 3} = \frac{(3 - \sqrt{2})u_n + 2 - 3\sqrt{2}}{u_n + 3}$$
$$= \frac{(3 - \sqrt{2})(u_n - \sqrt{2}) + (3 - \sqrt{2})\sqrt{2} + 2 - 3\sqrt{2}}{u_n + 3}$$
$$= \frac{(3 - \sqrt{2})(u_n - \sqrt{2}) + 3\sqrt{2} - 2 + 2 - 3\sqrt{2}}{u_n + 3} = \frac{(3 - \sqrt{2})(u_n - \sqrt{2})}{u_n + 3}$$

$$\frac{u_{n+1} - \sqrt{2}}{u_n - \sqrt{2}} = \frac{3 - \sqrt{2}}{u_n + 3}$$

بالمثل: $\frac{u_{n+1} + \sqrt{2}}{u_n + \sqrt{2}} = \frac{3 + \sqrt{2}}{u_n + 3}$

إذن:
$$\frac{w_{n+1}}{w_n} = \frac{\frac{u_{n+1} - \sqrt{2}}{u_{n+1} + \sqrt{2}}}{\frac{u_n - \sqrt{2}}{u_n + \sqrt{2}}} = \frac{u_{n+1} - \sqrt{2}}{u_n - \sqrt{2}} \cdot \frac{u_n + \sqrt{2}}{u_{n+1} + \sqrt{2}} = \frac{3 - \sqrt{2}}{3 + \sqrt{2}}$$

نسبط: $\frac{3 - \sqrt{2}}{3 + \sqrt{2}} = \frac{(3 - \sqrt{2})^2}{9 - 2} = \frac{9 - 6\sqrt{2} + 2}{7} = \frac{11 - 6\sqrt{2}}{7} \approx 0,359$

إذن $(w_n)$ هندسية أساسها $q = \frac{3 - \sqrt{2}}{3 + \sqrt{2}} \approx 0,359$.

التمرين الثالث (5 نقاط) — نهايات مركبة + نهايات شهيرة

السؤال 1) 1.25 نقطة

استعمال تaylor:
$$\sin x = x - \frac{x^3}{6} + O(x^5)$$

$$\sin x - x = -\frac{x^3}{6} + O(x^5)$$

$$\frac{\sin x - x}{x^3} = -\frac{1}{6} + O(x^2) \to -\frac{1}{6}$$

النتيجة: $\lim_{x \to 0} \frac{\sin x - x}{x^3} = -\frac{1}{6}$.

السؤال 2) 1 نقطة

التحويل:
$$\left(1 + \frac{1}{n}\right)^{2n+1} = \left(1 + \frac{1}{n}\right)^{2n} \cdot \left(1 + \frac{1}{n}\right) = \left[\left(1 + \frac{1}{n}\right)^n\right]^2 \cdot \left(1 + \frac{1}{n}\right)$$

النهايات:
- $\left(1 + \frac{1}{n}\right)^n \to e$
- $\left(1 + \frac{1}{n}\right) \to 1$

النتيجة: $\lim = e^2 \cdot 1 = e^2$.

السؤال 3) 1.25 نقطة

الفكرة: نستعمل عدم المساواة $k! \leq \left(\frac{k+1}{2}\right)^k$ أو مقارنة مباشرة.

نلاحظ:
$$\frac{n!}{n^n} = \frac{1 \cdot 2 \cdot 3 \cdots n}{n \cdot n \cdot n \cdots n} = \prod_{k=1}^n \frac{k}{n}$$

كل حد $\frac{k}{n} \leq 1$, و الحد الأول $\frac{1}{n} \to 0$.

بالأحرى, استعمال ستيرلينغ:
$$n! \sim \sqrt{2\pi n} \left(\frac{n}{e}\right)^n$$

$$\frac{n!}{n^n} \sim \sqrt{2\pi n} \cdot \frac{1}{e^n} \to 0$$

النتيجة: $\lim = 0$ (بسرعة كبيرة).

السؤال 4) 0.75 نقطة

بالضرب بالمرافق:
$$\sqrt{x^2 + 3x} - x = \frac{(\sqrt{x^2 + 3x} - x)(\sqrt{x^2 + 3x} + x)}{\sqrt{x^2 + 3x} + x}$$
$$= \frac{3x}{\sqrt{x^2 + 3x} + x}$$

نقسم على $x$:
$$= \frac{3}{\sqrt{1 + 3/x} + 1} \to \frac{3}{1 + 1} = \frac{3}{2}$$

النتيجة: $\lim = \frac{3}{2}$.

السؤال 5) 0.75 نقطة

التحويل:
$$1 - \cos x = 2 \sin^2\left(\frac{x}{2}\right)$$

$$\frac{1 - \cos x}{x^2} = \frac{2 \sin^2(x/2)}{x^2} = \frac{2}{4} \cdot \left(\frac{\sin(x/2)}{x/2}\right)^2 = \frac{1}{2} \cdot 1^2 = \frac{1}{2}$$

(استعملنا $\lim \frac{\sin t}{t} = 1$.)

التمرين الرابع (5 نقاط) — احتمالات + توزيع ذي الحدين

السؤال 1) 1 نقطة

الحساب:
- عدد السحوبات: $\binom{10}{3} = 120$
- عدد السحوبات المواتية: $\binom{4}{3} = 4$
- $P(3 \text{حمراء}) = \frac{4}{120} = \frac{1}{30}$

السؤال 2) 1 نقطة

بالحادثة المضادة:
$$P(\geq 1 \text{حمراء}) = 1 - P(0 \text{حمراء}) = 1 - \frac{\binom{6}{3}}{\binom{10}{3}} = 1 - \frac{20}{120} = 1 - \frac{1}{6} = \frac{5}{6}$$

السؤال 3) 1.75 نقطة

أ) النوع: $X \sim \mathcal{B}(3, 0.4)$ (توزيع ذي الحدين, $n = 3$, $p = 4/10 = 0.4$).

ب) $P(X = 3) = (0.4)^3 = 0.064$.

ج) الأمل والتباين:
- $E(X) = np = 3 \cdot 0.4 = 1.2$
- $V(X) = np(1-p) = 3 \cdot 0.4 \cdot 0.6 = 0.72$

السؤال 4) 0.75 نقطة

الحساب:
$$P(X \geq 2) = P(X = 2) + P(X = 3)$$
$$= \binom{3}{2}(0.4)^2(0.6) + (0.4)^3$$
$$= 3 \cdot 0.096 + 0.064 = 0.288 + 0.064 = 0.352$$

النتيجة: $P(X \geq 2) = 0.352$.

السؤال 5) 0.5 نقطة

الصيغة:
$$P(X = 2 | X \geq 1) = \frac{P(X = 2)}{P(X \geq 1)} = \frac{0.288}{1 - P(X = 0)} = \frac{0.288}{1 - (0.6)^3} = \frac{0.288}{1 - 0.216} = \frac{0.288}{0.784} \approx 0.367$$

أي حوالي $36,7\%$.
