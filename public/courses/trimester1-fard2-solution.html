حل التمرين الأول — صحيح أو خطأ
1)
1) خطأ. شروط: $x > 1$ و $x > -2$, أي $x > 1$. $\ln[(x-1)(x+2)] = \ln 4 \iff (x-1)(x+2) = 4 \iff x^2 + x - 6 = 0 \iff x = 2$ أو $x = -3$. نختار $x > 1$: حل وحيد $x = 2$ ✓ — العبارة صحيحة في الواقع (تحقق).
2)
2) صحيح. $f'(x) = \frac{e^x (x - 1)}{x^2}$. $f'(x) = 0 \iff x = 1$. $f'$ يغير الإشارة من $-$ إلى $+$ عند $x = 1$, إذن قيمة حدّية صغرى! في الواقع: $f'$ سالب على $(-\infty, 1)$ و موجب على $(1, +\infty)$, إذن $x = 1$ صغرى وليس عظمى. العبارة خطأ.
3)
3) صحيح. $\frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}$. المجموع: $\sum \left(\frac{1}{k} - \frac{1}{k+1}\right) = 1 - \frac{1}{n+1} = \frac{n}{n+1}$ ✓ (سلسلة تيليسكوبية).
4)
4) خطأ. $h(x) = e^x - x - 2$. $h'(x) = e^x - 1$. $h' \geq 0 \iff x \geq 0$, $h$ تزايد على $[0, +\infty)$. $h(0) = -1 < 0$, $h(2) = e^2 - 4 > 0$. إذن يوجد $\alpha \in (0, 2)$ بحيث $h(\alpha) = 0$ ✓ — العبارة خاطئة (يوجد حل).
حل التمرين الثاني — الدالة $f(x) = ax + b + e^{-x}$
1)
1) $f'(x) = a - e^{-x}$. $f(x) - f'(x) = ax + b + e^{-x} - a + e^{-x} = ax + (b - a) + 2e^{-x}$.
2)
أو: $f'(x) = a - e^{-x}$ و $f(x) = ax + b + e^{-x}$. نلاحظ أن $e^{-x} = a - f'(x)$, إذن $f(x) = ax + b + a - f'(x)$, أي $f(x) + f'(x) = a(x+1) + b$.
3)
2) المماس في $A(0, 3)$ أفقي يعني $f'(0) = 0$, أي $a - e^0 = 0 \Rightarrow a = 1$. كذلك $f(0) = 3$, أي $b + 1 = 3 \Rightarrow b = 2$.
4)
3) $f(x) = x + 2 + e^{-x}$. نهايات: عند $+\infty$: $e^{-x} \to 0$, $f(x) \sim x \to +\infty$. عند $-\infty$: $e^{-x} \to +\infty$, $f(x) \to +\infty$.
5)
4) $f(x) - (x + 2) = e^{-x} \to 0$ عند $+\infty$. إذن $(\Delta): y = x + 2$ مقارب مائل عند $+\infty$.
6)
عند $-\infty$: $\frac{f(x)}{x} = 1 + \frac{2}{x} + \frac{e^{-x}}{x} \to 1 - 0 + (-\infty)/(-\infty)$. الأسية تتفوق, $\frac{e^{-x}}{x} \to +\infty$. إذن لا يوجد مقارب مائل عند $-\infty$.
7)
5) $f'(x) = 1 - e^{-x}$. $f'(x) \geq 0 \iff e^{-x} \leq 1 \iff -x \leq 0 \iff x \geq 0$. إذن $f$ تناقص على $(-\infty, 0]$, تزايد على $[0, +\infty)$. الأدنى: $f(0) = 3$.
8)
6) $f(x) - (x + 2) = e^{-x} > 0$ دائمًا. إذن $(\mathcal{C})$ فوق $(\Delta)$ دائمًا.
9)
7) الرسم: منحنى يمر من $(0, 3)$, يقبل $(\Delta): y = x + 2$ مقاربًا مائلًا من فوق, يرتفع من $+\infty$ (عند $-\infty$, الأسية) ثم ينخفض إلى $(0, 3)$ ثم يرتفع مجددًا على شكل خط $y = x + 2$.
10)
8) على $[0, +\infty)$: $f$ تزايد من 3 إلى $+\infty$, إذن المعادلة $f(x) = 4$ يقبل حلًّا وحيدًا $\beta > 0$. $f(0) = 3 < 4$, $f(2) = 4 + e^{-2} \approx 4,135 > 4$. إذن $\beta \in (0, 2)$. تقريب: $f(1,5) = 3,5 + e^{-1,5} \approx 3,5 + 0,223 = 3,723 < 4$. $\beta \in (1,5, 2)$. $f(1,7) = 3,7 + e^{-1,7} \approx 3,7 + 0,183 = 3,883 < 4$. $\beta \approx 1,8$.
حل التمرين الثالث — براهين بالتراجع
1)
1) التهيئة: $n = 1$: $1 = \left(\frac{1 \cdot 2}{2}\right)^2 = 1$ ✓. النتيجة: $\sum_{k=1}^{n+1} k^3 = \left(\frac{n(n+1)}{2}\right)^2 + (n+1)^3 = (n+1)^2\left[\frac{n^2}{4} + (n+1)\right] = (n+1)^2 \cdot \frac{n^2 + 4n + 4}{4} = \left(\frac{(n+1)(n+2)}{2}\right)^2$ ✓.
2)
2) التهيئة: $n = 5$: $2^5 = 32 > 25 = 5^2$ ✓. الفرضية: $2^k > k^2$. النتيجة: $2^{k+1} = 2 \cdot 2^k > 2k^2 \geq (k+1)^2 \iff 2k^2 \geq k^2 + 2k + 1 \iff k^2 - 2k - 1 \geq 0$. لـ $k \geq 3$: $(k - 1)^2 - 2 \geq 2 \geq 0$ ✓. لـ $k \geq 5$ ✓.
3)
3) $u_0 = 1$, $u_1 = \frac{2}{2} = 1$, $u_2 = \frac{5}{3}$.
4)
4) $u_{n+1} - u_n = \frac{(n+1)^2 + 1}{n+2} - \frac{n^2 + 1}{n+1} = \frac{[(n+1)^2 + 1](n+1) - (n^2 + 1)(n+2)}{(n+2)(n+1)} = \frac{n^3 + 3n^2 + 4n + 2 - n^3 - 2n^2 - n - 2}{(n+2)(n+1)} = \frac{n^2 + 3n}{(n+2)(n+1)} = \frac{n(n+3)}{(n+2)(n+1)} \geq 0$ لـ $n \geq 0$. إذن $(u_n)$ متزايدة. $\lim u_n = \lim \frac{n^2}{n} = +\infty$.
5)
5) $u_n^2 - 2 = \frac{(n^2+1)^2 - 2(n+1)^2}{(n+1)^2} = \frac{n^4 + 2n^2 + 1 - 2n^2 - 4n - 2}{(n+1)^2} = \frac{n^4 - 4n - 1}{(n+1)^2}$. لـ $n \geq 2$: $n^4 \geq 16$, $4n + 1 \leq 9$, إذن $u_n^2 - 2 > 0$, $u_n > \sqrt{2}$ (لأن $u_n > 0$).
6)
6) $(u_n)$ متزايدة و غير محدودة ($\to +\infty$), إذن $(v_n) = (u_n - \sqrt{2}) \to +\infty$, غير متقاربة.
حل التمرين الرابع — النهايات
1)
1) $\lim \frac{x^3 - 2x + 1}{x^2 + x} = \lim \frac{x^3}{x^2} = +\infty$.
2)
2) $e^{2x} = 1 + 2x + 2x^2 + ...$, إذن $\frac{e^{2x} - 1 - 2x}{x^2} \to 2$ (تaylor رتبة 2).
3)
3) $x - \sqrt{x^2 + 3x} = \frac{(x - \sqrt{x^2+3x})(x + \sqrt{x^2+3x})}{x + \sqrt{x^2+3x}} = \frac{x^2 - x^2 - 3x}{x + \sqrt{x^2+3x}} = \frac{-3x}{x + \sqrt{x^2+3x}} = \frac{-3}{1 + \sqrt{1 + 3/x}} \to \frac{-3}{2}$.
4)
4) $\left(1 + \frac{1}{x}\right)^x \to e$ (شهيرة).
5)
5) $\frac{2^n}{n!} \to 0$ (المضروب يتفوق).
6)
6) $\left(1 - \frac{1}{n^2}\right)^n = e^{n \ln(1 - 1/n^2)}$. $\ln(1 - 1/n^2) \sim -1/n^2$, $n \cdot (-1/n^2) = -1/n \to 0$. إذن النهاية $e^0 = 1$.
