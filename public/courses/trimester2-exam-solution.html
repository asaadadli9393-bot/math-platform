حل التمرين الأول — صحيح أو خطأ
1)
1) صحيح. $f(-x) = \ln(x^2 + 1) = f(x)$ ✓ (لأن $(-x)^2 = x^2$).
2)
2) صحيح. $X = e^x$: $X^2 - 4X + 4 = (X - 2)^2 = 0 \Rightarrow X = 2$ (جذر مزدوج). $x = \ln 2$ حل وحيد ✓.
3)
3) صحيح. $|u_n| = \frac{1}{n+1} \to 0$, إذن $u_n \to 0$.
4)
4) صحيح. $h(x) = \ln x - x + 1$. $h(1) = 0 - 1 + 1 = 0$. $h'(x) = 1/x - 1 \geq 0 \iff x \leq 1$. $h$ تزايد على $(0, 1]$, تناقص على $[1, +\infty)$. الأقصى = 0 عند $x = 1$, إذن $h(x) \leq 0$, $\ln x \leq x - 1$ ✓.
حل التمرين الثاني — الدالة $f(x) = x \ln x - x$
1)
1) عند $0^+$: $x \ln x \to 0$ (شهيرة), إذن $f(x) \to 0$. عند $+\infty$: $x(\ln x - 1) \to +\infty$ (لأن $\ln x \to +\infty$).
2)
2) $f'(x) = \ln x + x \cdot \frac{1}{x} - 1 = \ln x$. إشارة: $f'(x) \geq 0 \iff x \geq e$.
3)
3) $f$ تناقص على $(0, e]$, تزايد على $[e, +\infty)$. الأدنى: $f(e) = e \cdot 1 - e = 0$.
4)
4) $\int_1^e x \ln x\, dx$ (بالتجزئة): $u = \ln x$, $v' = x$. $= [\frac{x^2}{2} \ln x]_1^e - \int_1^e \frac{x^2}{2} \cdot \frac{1}{x}\, dx = \frac{e^2}{2} - \frac{1}{2} \int_1^e x\, dx = \frac{e^2}{2} - \frac{e^2 - 1}{4} = \frac{2e^2 - e^2 + 1}{4} = \frac{e^2 + 1}{4}$.
5)
$\int_1^e x\, dx = \frac{e^2 - 1}{2}$.
6)
$\int_1^e f(x)\, dx = \frac{e^2 + 1}{4} - \frac{e^2 - 1}{2} = \frac{e^2 + 1 - 2e^2 + 2}{4} = \frac{3 - e^2}{4}$.
7)
5) الأدنى المطلق: $f(e) = 0 > -1$. إذن $f(x) \geq 0 > -1$ ✓. المساواة $f(x) = -1$ لا تتحقق (الأدنى 0). لكن السؤال يطلب $f(x) \geq -1$: صحيح دائمًا. المساواة لا تتحقق.
8)
ملاحظة: السؤال يحتاج تصحيحًا. الأدنى هو 0 وليس -1.
9)
6) $u_n = f(1 + 1/n) = (1 + 1/n)\ln(1 + 1/n) - (1 + 1/n) \to 1 \cdot 0 - 1 = -1$. إذن $\lim u_n = -1$.
10)
7) $f(x) = 0 \iff x \ln x - x = 0 \iff x(\ln x - 1) = 0$. على $(0, +\infty)$: $x \neq 0$, إذن $\ln x = 1 \iff x = e$. حل وحيد $x = e$. (ملاحظة: حل وحيد وليس حلّان.)
11)
8) $g(x) = f(x) + 1 \geq 0 + 1 = 1 > 0$ (لأن $f(x) \geq 0$). ✓
حل التمرين الثالث — الأعداد المركبة
1)
1) $|z| = \sqrt{1 + 1} = \sqrt{2}$. $\arg(z) = \arctan(-1) = -\pi/4$.
2)
2) $z = \sqrt{2} e^{-i\pi/4}$.
3)
3) $z^8 = (\sqrt{2})^8 e^{-i 8\pi/4} = 16 e^{-i 2\pi} = 16 \cdot 1 = 16$.
4)
4) $z^2 = -8i = 8 e^{-i\pi/2}$. الحلول: $z = \sqrt{8} e^{i(-\pi/4 + k\pi)}$ لـ $k \in \mathbb{Z}$. $z_1 = 2\sqrt{2} e^{-i\pi/4} = 2 - 2i$, $z_2 = 2\sqrt{2} e^{i3\pi/4} = -2 + 2i$.
5)
5) $Z = z^2 = (1 - i)^2 = 1 - 2i + i^2 = -2i$.
6)
6) $\bar Z = 2i$. $Z \bar Z = (-2i)(2i) = -4i^2 = 4$ ✓.
7)
7) $A(1, -1)$, $B(0, -2)$. $AB = \sqrt{1 + 1} = \sqrt{2}$.
8)
8) $\vec{OA}(1, -1)$ و $\vec{OB}(0, -2)$. $\vec{OA} \cdot \vec{OB} = 0 + 2 = 2 \neq 0$. المثلث ليس قائمًا في $O$! [ملاحظة: السؤال به خطأ — لكن $|\vec{OA}| = \sqrt{2}$ و $|\vec{OB}| = 2$ و $AB = \sqrt{2}$. لا قائمة.]
9)
ملاحظة: ربما السؤال يقصد المثلث قائم في $A$ أو $B$. $\vec{AO}(-1, 1)$ و $\vec{AB}(-1, -1)$. $\vec{AO} \cdot \vec{AB} = 1 - 1 = 0$ ✓. إذن المثلث قائم في $A$.

حل التمرين الخامس — المتتالية العودية
1)
1) $u_0 = 1$, $u_1 = \sqrt{3} \approx 1,73$, $u_2 = \sqrt{\sqrt{3} + 2} \approx 1,93$, $u_3 \approx 1,97$.
2)
2) التهيئة: $0 < u_0 = 1 < 2$ ✓. الفرضية: $0 < u_n < 2$. النتيجة: $u_{n+1} = \sqrt{u_n + 2} \in (\sqrt{2}, 2) \subset (0, 2)$ ✓ (لأن $u_n + 2 \in (2, 4)$).
3)
3) $u_{n+1} - u_n = \sqrt{u_n + 2} - u_n$. الإشارة: $\sqrt{u_n + 2} \geq u_n \iff u_n + 2 \geq u_n^2 \iff u_n^2 - u_n - 2 \leq 0 \iff (u_n - 2)(u_n + 1) \leq 0 \iff u_n \in [-1, 2]$. بما أن $u_n \in (0, 2)$, $u_{n+1} \geq u_n$. $(u_n)$ متزايدة.
4)
محدودة علويًا بـ 2, متقاربة. $\ell = \sqrt{\ell + 2} \Rightarrow \ell^2 = \ell + 2 \Rightarrow \ell = 2$ (نختار الموجب).
5)
4) $v_{n+1} = u_{n+1} - 2 = \sqrt{u_n + 2} - 2 = \frac{u_n + 2 - 4}{\sqrt{u_n + 2} + 2} = \frac{u_n - 2}{\sqrt{u_n + 2} + 2} = \frac{v_n}{\sqrt{u_n + 2} + 2}$.
6)
5) $|v_{n+1}| = \frac{|v_n|}{\sqrt{u_n + 2} + 2}$. بما أن $u_n > 0$, $\sqrt{u_n + 2} > \sqrt{2}$, إذن $\sqrt{u_n + 2} + 2 > 2 + \sqrt{2} > 2$. إذن $|v_{n+1}| < \frac{|v_n|}{2}$. بالتكرار: $|v_n| < \frac{|v_0|}{2^n} = \frac{1}{2^n} \to 0$. إذن $\lim v_n = 0$.
7)
6) $\frac{u_n - \ell}{u_{n-1} - \ell} = \frac{v_n}{v_{n-1}} = \frac{1}{\sqrt{u_{n-1} + 2} + 2} \to \frac{1}{\sqrt{2 + 2} + 2} = \frac{1}{4}$.
