حل التمرين 1 — دالة $f(x) = e^x \sin x$
1)
1) $f(-x) = e^{-x} \sin(-x) = -e^{-x} \sin x \neq \pm f(x)$ (إلا إذا $e^{-x} = e^x$, أي $x = 0$). إذن $f$ ليست زوجية و لا فردية.
2)
2) $f'(x) = e^x \sin x + e^x \cos x = e^x (\sin x + \cos x)$.
3)
$f''(x) = e^x(\sin x + \cos x) + e^x(\cos x - \sin x) = 2 e^x \cos x$.
4)
3) $f'' - 2f' + 2f = 2e^x \cos x - 2e^x(\sin x + \cos x) + 2e^x \sin x = 2e^x(\cos x - \sin x - \cos x + \sin x) = 0$ ✓.
5)
4) المعادلة المميزة: $r^2 + 4r + 4 = 0 \Rightarrow (r+2)^2 = 0 \Rightarrow r = -2$ (جذر مزدوج).
6)
الحل العام: $y = (Ax + B) e^{-2x}$ حيث $A, B$ ثوابت.
7)
5) $g'(x) = e^x \cos x - e^x \sin x = e^x(\cos x - \sin x)$. $g''(x) = e^x(\cos x - \sin x) + e^x(-\sin x - \cos x) = -2 e^x \sin x$.
8)
$g'' - 2g' + 2g = -2e^x \sin x - 2e^x(\cos x - \sin x) + 2e^x \cos x = -2e^x \sin x - 2e^x \cos x + 2e^x \sin x + 2e^x \cos x = 0$ ✓.
9)
6) $\int e^x \sin x\, dx = \frac{e^x (\sin x - \cos x)}{2} + C$ (بالتجزئة مرتين).
10)
$\int_0^{\pi/4} e^x \sin x\, dx = \frac{e^x(\sin x - \cos x)}{2}\Big|_0^{\pi/4} = \frac{e^{\pi/4}(\frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2}) - (0 - 1)}{2} = \frac{0 + 1}{2} = \frac{1}{2}$.
11)
7) $\frac{f(x)}{e^x} = \sin x \in [-1, 1]$, إذن النهاية غير موجودة (مهتزة).
12)
ملاحظة: $|\frac{f(x)}{e^x}| \leq 1$, لكن النهاية غير موجودة.
13)
8) $f(x) = 1 \iff e^x \sin x = 1 \iff \sin x = e^{-x}$. على $[0, 2\pi]$: $e^{-x} \in [e^{-2\pi}, 1]$. على $[0, \pi]$: $\sin x \geq 0$, نقطة تقاطع في كل فترة حيث $\sin x$ يزيد ثم ينقص و يلتقي بـ $e^{-x}$ المتناقصة. عدد محدود من الحلول (في الواقع 2 على $[0, 2\pi]$).
حل التمرين 2 — الأعداد المركبة
1)
1) $|z| = \sqrt{3 + 1} = 2$. $\arg(z) = \arctan(-1/\sqrt{3}) = -\pi/6$.
2)
2) $z = 2 e^{-i\pi/6}$.
3)
3) $z^2 = (2 e^{-i\pi/6})^2 = 4 e^{-i\pi/3}$. على الشكل الجبري: $4(\cos(-\pi/3) + i \sin(-\pi/3)) = 4(1/2 - i\sqrt{3}/2) = 2 - 2i\sqrt{3}$.
4)
4) $z^{12} = 2^{12} e^{-i 12\pi/6} = 4096 e^{-i 2\pi} = 4096 \cdot 1 = 4096$.
5)
5) $A(\sqrt{3}; -1)$ في المستوي المركب.
6)
6) $Z = z^2 = 2 - 2i\sqrt{3}$. $\bar Z = 2 + 2i\sqrt{3}$. $Z + \bar Z = 4$. $Z - \bar Z = -4i\sqrt{3}$.
7)
7) $z^2 = -8i = 8 e^{-i\pi/2}$. الحلول: $z = \sqrt{8} e^{i(-\pi/4 + k\pi)}$ لـ $k \in \mathbb{Z}$.
8)
أي: $z_1 = 2\sqrt{2} e^{-i\pi/4} = 2 - 2i$ و $z_2 = 2\sqrt{2} e^{i3\pi/4} = -2 + 2i$.
9)
8) $|z^n| = |z|^n = 2^n$. النقاط تقع على دوائر متحدة المركز، نصف القطر $2^n$. ليست على نفس الدائرة — بل على دوائر مختلفة بنصف قطر $2, 4, 8, 16, 32, 64$.
10)
ملاحظة: السؤال خطأ في صيغته — النقاط ليست على نفس الدائرة.
حل التمرين 3 — تكامل + متتالية + تراجع
1)
1) التهيئة: $n = 1$: $1 = \frac{1 \cdot 2 \cdot 3}{6} = 1$ ✓.
2)
النتيجة: $\sum_{k=1}^{n+1} k^2 = \frac{n(n+1)(2n+1)}{6} + (n+1)^2 = (n+1)\left[\frac{n(2n+1)}{6} + (n+1)\right] = (n+1) \cdot \frac{2n^2 + n + 6n + 6}{6} = \frac{(n+1)(n+2)(2n+3)}{6}$ ✓.
3)
2) $\sum (k^2 + k) = \frac{n(n+1)(2n+1)}{6} + \frac{n(n+1)}{2} = \frac{n(n+1)(2n+1) + 3n(n+1)}{6} = \frac{n(n+1)(2n+4)}{6} = \frac{n(n+1)(n+2)}{3}$.
4)
3) $\int_0^1 x^2(1-x)\, dx = \int_0^1 x^2\, dx - \int_0^1 x^3\, dx = \frac{1}{3} - \frac{1}{4} = \frac{1}{12}$.
5)
4) التهيئة: $n = 0$: $\int_0^1 (1-x)\, dx = \frac{1}{2} = \frac{1}{1 \cdot 2}$ ✓.
6)
النتيجة: بالتجزئة: $\int_0^1 x^n(1-x)\, dx = \frac{x^{n+1}(1-x)}{n+1}\Big|_0^1 + \frac{1}{n+1} \int_0^1 x^{n+1}\, dx = 0 + \frac{1}{(n+1)(n+2)}$ ✓.
7)
5) $I_n = \int_0^{\pi/2} \sin^n x\, dx$. بالتجزئة: $u = \sin^{n-1} x$, $v' = \sin x$. $\int_0^{\pi/2} \sin^n x\, dx = [-\sin^{n-1} x \cos x]_0^{\pi/2} + (n-1) \int_0^{\pi/2} \sin^{n-2} x \cos^2 x\, dx$.
8)
الحد الأول = 0. $\cos^2 = 1 - \sin^2$: $I_n = (n-1)(I_{n-2} - I_n) \Rightarrow n I_n = (n-1) I_{n-2} \Rightarrow I_n = \frac{n-1}{n} I_{n-2}$ ✓.
9)
6) $I_0 = \pi/2$. $I_1 = 1$.
10)
7) $I_2 = \frac{1}{2} I_0 = \pi/4$. $I_4 = \frac{3}{4} I_2 = \frac{3\pi}{16}$.
11)
8) $\sin^n x \leq \sin^{n-1} x$ على $[0, \pi/2]$ (لأن $\sin x \in [0, 1]$), إذن $I_n \leq I_{n-1}$. $(I_n)$ متناقصة و موجبة → متقاربة. $\lim I_n = 0$ (لأن $I_n \leq \sin^n(\pi/4) \cdot \pi/2 \to 0$).
حل التمرين 4 — التوزيع ذو الحدين
1)
1) $X \sim \mathcal{B}(n=5, p=0.6)$. (تجارب بيرنولي مستقلة، احتمال النجاح = 0.6).
2)
2) $P(X = 0) = (0.4)^5 = 0.01024$. $P(X = 5) = (0.6)^5 = 0.07776$.
3)
3) $P(X = 3) = \binom{5}{3}(0.6)^3(0.4)^2 = 10 \cdot 0.216 \cdot 0.16 = 0.3456$.
4)
4) $P(X \geq 3) = P(3) + P(4) + P(5) = 0.3456 + \binom{5}{4}(0.6)^4(0.4) + (0.6)^5 = 0.3456 + 0.2592 + 0.07776 = 0.683$.
5)
5) $E(X) = np = 5 \cdot 0.6 = 3$. $V(X) = np(1-p) = 5 \cdot 0.6 \cdot 0.4 = 1.2$.
6)
6) $P(X \geq 4 | X \geq 3) = \frac{P(X \geq 4)}{P(X \geq 3)} = \frac{P(4) + P(5)}{P(X \geq 3)} = \frac{0.2592 + 0.07776}{0.683} \approx 0.493$.
7)
7) $P(X \geq 1) = 1 - (0.4)^n \geq 0.95 \iff (0.4)^n \leq 0.05 \iff n \ln 0.4 \leq \ln 0.05 \iff n \geq \frac{\ln 0.05}{\ln 0.4} \approx 3.27$. إذن $n_{\min} = 4$.
8)
8) صيغة التوزيع ذي الحدين: لكل $k \in \{0, ..., 5\}$, $P(X = k) = \binom{5}{k} p^k (1-p)^{5-k} = \binom{5}{k} (0.6)^k (0.4)^{5-k}$ ✓.
حل التمرين 5 — مسألة شاملة
1)
1) $x \ln x \to 0$ عند $x \to 0^+$ (شهيرة). إذن $\lim f(x) = 0 - 0 = 0$.
2)
2) $f(x) = x(\ln x - 1)$. عند $+\infty$: $\ln x \to +\infty$, إذن $f(x) \to +\infty \cdot +\infty = +\infty$.
3)
3) $f'(x) = \ln x + x \cdot \frac{1}{x} - 1 = \ln x + 1 - 1 = \ln x$.
4)
$f'(x) \geq 0 \iff \ln x \geq 0 \iff x \geq e$.
5)
4) $f$ تناقص على $(0, e]$, تزايد على $[e, +\infty)$. القيمة الصغرى: $f(e) = e \ln e - e = e - e = 0$. عند $e$: $f = 0$.
6)
5) $\int_1^e (x \ln x - x)\, dx = \int_1^e x \ln x\, dx - \int_1^e x\, dx$.
7)
$\int x \ln x\, dx = \frac{x^2}{2} \ln x - \frac{x^2}{4}$ (بالتجزئة). $\int_1^e x \ln x\, dx = \frac{e^2}{2} - \frac{e^2}{4} - (0 - 1/4) = \frac{e^2}{4} + \frac{1}{4}$.
8)
$\int_1^e x\, dx = \frac{e^2 - 1}{2}$.
9)
إذن $\int_1^e f(x)\, dx = \frac{e^2 + 1}{4} - \frac{e^2 - 1}{2} = \frac{e^2 + 1 - 2e^2 + 2}{4} = \frac{-e^2 + 3}{4} = \frac{3 - e^2}{4}$.
10)
6) $u_n = f(1 + 1/n) = (1 + 1/n)\ln(1 + 1/n) - (1 + 1/n)$. $\lim_{n \to +\infty} u_n = 1 \cdot \ln 1 - 1 = 0 - 1 = -1$.
11)
7) القيمة الصغرى المطلقة لـ $f$ هي $0$ عند $x = e$. إذن $f(x) \geq 0 > -1$ لكل $x$. ملاحظة: المساواة لا تتحقق مع $-1$ (لأن الأدنى هو 0). نُصحّح: $f(x) \geq 0$ لكل $x$, المساواة عند $x = e$.
12)
8) $f$ تزايد على $[e, +\infty)$ و بيقية من $0$ إلى $+\infty$ (لأن $\lim f = +\infty$). إذن تقبل دالة عكسية $f^{-1}: [0, +\infty) \to [e, +\infty)$.
13)
ضمنيًا: $y = x \ln x - x$, حل لـ $x \in [e, +\infty)$.
