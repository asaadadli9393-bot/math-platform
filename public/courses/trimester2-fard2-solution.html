حل التمرين الأول — الدالة $f(x) = (ax + b) e^{-x}$

2) من الشكل الافتراضي: $f(x) \to 0$ عند $+\infty$ (مقارب أفقي $y = 0$) و $f(x) \to +\infty$ أو $-\infty$ عند $-\infty$ (حسب إشارة $a$).

3) المنحنى يمر من $A(0; 2)$: $f(0) = b \cdot e^0 = b = 2$.

المماس في $A$ يمر من $B(1; 3)$. معامل المماس = $\frac{3 - 2}{1 - 0} = 1$. أي $f'(0) = 1$.

$f'(x) = a e^{-x} - (ax + b) e^{-x} = (a - ax - b) e^{-x}$. $f'(0) = a - b = 1 \Rightarrow a = b + 1 = 3$.

4) $f(x) = (3x + 2) e^{-x}$.

5) $f'(x) = (3 - 3x - 2) e^{-x} = (1 - 3x) e^{-x}$. إشارة $e^{-x} > 0$ دائمًا, إذن $f'(x) \geq 0 \iff x \leq 1/3$. $f$ تزايد على $(-\infty, 1/3]$, تناقص على $[1/3, +\infty)$. الأقصى: $f(1/3) = (1 + 2) e^{-1/3} = 3 e^{-1/3} \approx 2,15$.

6) $f(x) - 0 = (3x + 2) e^{-x} \to 0$ عند $+\infty$. $y = 0$ مقارب أفقي. إشارة $f(x)$ = إشارة $3x + 2$: لـ $x > -2/3$, $f > 0$ (فوق), لـ $x < -2/3$, $f < 0$ (تحت).

7) $f(1) = 5 e^{-1} \approx 1,84$, $f'(1) = (1 - 3) e^{-1} = -2/e \approx -0,74$. المماس: $y = -\frac{2}{e}(x - 1) + \frac{5}{e} = -\frac{2x}{e} + \frac{7}{e}$.

8) الرسم: منحنى من $-\infty$ (لأن $3x + 2 \to -\infty$ و $e^{-x} \to +\infty$, المنتج $\to -\infty$) يصعد, يقطع المحور السيني عند $x = -2/3$, يصل القمة $(1/3, 2,15)$, ثم ينزل نحو $y = 0$ من فوق.

حل التمرين الثاني — أعداد مركبة

1) $|z| = \sqrt{3 + 1} = 2$. $\arg(z) = \arctan(-1/\sqrt{3}) = -\pi/6$.

2) $z = 2 e^{-i\pi/6}$.

3) $z^6 = 2^6 e^{-i\pi} = 64 \cdot (-1) = -64$.

4) $OA = |z| = 2$.

5) $z^3 = -8i = 8 e^{-i\pi/2}$. الحلول: $z = 2 e^{i(-\pi/6 + 2k\pi/3)}$ لـ $k = 0, 1, 2$.

$z_0 = 2 e^{-i\pi/6} = \sqrt{3} - i$.

$z_1 = 2 e^{i\pi/2} = 2i$.

$z_2 = 2 e^{i 7\pi/6} = -\sqrt{3} - i$.

6) $Z = z^2 = (\sqrt{3} - i)^2 = 3 - 2i\sqrt{3} + i^2 = 2 - 2i\sqrt{3}$.

7) $|Z| = |z|^2 = 4$, إذن $Z \bar Z = |Z|^2 = 16$ ✓.

8) $\arg(z) + \arg(\bar z) = -\pi/6 + \pi/6 = 0$. ملاحظة: $\arg(\bar z) = -\arg(z)$, إذن المجموع دائمًا 0.

حل التمرين الثالث — احتمالات

1) $X \sim \mathcal{B}(3, 0,4)$ (تجارب بيرنولي مستقلة, $p = 4/10 = 0,4$).

2) $P(X = 0) = (0,6)^3 = 0,216$. $P(X = 3) = (0,4)^3 = 0,064$.

3) $E(X) = np = 3 \cdot 0,4 = 1,2$. $V(X) = np(1-p) = 3 \cdot 0,4 \cdot 0,6 = 0,72$.

4) $P(X \geq 2) = P(2) + P(3) = \binom{3}{2}(0,4)^2(0,6) + 0,064 = 3 \cdot 0,096 \cdot 0,6 + 0,064 = 0,1728 + 0,064 = 0,2368$.

5) صيغة التوزيع ذي الحدين: $P(X = k) = \binom{n}{k} p^k (1-p)^{n-k} = \binom{3}{k}(0,4)^k(0,6)^{3-k}$ ✓.

6) $P(Y \geq 1) = 1 - (0,6)^n \geq 0,95 \iff (0,6)^n \leq 0,05 \iff n \ln 0,6 \leq \ln 0,05 \iff n \geq \frac{\ln 0,05}{\ln 0,6} \approx 6,15$. إذن $n_{\min} = 7$.

7) $P(X = 2 | X \geq 1) = \frac{P(X = 2)}{P(X \geq 1)} = \frac{0,288}{1 - 0,216} = \frac{0,288}{0,784} \approx 0,367$.

8) بدون إعادة: $P(X = 0) = \frac{\binom{6}{3}}{\binom{10}{3}} = \frac{20}{120} = \frac{1}{6} \approx 0,167$.

حل التمرين الرابع — متتالية + تراجع

1) التهيئة: $n = 1$: $\sum_{k=0}^1 q^k = 1 + q = \frac{1 - q^2}{1 - q}$ ✓ (لـ $q \neq 1$).

النتيجة: $\sum_{k=0}^{n+1} q^k = \frac{1 - q^{n+1}}{1 - q} + q^{n+1} = \frac{1 - q^{n+1} + (1-q) q^{n+1}}{1 - q} = \frac{1 - q^{n+2}}{1 - q}$ ✓.

2) $q = 1/2$: $\sum_{k=0}^n \frac{1}{2^k} = \frac{1 - (1/2)^{n+1}}{1/2} = 2\left(1 - \frac{1}{2^{n+1}}\right) \to 2$.

3) $u_1 = \frac{3}{2}$, $u_2 = \frac{5}{4}$, $u_3 = \frac{9}{8}$.

4) التهيئة: $u_0 = 2 \in (1, 2]$ ✓. الفرضية: $1 < u_n \leq 2$. النتيجة: $u_{n+1} = \frac{u_n + 1}{2} \in \left(\frac{2}{2}, \frac{3}{2}\right] = (1, 1,5] \subset (1, 2]$ ✓.

5) $u_{n+1} - u_n = \frac{u_n + 1}{2} - u_n = \frac{1 - u_n}{2} < 0$ (لأن $u_n > 1$). $(u_n)$ متناقصة.

محدودة سفلًا بـ 1, إذن متقاربة. $\ell = \frac{\ell + 1}{2} \Rightarrow \ell = 1$.

6) $v_{n+1} = u_{n+1} - 1 = \frac{u_n + 1}{2} - 1 = \frac{u_n - 1}{2} = \frac{v_n}{2}$. $(v_n)$ هندسية أساسها $1/2$ و $v_0 = 1$. $v_n = (1/2)^n$.

7) $\sum_{k=0}^n v_k = \frac{1 - (1/2)^{n+1}}{1/2} = 2 - \frac{1}{2^n}$. $\sum u_k = \sum (v_k + 1) = \sum v_k + (n + 1) = 2 - \frac{1}{2^n} + n + 1 = n + 3 - \frac{1}{2^n}$.

8) $\lim \sum v_k = 2$.
