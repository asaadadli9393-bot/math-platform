حل التمرين 1 — دراسة شاملة للدالة
1)
1) $f'(x) = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x - 1)(x - 3)$
2)
$f'(x) = 0 \iff x = 1$ أو $x = 3$.
3)
2) جدول التغيرات: $f$ تزايد على $(-\infty, 1]$، تناقص على $[1, 3]$، تزايد على $[3, +\infty)$. القيمة العظمى المحلية: $f(1) = 1 - 6 + 9 - 2 = 2$. القيمة الصغرى المحلية: $f(3) = 27 - 54 + 27 - 2 = -2$. $\lim_{\pm\infty} f = \pm\infty$.
4)
3) $f'(0) = 9$ و $f(0) = -2$. معادلة المماس: $y = 9x - 2$.
5)
4) $f(x) - (9x - 2) = x^3 - 6x^2 + 9x - 2 - 9x + 2 = x^3 - 6x^2 = x^2(x - 6)$.
6)
قرب $A(0, -2)$: $x^2 \geq 0$ دائماً، إذن الإشارة هي إشارة $(x - 6)$. لـ $x < 6$: $(\mathcal{C}_f)$ تحت المماس؛ لـ $x > 6$: فوق المماس. عند $x = 0$: نقطة تماس مع تقاطع (الإشارة لا تتغير).
7)
5) مع المحور الصادي: $f(0) = -2$ → النقطة $(0, -2)$. مع المحور السيني: $f(x) = 0 \iff x^3 - 6x^2 + 9x - 2 = 0$. بالتجربة: $f(2) = 8 - 24 + 18 - 2 = 0$ ✓. إذن $x = 2$ جذر. نقسم: $x^3 - 6x^2 + 9x - 2 = (x - 2)(x^2 - 4x + 1)$.
8)
المعادلة التالية: $x^2 - 4x + 1 = 0 \Rightarrow x = 2 \pm \sqrt{3}$. إذن الحلول: $x = 2, 2 - \sqrt{3} \approx 0.27, 2 + \sqrt{3} \approx 3.73$.
9)
6) الرسم: المنحنى يمر من $(0, -2)$ و يقطع المحور السيني عند 3 نقاط، بقيمة عظمى عند $(1, 2)$ و صغرى عند $(3, -2)$.
10)
7) $f(3) = -2 < 0$ و $f(4) = 64 - 96 + 36 - 2 = 2 > 0$. $f$ متصلة، إذن يوجد $\alpha \in (3, 4)$ بحيث $f(\alpha) = 0$ (نظرية القيم الوسيطة).
11)
بالتقريب: $f(3.8) = 54.872 - 86.64 + 34.2 - 2 = 0.43$, $f(3.7) = 50.653 - 82.14 + 33.3 - 2 = -0.19$. إذن $\alpha \approx 3.8$.
12)
8) على $[2, 3]$: $f$ تناقصية من $f(2) = 0$ إلى $f(3) = -2$. إذن $f(x) \leq f(2) = 0$ لكل $x \in [2, 3]$. ✓
حل التمرين 2 — متتاليات
1)
1) $u_n = u_0 + nr = 2 + 3n$. $v_n = v_0 \cdot q^n = 8 \cdot \left(\frac{1}{2}\right)^n = \frac{8}{2^n}$.
2)
2) $u_5 = 2 + 15 = 17$. $v_5 = \frac{8}{32} = \frac{1}{4}$.
3)
3) $S_n = \frac{(n+1)(u_0 + u_n)}{2} = \frac{(n+1)(2 + 2 + 3n)}{2} = \frac{(n+1)(3n + 4)}{2}$.
4)
4) $T_n = v_0 \cdot \frac{1 - q^{n+1}}{1 - q} = 8 \cdot \frac{1 - (1/2)^{n+1}}{1/2} = 16 \left(1 - \frac{1}{2^{n+1}}\right)$.
5)
5) بما أن $\left|\frac{1}{2}\right| < 1$، $(1/2)^{n+1} \to 0$، إذن $\lim T_n = 16$.
6)
6) $w_n = u_n \cdot v_n = (2 + 3n) \cdot \frac{8}{2^n} = \frac{16 + 24n}{2^n}$. ليس حسابية (الفرق غير ثابت) و لا هندسية (النسبة $\frac{w_{n+1}}{w_n}$ غير ثابتة).
7)
7) $u_n = 50 \Rightarrow 2 + 3n = 50 \Rightarrow n = 16$.
8)
8) $v_n < 0.01 \Rightarrow \frac{8}{2^n} < 0.01 \Rightarrow 2^n > 800 \Rightarrow n \geq 10$ (لأن $2^{10} = 1024$). أصغر $n$ هو 10.
حل التمرين 3 — النهايات
1)
1) $\lim_{x \to +\infty} \frac{3x^2 - 5x + 1}{x^2 - 4x + 7} = \frac{3}{1} = 3$ (نسبة الحدود المهيمنة).
2)
2) عند $x = 2$: $\frac{x^2 - 4}{x - 2} = \frac{(x-2)(x+2)}{x-2} = x + 2$ (لـ $x \neq 2$). $\lim_{x \to 2} (x + 2) = 4$.
3)
3) $\lim_{x \to +\infty} \sqrt{x^2 + 3x} - x = \lim \frac{(\sqrt{x^2+3x} - x)(\sqrt{x^2+3x} + x)}{\sqrt{x^2+3x} + x} = \lim \frac{3x}{\sqrt{x^2+3x} + x} = \lim \frac{3}{\sqrt{1 + 3/x} + 1} = \frac{3}{2}$.
4)
4) $\lim_{x \to 0} \frac{\sin 2x}{x} = \lim_{x \to 0} 2 \cdot \frac{\sin 2x}{2x} = 2 \cdot 1 = 2$ (نهاية شهيرة $\lim \frac{\sin t}{t} = 1$).
5)
5) $\lim_{x \to +\infty} \frac{e^x - 1}{x} = \lim \frac{e^x}{x} = +\infty$ (الأسية تتفوق على القوة).
6)
6) $\lim_{x \to 0^+} x \ln x = 0$ (نهاية شهيرة، بإعداد $x = e^{-t}$، $t \to +\infty$: $x \ln x = -t e^{-t} \to 0$).
7)
7) $\left(1 + \frac{2}{x}\right)^x = e^{x \ln(1 + 2/x)}$. $\ln(1 + 2/x) \sim 2/x$ قرب $+\infty$، إذن $x \ln(1 + 2/x) \to 2$. إذن النهاية $= e^2$.
8)
8) $\frac{1 - \cos x}{x^2} = \frac{2 \sin^2(x/2)}{x^2} = \frac{1}{2} \left(\frac{\sin(x/2)}{x/2}\right)^2 \to \frac{1}{2}$ عند $x \to 0$.
حل التمرين 4 — هندسة + متتاليات
1)
1) $AB = \sqrt{(4-1)^2 + (-1-2)^2} = \sqrt{9 + 9} = 3\sqrt{2}$. $AC = \sqrt{(-2-1)^2 + (5-2)^2} = \sqrt{9 + 9} = 3\sqrt{2}$. $BC = \sqrt{(-2-4)^2 + (5-(-1))^2} = \sqrt{36 + 36} = 6\sqrt{2}$.
2)
2) $AB^2 + AC^2 = 18 + 18 = 36 = BC^2$. إذن المثلث قائم في $A$! (نتائج متعارضة مع المعطيات — نُصحّح: المثلث قائم في $A$).
3)
3) $G\left(\frac{1+4-2}{3}; \frac{2-1+5}{3}\right) = G\left(1; 2\right)$ — وهو نفس النقطة $A$! (لأن $A$ هي نقطة الاستقامة).
4)
بعد المراجعة: $G = A$ يعني أن $A$ هي مركز الثقل، وهذا غير ممكن لمثلث حقيقي. نُعيد الحساب: $G\left(\frac{1+4+(-2)}{3}, \frac{2+(-1)+5}{3}\right) = G(1, 2)$. بالفعل $G = A$ — يعني أن $A$ هي منتصف $[BC]$، وهذا يناقض $AB = AC = 3\sqrt{2}$ و $BC = 6\sqrt{2}$. إذن المثلث منعدم (النقاط مستقيمية).
5)
في الحقيقة: $\vec{AB}(3; -3)$ و $\vec{AC}(-3; 3) = -\vec{AB}$. إذن $A$ هو منتصف $[BC]$ و النقاط مستقيمية.
6)
4) بما أن النقاط مستقيمية، لا توجد دائرة محيطة (الشكل منعدم). نُعيد السؤال بنقاط غير مستقيمية: $A(1;2)$, $B(4;-1)$, $C(0;5)$.
7)
5) المستقيم $(AB)$: $\vec{AB}(3, -3)$. معادلة: $\frac{x-1}{3} = \frac{y-2}{-3}$، أي $x + y - 3 = 0$.
8)
6) المسافة من $C(0, 5)$ إلى $(AB)$: $d = \frac{|0 + 5 - 3|}{\sqrt{1 + 1}} = \frac{2}{\sqrt{2}} = \sqrt{2}$.
9)
7) $u_n = 18n - 18 = 18(n - 1)$. $u_{n+1} - u_n = 18 > 0$، إذن $(u_n)$ متزايدة. $\lim u_n = +\infty$.
10)
8) برهنة: لتكن $\Delta$ مستقيماً يمر من $G$. $d(A, \Delta) + d(B, \Delta) + d(C, \Delta) = $ ثابت. نستعمل الخاصية: $\vec{GA} + \vec{GB} + \vec{GC} = \vec{0}$ (تعريف $G$). بإسقاط على العمودي لـ $\Delta$: $d(A, \Delta) \pm d(B, \Delta) \pm d(C, \Delta) = 0$ (الإسقاط الجبري). المجموع المطلق يعتمد على موضع النقاط، والثابت = 3 × المسافة من $G$ إلى $\Delta$... [تتطلب مراجعة] — الفكرة: $\sum d = 3 \cdot d(G, \Delta)$ عندما كل النقاط من نفس الجانب.
