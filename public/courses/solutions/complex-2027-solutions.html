📝 التمرين 2

التمرين 2 — احسب:
1. $(3 + 2i)(1 - 4i)$
2. $\frac{2+i}{1-i}$
3. $|3+4i|$ و $|\overline{3+4i}|$

💡

اضرب واجمع; للقسمة اضرب في المرافق

✅ الحل النموذجي:

1) $3 - 12i + 2i - 8i^2 = 3 - 10i + 8 = 11 - 10i$

2) $\frac{2+i}{1-i} \times \frac{1+i}{1+i} = \frac{(2+i)(1+i)}{1+1} = \frac{2+2i+i+i^2}{2} = \frac{1+3i}{2}$

3) $|3+4i| = \sqrt{9+16} = 5$; $|\overline{3+4i}| = |3-4i| = 5$

📝 التمرين 3

التمرين 3 — حل $z^3 = -8i$ في $\mathbb{C}$.

💡

اكتب z = re^(iθ), ثم r³ = 8 و 3θ = -π/2 + 2kπ

✅ الحل النموذجي:

نكتب $z = re^{i\theta}$:
$r^3 e^{3i\theta} = 8e^{-i\pi/2}$

$r^3 = 8 \implies r = 2$
$3\theta = -\frac{\pi}{2} + 2k\pi \implies \theta = -\frac{\pi}{6} + \frac{2k\pi}{3}$

- $k=0$: $\theta = -\frac{\pi}{6}$, $z_1 = 2e^{-i\pi/6} = \sqrt{3} - i$
- $k=1$: $\theta = \frac{\pi}{2}$, $z_2 = 2e^{i\pi/2} = 2i$
- $k=2$: $\theta = \frac{7\pi}{6}$, $z_3 = 2e^{7i\pi/6} = -\sqrt{3} - i$

📝 التمرين 4

التمرين 4 — أكتب $z = 1 + i$ بالصيغة المثلثية والأسية.

💡

r = |z| = √2, θ = arctan(1/1) = π/4

✅ الحل النموذجي:

$r = \sqrt{1^2 + 1^2} = \sqrt{2}$
$\theta = \arctan\left(\frac{1}{1}\right) = \frac{\pi}{4}$

مثلثية: $z = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$

أسية: $z = \sqrt{2} \, e^{i\pi/4}$

📝 التمرين 5

التمرين 5 — استعمل صيغة Moivre لحساب $(1 + i)^6$.

💡

z = √2·e^(iπ/4), z^6 = (√2)^6 · e^(6iπ/4) = 8·e^(3iπ/2)

✅ الحل النموذجي:

$(1+i)^6 = \left(\sqrt{2} \, e^{i\pi/4}\right)^6 = (\sqrt{2})^6 \cdot e^{6i\pi/4} = 8 \, e^{3i\pi/2}$

$e^{3i\pi/2} = \cos\frac{3\pi}{2} + i\sin\frac{3\pi}{2} = -i$

$\boxed{(1+i)^6 = -8i}$

📝 التمرين 6

التمرين 6 — لتكن $A(2+i)$ و $B(3+3i)$ و $C(1+2i)$.
1. احسب $AB$, $AC$, $BC$.
2. برهن أن المثلث $ABC$ قائم في $A$.
3. احسب مساحة المثلث $ABC$.

💡

AB = |zB-zA|; قائم إذا AB² + AC² = BC²

✅ الحل النموذجي:

1) $AB = |(3+3i)-(2+i)| = |1+2i| = \sqrt{5}$
$AC = |(1+2i)-(2+i)| = |-1+i| = \sqrt{2}$
$BC = |(1+2i)-(3+3i)| = |-2-i| = \sqrt{5}$

2) $AB^2 + AC^2 = 5 + 2 = 7 \neq BC^2 = 5$. ليس قائماً في $A$.

$AB^2 + BC^2 = 5 + 5 = 10 \neq AC^2 = 2$. ليس قائماً في $B$.

$AC^2 + BC^2 = 2 + 5 = 7 \neq AB^2 = 5$. ليس قائماً في $C$.

المثلث $ABC$ ليس قائماً.

3) بالصيغة: $\mathcal{A} = \frac{1}{2}|\text{Im}((z_B-z_A)\overline{(z_C-z_A)})|$
$= \frac{1}{2}|\text{Im}((1+2i)(-1-i)| = \frac{1}{2}|\text{Im}(-1-i-2i-2i^2)| = \frac{1}{2}|\text{Im}(1-3i)| = \frac{3}{2}$

📝 التمرين 7

التمرين 7 (مسألة شاملة) — حل $z^4 = -16$ ثم استنتج أن النقاط صور الحلول تشكل مربعاً.

💡

z = 2·e^(i(π/4 + kπ/2)), k=0,1,2,3

✅ الحل النموذجي:

$z^4 = 16 e^{i\pi}$, إذن $z = 2 e^{i(\pi/4 + k\pi/2)}$ لـ $k = 0,1,2,3$:

- $z_0 = 2e^{i\pi/4} = \sqrt{2}(1+i)$
- $z_1 = 2e^{3i\pi/4} = \sqrt{2}(-1+i)$
- $z_2 = 2e^{5i\pi/4} = \sqrt{2}(-1-i)$
- $z_3 = 2e^{7i\pi/4} = \sqrt{2}(1-i)$

كل نقطة على دائرة نصف قطرها 2، والفرق بين زاويتين متتاليتين هو $\frac{\pi}{2}$ (90°), إذن النقاط تشكل مربعاً ✓
