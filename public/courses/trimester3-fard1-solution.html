حل التمرين الأول — هندسة في الفضاء

1) $\vec{AB}(1; -3; -2)$, $\vec{AC}(2; -2; -4)$, $\vec{AD}(-1; -1; 1)$.

2) $\vec{AB} \cdot \vec{AC} = 1 \cdot 2 + (-3)(-2) + (-2)(-4) = 2 + 6 + 8 = 16$.

3) $\vec{AB} \wedge \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & -3 & -2 \\ 2 & -2 & -4 \end{vmatrix} = (12 - 4)\vec{i} - (-4 + 4)\vec{j} + (-2 + 6)\vec{k} = (8; 0; 4)$.

4) المتجه العادي للمستوي $(ABC)$ هو $(8, 0, 4)$. المعادلة: $8(x - 1) + 0(y - 2) + 4(z - 3) = 0 \Rightarrow 8x + 4z - 20 = 0 \Rightarrow 2x + z - 5 = 0$.

5) $d(D, (ABC)) = \frac{|2 \cdot 0 + 0 \cdot 1 + 1 \cdot 4 - 5|}{\sqrt{4 + 0 + 1}} = \frac{|-1|}{\sqrt{5}} = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5} \approx 0,447$.

6) الجداء المختلط: $(\vec{AB} \wedge \vec{AC}) \cdot \vec{AD} = 8 \cdot (-1) + 0 \cdot (-1) + 4 \cdot 1 = -8 + 4 = -4$. الحجم = $\frac{|-4|}{6} = \frac{2}{3}$.

7) $\vec{AB}$ و $\vec{AC}$ غير معمدلين (لأن $\vec{AB} \wedge \vec{AC} \neq \vec{0}$), إذن $A, B, C$ ليست مستقيمية.

8) مساحة المثلث $ABC$: $\mathcal{S} = \frac{1}{2}|\vec{AB} \wedge \vec{AC}| = \frac{1}{2}\sqrt{64 + 0 + 16} = \frac{1}{2}\sqrt{80} = 2\sqrt{5} \approx 4,47$.

حل التمرين الثاني — الدالة $f(x) = \ln x / x$

1) عند $0^+$: $\ln x \to -\infty$ و $1/x \to +\infty$. $\ln x / x \to -\infty \cdot +\infty = -\infty$ (اللوغاريتم يتفوق على القوة بشكل عكسي). إذن $f(x) \to -\infty$. عند $+\infty$: $\frac{\ln x}{x} \to 0^+$.

2) $f'(x) = \frac{x \cdot \frac{1}{x} - \ln x \cdot 1}{x^2} = \frac{1 - \ln x}{x^2}$. $f'(x) \geq 0 \iff \ln x \leq 1 \iff x \leq e$.

3) القيمة العظمى عند $x = e$: $f(e) = \ln e / e = 1/e$.

4) $f(x) = 0 \iff \ln x = 0 \iff x = 1$. نقطة تقاطع وحيدة: $(1, 0)$.

5) $\int_1^e \frac{\ln x}{x}\, dx = \frac{(\ln x)^2}{2}\Big|_1^e = \frac{1 - 0}{2} = \frac{1}{2}$.

6) $u_n = \frac{\ln n}{n}$. $u_{n+1} - u_n = \frac{\ln(n+1)}{n+1} - \frac{\ln n}{n} = \frac{n \ln(n+1) - (n+1)\ln n}{n(n+1)} = \frac{\ln\frac{(n+1)^n}{n^{n+1}}}{n(n+1)} = \frac{\ln\frac{(1 + 1/n)^n}{n}}{n(n+1)}$. لـ $n \geq 3$: $(1+1/n)^n < e < n$, إذن البسط $< 0$, $u_{n+1} < u_n$. $(u_n)$ متناقية لـ $n \geq 3$.

7) $\lim u_n = 0$.

8) القيمة العظمى لـ $f$ هي $1/e$, و $\frac{1}{2e} < \frac{1}{e}$. $f$ تزايد من $-\infty$ إلى $1/e$ على $(0, e)$ ثم تناقص من $1/e$ إلى 0 على $(e, +\infty)$. إذن $f(x) = 1/(2e)$ يقطع مرتين: مرة على $(0, e)$ و مرة على $(e, +\infty)$.

حل التمرين الثالث — براهين + متتالية

1) التهيئة: $n = 1$: $1 = \frac{1 \cdot 2 \cdot 3}{6} = 1$ ✓. النتيجة: $\sum_{k=1}^{n+1} k^2 = \frac{n(n+1)(2n+1)}{6} + (n+1)^2 = (n+1)\left[\frac{n(2n+1)}{6} + (n+1)\right] = (n+1) \cdot \frac{2n^2 + n + 6n + 6}{6} = \frac{(n+1)(n+2)(2n+3)}{6}$ ✓.

2) $\sum (k^2 + k) = \sum k^2 + \sum k = \frac{n(n+1)(2n+1)}{6} + \frac{n(n+1)}{2} = \frac{n(n+1)(2n+1) + 3n(n+1)}{6} = \frac{n(n+1)(2n+4)}{6} = \frac{n(n+1)(n+2)}{3}$.

3) $u_n = \frac{n^2 + n + 1}{n^2 - n + 1}$. $u_{n+1} - u_n$ بعد التبسيط: نحسب البسط المشترك.

$u_{n+1} = \frac{(n+1)^2 + (n+1) + 1}{(n+1)^2 - (n+1) + 1} = \frac{n^2 + 3n + 3}{n^2 + n + 1}$. $u_{n+1} - u_n = \frac{(n^2 + 3n + 3)(n^2 - n + 1) - (n^2 + n + 1)(n^2 + n + 1)}{(n^2 + n + 1)(n^2 - n + 1)}$.

البسط: $n^4 - n^3 + n^2 + 3n^3 - 3n^2 + 3n + 3n^2 - 3n + 3 - (n^4 + 2n^3 + 3n^2 + 2n + 1) = 2n^3 + n^2 + 0n + 2 - 2n^3 - 3n^2 - 2n - 1$... (الحساب معقد).

بالأحرى: $u_n - 1 = \frac{2n}{n^2 - n + 1}$. $u_{n+1} - 1 = \frac{2(n+1)}{(n+1)^2 - (n+1) + 1} = \frac{2n + 2}{n^2 + n + 1}$. $u_{n+1} - u_n = (u_{n+1} - 1) - (u_n - 1) = \frac{2n+2}{n^2+n+1} - \frac{2n}{n^2-n+1}$.

بعد التبسيط: $\frac{(2n+2)(n^2-n+1) - 2n(n^2+n+1)}{...} = \frac{2n^3 - 2n^2 + 2n + 2n^2 - 2n + 2 - 2n^3 - 2n^2 - 2n}{...} = \frac{-2n^2 - 2n + 2}{...}$. لـ $n$ كبير, سالب, إذن $(u_n)$ متناقية لـ $n$ كبير.

4) $\lim u_n = \lim \frac{n^2}{n^2} = 1$.

5) $u_n - 1 = \frac{2n}{n^2 - n + 1} > 0$ لـ $n \geq 1$ (لأن $n^2 - n + 1 > 0$ دائمًا). إذن $u_n > 1$ ✓.

6) $n(u_n - 1) = \frac{2n^2}{n^2 - n + 1} \to 2$.

7) $v_n = n u_n = n \cdot \frac{n^2 + n + 1}{n^2 - n + 1} = \frac{n^3 + n^2 + n}{n^2 - n + 1} \to +\infty$ (لأن البسط درجة 3 و المقام درجة 2).

8) $u_n - 1 \sim \frac{2}{n}$ (تقريب taylor), إذن التقارب من الرتبة 1 بمعدل $2$.

حل التمرين الرابع — التكاملات

1) $[x^3 + x^2 - x]_0^1 = 1 + 1 - 1 = 1$.

2) بالتجزئة: $\int_0^1 x e^x\, dx = [x e^x]_0^1 - \int_0^1 e^x\, dx = e - (e - 1) = 1$.

3) بالتجزئة: $u = \ln x$, $v' = 1/x^2$. $\int_1^e \frac{\ln x}{x^2}\, dx = [-\frac{\ln x}{x}]_1^e + \int_1^e \frac{1}{x^2}\, dx = -1 + [-1/x]_1^e = -1 + (-1/e + 1) = -1/e$.

4) $u = \cos x$, $du = -\sin x\, dx$. $\int_0^{\pi/2} \sin x (1 - \cos^2 x)\, dx = -\int_1^0 (1 - u^2)\, du = [u - u^3/3]_0^1 = 2/3$.

5) $u = e^x + 1$, $du = e^x\, dx$. $[\ln(e^x + 1)]_0^{\ln 2} = \ln 3 - \ln 2$.

6) بالتجزئة: $u = x$, $v' = \sin x$. $[-x \cos x]_0^\pi + \int_0^\pi \cos x\, dx = \pi + 0 = \pi$.

7) $\int_0^{+\infty} x e^{-x}\, dx = \lim_{A \to +\infty} [-x e^{-x} - e^{-x}]_0^A = \lim (0 - 0) - (-1) = 1$.

8) $\int_0^1 \frac{1}{x^2 + 1}\, dx = [\arctan x]_0^1 = \pi/4$.
