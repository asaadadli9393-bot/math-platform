حل التمرين 1 — هندسة في الفضاء
1)
1) $\vec{AB}(1; -3; -2)$, $\vec{AC}(2; -2; -4)$, $\vec{AD}(-1; -1; 1)$.
2)
2) $\vec{AB} \cdot \vec{AC} = 1 \cdot 2 + (-3)(-2) + (-2)(-4) = 2 + 6 + 8 = 16$.
3)
3) $\vec{AB} \wedge \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & -3 & -2 \\ 2 & -2 & -4 \end{vmatrix} = \vec{i}(12 - 4) - \vec{j}(-4 + 4) + \vec{k}(-2 + 6) = 8\vec{i} + 0\vec{j} + 4\vec{k} = (8; 0; 4)$.
4)
4) مساحة المثلث $ABC$: $\mathcal{S} = \frac{1}{2}|\vec{AB} \wedge \vec{AC}| = \frac{1}{2} \sqrt{64 + 0 + 16} = \frac{1}{2} \sqrt{80} = 2\sqrt{5}$.
5)
5) الجداء المختلط: $[\vec{AB}, \vec{AC}, \vec{AD}] = (\vec{AB} \wedge \vec{AC}) \cdot \vec{AD} = (8)(-1) + (0)(-1) + (4)(1) = -8 + 0 + 4 = -4$.
6)
حجم الرباعي = $\frac{1}{6}|\text{جداء مختلط}| = \frac{4}{6} = \frac{2}{3}$.
7)
6) $\vec{AB} \wedge \vec{AC} = (8, 0, 4)$ هو متجه عادي للمستوي $(ABC)$. المعادلة: $8(x - 1) + 0(y - 2) + 4(z - 3) = 0 \Rightarrow 8x + 4z - 20 = 0 \Rightarrow 2x + z - 5 = 0$.
8)
إذن $a = 2, b = 0, c = 1, d = -5$.
9)
7) $d(D, (ABC)) = \frac{|2 \cdot 0 + 0 \cdot 1 + 1 \cdot 4 - 5|}{\sqrt{4 + 0 + 1}} = \frac{|-1|}{\sqrt{5}} = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}$.
10)
8) الجداء المختلط = -4 ≠ 0, إذن النقاط الأربعة ليست في نفس المستوي (فضاء ثلاثي الأبعاد حقيقي). ليست مستقيمية (لأن $\vec{AB}$ و $\vec{AC}$ غير معمدلين).
حل التمرين 2 — تكامل
1)
1) $u = x$, $v' = e^x$. $\int_0^1 x e^x\, dx = [x e^x]_0^1 - \int_0^1 e^x\, dx = e - (e - 1) = 1$.
2)
2) بالتجزئة مرتين: $\int x^2 e^x\, dx = x^2 e^x - 2 \int x e^x\, dx = x^2 e^x - 2 x e^x + 2 e^x$.
3)
$\int_0^1 x^2 e^x\, dx = [x^2 e^x - 2 x e^x + 2 e^x]_0^1 = (e - 2e + 2e) - (0 - 0 + 2) = e - 2$.
4)
3) $u = \ln x$, $v' = 1/x^2$. $\int_1^e \frac{\ln x}{x^2}\, dx = [-\frac{\ln x}{x}]_1^e + \int_1^e \frac{1}{x^2}\, dx = -1/e + 0 + [-1/x]_1^e = -1/e + (-1/e + 1) = 1 - 2/e$.
5)
4) $\int_0^{\pi/2} \sin^3 x\, dx = \int_0^{\pi/2} \sin x (1 - \cos^2 x)\, dx$. نضع $u = \cos x$, $du = -\sin x\, dx$.
6)
$= -\int_1^0 (1 - u^2)\, du = \int_0^1 (1 - u^2)\, du = [u - u^3/3]_0^1 = 1 - 1/3 = 2/3$.
7)
5) $u = e^x + 1$, $du = e^x\, dx$. $\int_0^{\ln 2} \frac{e^x}{e^x + 1}\, dx = [\ln(e^x + 1)]_0^{\ln 2} = \ln 3 - \ln 2$.
8)
6) $\int_0^1 \frac{1}{x^2 + 1}\, dx = [\arctan x]_0^1 = \pi/4$.
9)
7) $\int \tan x\, dx = -\ln |\cos x|$. $\int_0^{\pi/4} \tan x\, dx = [-\ln |\cos x|]_0^{\pi/4} = -\ln(\sqrt{2}/2) - 0 = \ln(2/\sqrt{2}) = \frac{1}{2} \ln 2$.
10)
8) $\int_0^{+\infty} \frac{1}{x^2 + 1}\, dx = [\arctan x]_0^{+\infty} = \pi/2 - 0 = \pi/2$.
حل التمرين 3 — متتالية عودية
1)
1) $u_0 = 1$, $u_1 = \sqrt{3} \approx 1.732$, $u_2 = \sqrt{\sqrt{3} + 2} \approx 1.892$, $u_3 \approx 1.937$.
2)
2) التهيئة: $0 < u_0 = 1 < 2$ ✓.
3)
النتيجة: $u_{n+1} = \sqrt{u_n + 2}$. إذا $0 < u_n < 2$, فإن $2 < u_n + 2 < 4$, إذن $\sqrt{2} < u_{n+1} < 2$. بما أن $\sqrt{2} > 0$, $0 < u_{n+1} < 2$ ✓.
4)
3) $u_{n+1} - u_n = \sqrt{u_n + 2} - u_n$. ندرس الإشارة: $u_{n+1} \geq u_n \iff \sqrt{u_n + 2} \geq u_n \iff u_n + 2 \geq u_n^2 \iff u_n^2 - u_n - 2 \leq 0$.
5)
$u_n^2 - u_n - 2 = (u_n - 2)(u_n + 1)$. على $[-1, 2]$: $\leq 0$. بما أن $u_n \in (0, 2)$, $u_{n+1} - u_n \geq 0$.
6)
إذن $(u_n)$ متزايدة.
7)
4) $(u_n)$ متزايدة و محدودة علويًا بـ 2, إذن متقاربة. $\ell = \sqrt{\ell + 2} \Rightarrow \ell^2 = \ell + 2 \Rightarrow \ell^2 - \ell - 2 = 0 \Rightarrow (\ell - 2)(\ell + 1) = 0$.
8)
نختار $\ell > 0$: $\ell = 2$.
9)
5) $v_{n+1} = u_{n+1} - 2 = \sqrt{u_n + 2} - 2 = \frac{u_n + 2 - 4}{\sqrt{u_n + 2} + 2} = \frac{u_n - 2}{\sqrt{u_n + 2} + 2} = \frac{v_n}{\sqrt{u_n + 2} + 2}$.
10)
6) $|v_{n+1}| = \frac{|v_n|}{\sqrt{u_n + 2} + 2}$. بما أن $u_n > 0$, $\sqrt{u_n + 2} > \sqrt{2} > 0$, إذن $\sqrt{u_n + 2} + 2 > 2$. إذن $|v_{n+1}| \leq \frac{|v_n|}{2} < \frac{|v_n|}{1}$. ✓
11)
بالتكرار: $|v_n| \leq \frac{|v_0|}{2^n} = \frac{1}{2^n} \to 0$. إذن $\lim v_n = 0$.
12)
7) التقريب الخطي: $(u_n)$ يقترب من 2 بمعدل $1/2$ في كل خطوة (تقريبًا). بعد $n$ خطوة, الخطأ $\leq 1/2^n$.
13)
للحصول على دقة $\epsilon$, نحتاج $n \geq \log_2(1/\epsilon)$. لـ $\epsilon = 10^{-3}$: $n \geq 10$.
14)
8) $\frac{u_n - \ell}{u_{n-1} - \ell} = \frac{v_n}{v_{n-1}} = \frac{1}{\sqrt{u_{n-1} + 2} + 2} \to \frac{1}{\sqrt{2 + 2} + 2} = \frac{1}{4}$.
15)
إذن $\lim \frac{u_n - \ell}{u_{n-1} - \ell} = \frac{1}{4}$.
حل التمرين 4 — دالة $f(x) = \ln x / x$
1)
1) عند $0^+$: $\ln x \to -\infty$ و $1/x \to +\infty$. النهاية: $\ln x / x \to -\infty$ (اللوغاريتم يتفوق على القوة؟ لا — $1/x$ يتفوق. لكن $\ln x \cdot (1/x) = \ln x / x \to -\infty / +\infty$. نكتب: $\frac{\ln x}{x} = \frac{-\infty}{0^+}$. إذن $\to -\infty$.
2)
عند $+\infty$: $\frac{\ln x}{x} \to 0$ (شهيرة — القوة تتفوق على اللوغاريتم).
3)
2) $f'(x) = \frac{1 \cdot x - \ln x \cdot 1}{x^2} = \frac{1 - \ln x}{x^2}$. $x^2 > 0$, إذن $f'(x) \geq 0 \iff \ln x \leq 1 \iff x \leq e$.
4)
3) الأقصى عند $x = e$: $f(e) = \ln e / e = 1/e$.
5)
4) $f(x) = 0 \iff \ln x = 0 \iff x = 1$. نقطة تقاطع وحيدة: $(1, 0)$.
6)
5) $\int_1^e \frac{\ln x}{x}\, dx = \frac{(\ln x)^2}{2}\Big|_1^e = \frac{1 - 0}{2} = \frac{1}{2}$.
7)
6) $u_n = \frac{\ln n}{n}$. $u_{n+1} - u_n = \frac{\ln(n+1)}{n+1} - \frac{\ln n}{n} = \frac{n \ln(n+1) - (n+1) \ln n}{n(n+1)}$.
8)
البسط = $\ln((n+1)^n / n^{n+1}) = \ln((1 + 1/n)^n / n)$. لـ $n \geq 3$: $(1+1/n)^n < e < n$, إذن البسط $< 0$, $u_{n+1} - u_n < 0$, $(u_n)$ متناقصة لـ $n \geq 3$.
9)
7) $\lim u_n = 0$. المتتالية متناقصة (لـ $n \geq 3$) و نهايتها 0.
10)
8) $f(x) = \frac{1}{2e}$: القيمة القصوى لـ $f$ هي $1/e > 1/(2e)$. إذن المعادلة يقبل حلين على $(0, +\infty)$: واحد على $(0, e)$ و الآخر على $(e, +\infty)$. (لأن $f$ تزايد من $-\infty$ إلى $1/e$ على $(0, e)$ ثم تناقص من $1/e$ إلى $0$ على $(e, +\infty)$, يقطع $1/(2e)$ مرتين.)
