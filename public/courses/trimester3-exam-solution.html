حل التمرين 1 — دراسة دالة $f(x) = \frac{x - 2}{x + 1}$
1)
1) عند $-1^-$: $\frac{-3}{0^-} = +\infty$. عند $-1^+$: $\frac{-3}{0^+} = -\infty$.
2)
عند $\pm\infty$: $\frac{x}{x} = 1$.
3)
2) المقاربات: $x = -1$ (عمودية), $y = 1$ (أفقية).
4)
3) $f'(x) = \frac{1 \cdot (x+1) - (x-2) \cdot 1}{(x+1)^2} = \frac{3}{(x+1)^2} > 0$ على مجال التعريف.
5)
4) $f$ تزايد على $(-\infty, -1)$ و على $(-1, +\infty)$. حدود: $+\infty$ عند $-1^-$, $1$ عند $\pm\infty$.
6)
5) مركز التناظر = تقاطع المقاربتين: $I(-1, 1)$. للتحقق: $f(-1 + h) + f(-1 - h) = \frac{h - 3}{h} + \frac{-h - 3}{-h} = \frac{h - 3 + h + 3}{h} = 2$ ✓.
7)
إذن $I(-1, 1)$ مركز تناظر.
8)
6) لتكن $M(x, f(x))$ على $(\mathcal{C}_f)$, مناظرها بالنسبة لـ $I$ هو $M'(2 \cdot (-1) - x, 2 \cdot 1 - f(x)) = M'(-2 - x, 2 - f(x))$.
9)
نتحقق أن $M'$ على $(\mathcal{C}_f)$: $f(-2 - x) = \frac{-2 - x - 2}{-2 - x + 1} = \frac{-x - 4}{-x - 1} = \frac{x + 4}{x + 1} = 1 + \frac{3}{x + 1}$. $2 - f(x) = 2 - \frac{x-2}{x+1} = \frac{2x + 2 - x + 2}{x + 1} = \frac{x + 4}{x + 1}$ ✓.
10)
7) الرسم: منحنى زوالدي بمركز $I(-1, 1)$, يقترب من المقاربتين.
11)
8) $g(x) = \frac{x-2}{x+1} - \ln(x+2)$. $g'(x) = \frac{3}{(x+1)^2} - \frac{1}{x+2}$. دراسة الإشارة:
12)
عند $x \to -1^+$: $g'(x) \to +\infty - 1 = +\infty$. عند $x \to +\infty$: $g'(x) \to 0 - 0$ (سلبي لـ $x$ كبير).
13)
$g'$ يتناقص من $+\infty$ إلى 0, يقطع 0 عند نقطة معينة. $g$ يزيد ثم ينقص.
14)
$g(-1^+) = +\infty - \ln 1 = +\infty$. $g(+\infty) = 1 - (+\infty) = -\infty$. إذن $g$ يقطع 0 مرة واحدة على $(-1, +\infty)$ → حل وحيد.
حل التمرين 2 — متتالية عودية
1)
1) $u_1 = 2(1)/2 = 1$. $u_2 = 2(1)/2 = 1$. $u_3 = 1$. (المتتالية ثابتة عند 1 — حل ثابت).
2)
2) التهيئة: $u_0 = 1 > 0$ ✓. النتيجة: $u_{n+1} = 2u_n/(u_n + 1)$. إذا $u_n > 0$, $2u_n > 0$ و $u_n + 1 > 1 > 0$, إذن $u_{n+1} > 0$ ✓.
3)
3) $v_{n+1} = \frac{1}{u_{n+1}} = \frac{u_n + 1}{2 u_n} = \frac{1}{2} + \frac{1}{2 u_n} = \frac{1}{2} + \frac{v_n}{2}$.
4)
4) $v_{n+1} - v_n = \frac{1}{2}$ (ثابت). $(v_n)$ حسابية أساسها $1/2$ و $v_0 = 1/u_0 = 1$.
5)
5) $v_n = 1 + n \cdot \frac{1}{2} = \frac{n + 2}{2}$. $u_n = \frac{1}{v_n} = \frac{2}{n + 2}$.
6)
6) $\lim u_n = 0$.
7)
7) $u_{n+1} - u_n = \frac{2}{n+3} - \frac{2}{n+2} = \frac{2(n+2) - 2(n+3)}{(n+3)(n+2)} = \frac{-2}{(n+3)(n+2)} < 0$.
8)
إذن $(u_n)$ متناقصة (ملاحظة: في الواقع $u_0 = 1, u_1 = 1$ ثابت — ثم يتناقص من $u_2$ فما بعد... لا بل $u_0 = 1$, $u_n = 2/(n+2)$: $u_0 = 1, u_1 = 2/3, u_2 = 1/2$).
9)
إذن $(u_n)$ متناقصة من $u_0$ فصاعدًا.
10)
8) $\sum v_k = \sum \frac{k + 2}{2} = \frac{1}{2} \sum (k + 2) = \frac{1}{2} \left[\frac{n(n+1)}{2} + 2(n+1)\right] = \frac{(n+1)(n + 4)}{4}$.
11)
$\sum 1/u_k = \sum v_k = \frac{(n+1)(n+4)}{4}$.

حل التمرين 4 — تكامل و متتالية
1)
1) $u = -x^3$, $du = -3x^2\, dx$. $\int_0^1 x^2 e^{-x^3}\, dx = -\frac{1}{3} \int_0^{-1} e^u\, du = -\frac{1}{3} (e^{-1} - 1) = \frac{1 - e^{-1}}{3} = \frac{e - 1}{3e}$.
2)
2) $u = \cos x$, $du = -\sin x\, dx$. $\int_0^{\pi/2} \cos^2 x \sin x\, dx = -\int_1^0 u^2\, du = \int_0^1 u^2\, du = 1/3$.
3)
3) $u = \sin^{n-1} x$, $v' = \sin x$. $I_n = [-\sin^{n-1} x \cos x]_0^{\pi/2} + (n-1) \int_0^{\pi/2} \sin^{n-2} x \cos^2 x\, dx$.
4)
الحد الأول = 0. $\cos^2 = 1 - \sin^2$: $I_n = (n-1)(I_{n-2} - I_n) \Rightarrow n I_n = (n-1) I_{n-2} \Rightarrow I_n = \frac{n-1}{n} I_{n-2}$ ✓.
5)
4) $I_0 = \int_0^{\pi/2} 1\, dx = \pi/2$. $I_1 = \int_0^{\pi/2} \sin x\, dx = [-\cos x]_0^{\pi/2} = 0 - (-1) = 1$.
6)
5) $I_2 = \frac{1}{2} I_0 = \pi/4$. $I_3 = \frac{2}{3} I_1 = 2/3$. $I_4 = \frac{3}{4} I_2 = 3\pi/16$. $I_5 = \frac{4}{5} I_3 = 8/15$.
7)
6) على $[0, \pi/2]$: $\sin x \in [0, 1]$, إذن $\sin^n x \leq \sin^{n-1} x$. بالتكامل: $I_n \leq I_{n-1}$. $(I_n)$ متناقية و موجبة → متقاربة.
8)
$I_n \leq \sin^n(\pi/2 - 1/n) \cdot \pi/2 \to 0$ (تقريب), إذن $\lim I_n = 0$.
9)
7) $J_n = (n+1) I_n I_{n+1}$. من العلاقة $I_{n+1} = \frac{n}{n+1} I_{n-1}$: $(n+1) I_{n+1} = n I_{n-1}$. إذن $J_n = I_n \cdot n I_{n-1}$.
10)
$J_0 = 1 \cdot I_0 \cdot I_1 = \pi/2$. $J_1 = 2 \cdot I_1 \cdot I_2 = 2 \cdot 1 \cdot \pi/4 = \pi/2$. ✓
11)
بصفة عامة: $J_{n+1} = (n+2) I_{n+1} I_{n+2} = (n+2) \cdot \frac{n+1}{n+2} I_n \cdot I_{n+1} = (n+1) I_n I_{n+1} = J_n$ ✓. إذن $J_n = \pi/2$ ثابتة.
12)
8) من $J_n = (n+1) I_n I_{n+1} = \pi/2$: $\frac{I_{n+1}}{I_n} = \frac{\pi/2}{(n+1) I_n^2}$. وبما أن $I_n \to 0$ بشكل سريع, نحتاج تحليل أعمق. نستعمل: $I_{n+1}/I_n = \frac{n}{n+1}$ (من العلاقة). إذن $\lim I_{n+1}/I_n = \lim \frac{n}{n+1} = 1$ ✓.
حل التمرين 5 — بواسون + واليس
1)
1) $X \sim \mathcal{B}(100, 0.01)$. (توزيع ذي الحدين بـ $n = 100$, $p = 0.01$.)
2)
2) بتقريب بواسون ($\lambda = np = 1$): $P(X = k) = \frac{e^{-1}}{k!}$.
3)
$P(X = 0) = e^{-1} \approx 0.368$.
4)
$P(X = 1) = e^{-1} \approx 0.368$.
5)
$P(X = 2) = e^{-1}/2 \approx 0.184$.
6)
3) $P(X \leq 2) = e^{-1}(1 + 1 + 1/2) = e^{-1} \cdot 5/2 \approx 0.920$.
7)
4) $E(X) = \lambda = 1$. $V(X) = \lambda = 1$ (بواسون).
8)
5) ندرس $u_n = (1 + 1/n)^n$. $\ln u_n = n \ln(1 + 1/n) = n(1/n - 1/(2n^2) + ...) = 1 - 1/(2n) + ...$. إذن $\ln u_n \nearrow 1$ و $u_n \nearrow e$.
9)
برهنة التزايد: $u_{n+1}/u_n = (1 + 1/(n+1))^{n+1} / (1 + 1/n)^n$. بعد التبسيط (باستخدام عدم المساواة بين المتوسطات الهندسية والحسابية), نجد $u_{n+1} > u_n$.
10)
6) $(u_n)$ متزايدة و محدودة علويًا بـ $e$ (لأن $\ln u_n < 1$). إذن متقاربة و نهايتها $e$.
11)
7) $\lim (1 + 2/n)^n = \lim e^{n \ln(1 + 2/n)} = e^{\lim 2 - 2/n + ...} = e^2$.
12)
8) $(1 + 1/n)^{n+1} = (1 + 1/n)^n \cdot (1 + 1/n)$. $\ln = (n+1) \ln(1 + 1/n) = (n+1)(1/n - 1/(2n^2) + ...) = 1 + 1/n - 1/(2n) + ... = 1 + 1/(2n) + ... \to 1$.
13)
إذن النهاية $= e$. للتراجع: $(1 + 1/n)^{n+1} = (1 + 1/n) \cdot (1 + 1/n)^n \to 1 \cdot e = e$.
14)
للتناقص: $w_n = (1 + 1/n)^{n+1}$. $\ln w_n = (n+1) \ln(1 + 1/n)$. $\ln w_{n+1} - \ln w_n = (n+2)\ln(1 + 1/(n+1)) - (n+1)\ln(1 + 1/n) < 0$ (برهنة بإعداد الدالة). إذن $(w_n)$ متناقصة و نهايتها $e$.
