حل التمرين الأول — الدالة $f(x) = \frac{x - 2}{x + 1}$
1)
1) عند $-1^-$: $\frac{-3}{0^-} = +\infty$. عند $-1^+$: $\frac{-3}{0^+} = -\infty$. عند $\pm\infty$: $\frac{x}{x} = 1$.
2)
2) المقاربات: $x = -1$ (عمودية), $y = 1$ (أفقية).
3)
3) $f'(x) = \frac{1 \cdot (x+1) - (x-2) \cdot 1}{(x+1)^2} = \frac{3}{(x+1)^2} > 0$ على المجال.
4)
4) $f$ تزايد على $(-\infty, -1)$ و على $(-1, +\infty)$. لا توجد قيم قصوى.
5)
5) مركز التناظر: تقاطع المقاربتين $I(-1, 1)$. للتحقق: $f(-1 + h) + f(-1 - h) = \frac{h - 3}{h} + \frac{-h - 3}{-h} = \frac{h - 3 + h + 3}{h} = 2 = 2 \cdot 1$ ✓. إذن $I(-1, 1)$ مركز تناظر.
6)
6) الرسم: منحنى زوالدي بمركز $I(-1, 1)$, يقترب من المقاربتين.
7)
7) $g(x) = f(x) - \ln(x + 2)$. $g'(x) = \frac{3}{(x+1)^2} - \frac{1}{x+2}$. دراسة الإشارة معقدة. $g(-1^+) = +\infty - \ln 1 = +\infty$. $g(+\infty) = 1 - (+\infty) = -\infty$. إذن $g$ يقطع 0 مرة واحدة على الأقل. التفرد يتطلب دراسة $g'$ (رتيبة تناقصية كفاية).
8)
8) مساحة المنطقة على $[-2, 1]$: $f$ معرفة على $[-2, 1] \setminus \{-1\}$. $\int_{-2}^1 f(x)\, dx = \int_{-2}^1 \frac{x - 2}{x + 1}\, dx$.
9)
$\frac{x - 2}{x + 1} = 1 - \frac{3}{x + 1}$. $\int (1 - 3/(x+1))\, dx = x - 3 \ln|x+1|$.
10)
$[x - 3 \ln|x+1|]_{-2}^1 = (1 - 3 \ln 2) - (-2 - 3 \ln 1) = 1 - 3 \ln 2 + 2 = 3 - 3 \ln 2$. (مع الأخذ بالحسبان تجزؤ المجال عند $-1$ — التكامل غير منتظم هناك.)
حل التمرين الثاني — المتتالية العودية
1)
1) $u_0 = 1$, $u_1 = 2/2 = 1$, $u_2 = 1$, $u_3 = 1$. (ثابتة!)
2)
ملاحظة: $u_0 = 1$ يعطي متتالية ثابتة. لنجعلها مثيرة, نستعمل $u_0 = 2$.
3)
إذا $u_0 = 2$: $u_1 = 4/3$, $u_2 = (2 \cdot 4/3)/(4/3 + 1) = (8/3)/(7/3) = 8/7$, $u_3 = (16/7)/(8/7 + 1) = (16/7)/(15/7) = 16/15$.
4)
2) التهيئة: $u_0 = 2 > 0$ ✓. الفرضية: $u_n > 0$. النتيجة: $u_{n+1} = 2u_n/(u_n + 1) > 0$ (لأن $u_n > 0$ و $u_n + 1 > 0$) ✓.
5)
3) $v_{n+1} = \frac{1}{u_{n+1}} = \frac{u_n + 1}{2 u_n} = \frac{1}{2} + \frac{1}{2 u_n} = \frac{1}{2} + \frac{v_n}{2}$.
6)
4) $v_{n+1} - v_n = \frac{1}{2}$ (ثابت). $(v_n)$ حسابية أساسها $\frac{1}{2}$ و $v_0 = 1/u_0 = 1/2$.
7)
5) $v_n = 1/2 + n \cdot 1/2 = (n + 1)/2$. $u_n = 1/v_n = 2/(n + 1)$.
8)
6) $\lim u_n = 0$.
9)
7) $u_{n+1} - u_n = \frac{2}{n+2} - \frac{2}{n+1} = \frac{2(n+1) - 2(n+2)}{(n+1)(n+2)} = \frac{-2}{(n+1)(n+2)} < 0$. $(u_n)$ متناقصة.
10)
8) $\sum v_k = \sum \frac{k+1}{2} = \frac{1}{2} \sum (k+1) = \frac{1}{2}\left[\frac{n(n+1)}{2} + (n+1)\right] = \frac{(n+1)(n+2)}{4}$.
11)
$\sum 1/u_k = \sum v_k = \frac{(n+1)(n+2)}{4}$.
حل التمرين الثالث — الأعداد المركبة
1)
1) $|z| = 2$, $\arg(z) = -\pi/6$.
2)
2) $z = 2 e^{-i\pi/6}$.
3)
3) $z^6 = 2^6 e^{-i\pi} = -64$.
4)
4) $z^3 = -8i = 8 e^{-i\pi/2}$. الحلول: $z = 2 e^{i(-\pi/6 + 2k\pi/3)}$ لـ $k = 0, 1, 2$.
5)
$z_0 = 2 e^{-i\pi/6} = \sqrt{3} - i$, $z_1 = 2 e^{i\pi/2} = 2i$, $z_2 = 2 e^{i 7\pi/6} = -\sqrt{3} - i$.
6)
5) $Z = -64$, $\bar Z = -64$ (حقيقي).
7)
6) $A(\sqrt{3}, -1)$. $OA = |z| = 2$. الزاوية $= \arg(z) = -\pi/6$.
8)
7) $B = z^2 = (2 e^{-i\pi/6})^2 = 4 e^{-i\pi/3} = 4(1/2 - i\sqrt{3}/2) = 2 - 2i\sqrt{3}$. $AB = |z^2 - z| = |z(z-1)| = 2 |\sqrt{3} - 1 - i| = 2 \sqrt{(\sqrt{3}-1)^2 + 1} = 2 \sqrt{4 - 2\sqrt{3} + 1} = 2\sqrt{5 - 2\sqrt{3}}$.
9)
8) $OA = 2$, $OB = |z^2| = 4$, $AB \approx 2,82$. مثلث غير متساوي الأضلاع لكنه يشكل مثلثًا (مجموع طولين > الثالث: $2 + 2,82 = 4,82 > 4$).
حل التمرين الرابع — تكامل + واليس
1)
1) $u = -x^3$, $du = -3x^2\, dx$. $\int_0^1 x^2 e^{-x^3}\, dx = -\frac{1}{3}[e^{-x^3}]_0^1 = \frac{1 - e^{-1}}{3} = \frac{e - 1}{3e}$.
2)
2) $u = \cos x$, $du = -\sin x\, dx$. $\int_0^{\pi/2} \cos^2 x \sin x\, dx = -\int_1^0 u^2\, du = \int_0^1 u^2\, du = 1/3$.
3)
3) $u = \sin^{n-1} x$, $v' = \sin x$. $I_n = [-\sin^{n-1} x \cos x]_0^{\pi/2} + (n-1)\int_0^{\pi/2} \sin^{n-2} x \cos^2 x\, dx = (n-1)(I_{n-2} - I_n)$. $n I_n = (n-1) I_{n-2} \Rightarrow I_n = \frac{n-1}{n} I_{n-2}$ ✓.
4)
4) $I_0 = \pi/2$, $I_1 = 1$.
5)
5) $I_2 = \frac{1}{2} I_0 = \pi/4$, $I_3 = \frac{2}{3} I_1 = 2/3$, $I_4 = \frac{3}{4} I_2 = 3\pi/16$.
6)
6) على $[0, \pi/2]$: $\sin x \in [0, 1]$, إذن $\sin^n x \leq \sin^{n-1} x$. $(I_n)$ متناقية. موجبة و متناقية → متقاربة. $I_n \leq \sin^n(\pi/2 - 1/n) \cdot \pi/2 \to 0$ (تقريب), إذن $\lim I_n = 0$.
7)
7) $J_n = (n+1) I_n I_{n+1}$. من العلاقة: $(n+1) I_{n+1} = n I_{n-1}$. $J_n = I_n \cdot n I_{n-1}$. $J_{n+1} = (n+2) I_{n+1} I_{n+2} = (n+2) \cdot \frac{n+1}{n+2} I_n \cdot I_{n+1} = (n+1) I_n I_{n+1} = J_n$ ✓. إذن $J_n$ ثابتة.
8)
قيمة الثابت: $J_0 = 1 \cdot I_0 \cdot I_1 = \pi/2$.
9)
8) من $J_n = (n+1) I_n I_{n+1} = \pi/2$ و العلاقة $I_{n+1} = \frac{n}{n+1} I_{n-1}$: $\frac{I_{n+1}}{I_n} = \frac{n}{n+1} \to 1$ ✓.
حل التمرين الخامس — احتمالات
1)
1) $\binom{10}{3} = 120$.
2)
2) $P(3 حمراء) = \binom{4}{3}/120 = 4/120 = 1/30$.
3)
3) 3 من نفس اللون = 3 حمراء + 3 بيضاء + 3 خضراء. 3 خضراء غير ممكنة (1 خضراء فقط). $P = \binom{4}{3}/120 + \binom{5}{3}/120 + 0 = 4/120 + 10/120 = 14/120 = 7/60$.
4)
4) مكمّم: $P(\geq 2 لون) = 1 - P(1 لون) = 1 - 7/60 = 53/60$.
5)
5) $X$ = عدد الكرات البيضاء المسحوبة. $X \in \{0, 1, 2, 3\}$ (5 بيضاء فقط).
6)
$P(X = k) = \binom{5}{k} \binom{5}{3-k}/120$.
7)
$P(0) = \binom{5}{3}/120 = 10/120 = 1/12$.
8)
$P(1) = \binom{5}{1}\binom{5}{2}/120 = 5 \cdot 10/120 = 50/120 = 5/12$.
9)
$P(2) = \binom{5}{2}\binom{5}{1}/120 = 50/120 = 5/12$.
10)
$P(3) = \binom{5}{3}/120 = 10/120 = 1/12$.
11)
تحقق: $1/12 + 5/12 + 5/12 + 1/12 = 12/12 = 1$ ✓.
12)
6) $E(X) = 0 + 5/12 + 2 \cdot 5/12 + 3 \cdot 1/12 = 5/12 + 10/12 + 3/12 = 18/12 = 3/2 = 1,5$. أو: $n \cdot K/N = 3 \cdot 5/10 = 1,5$ ✓.
13)
$V(X) = n \frac{K}{N} \frac{N-K}{N} \frac{N-n}{N-1} = 3 \cdot 0,5 \cdot 0,5 \cdot \frac{7}{9} = 3 \cdot 0,25 \cdot 7/9 = 7/12 \approx 0,583$.
14)
7) $P(X \geq 2) = P(2) + P(3) = 5/12 + 1/12 = 6/12 = 1/2$.
15)
8) $P(X = 1 | X \geq 1) = \frac{P(X = 1)}{P(X \geq 1)} = \frac{5/12}{1 - 1/12} = \frac{5/12}{11/12} = \frac{5}{11} \approx 0,455$.
