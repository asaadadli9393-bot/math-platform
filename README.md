# تدرّج — منصة الرياضيات للطور الثانوي

منصة تعليمية عربية (RTL) شاملة لمادة الرياضيات في السنوات الثلاث للتعليم الثانوي الجزائري، **تحت إشراف الأستاذ عدلي اسعد**، مبنية وفق جداول **التدرج الرسمي 2022-2023** لكل شعبة.

> 🌐 نسخة الأستاذ المرجعية: [math-adli.vercel.app](https://math-adli.vercel.app)

## ماذا تقدم المنصة؟

- **ثلاث سنوات دراسية كاملة**: الأولى ثانوي (الجذعان)، الثانية ثانوي (5 شعب)، الثالثة ثانوي (5 شعب).
- **جداول التدرج الرسمية**: أسابيع وساعات كل محور لكل شعبة، مستخرجة من وثيقة الوزارة.
- **بنوك تمارين بحلول نموذجية**: تمارين مصنفة (سهل / متوسط / صعب / بكالوريا) مع تلميحات وحلول متعددة الخطوات بمعادلات KaTeX.
- **اختبارات تفاعلية**: توليد اختبار حسب الفصل والصعوبة مع تصحيح ذاتي.
- **تتبع التقدم**: لوحة تطور لكل طالب (محلول / مرئي / نتائج الاختبارات) محفوظة محلياً.

## التقنيات

Next.js 16 · TypeScript · Tailwind CSS 4 · shadcn/ui · KaTeX

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:3000
```

## النشر على Vercel

المنصة جاهزة للنشر فوراً — اتبع الدليل المفصل في [`DEPLOY_VERCEL.md`](./DEPLOY_VERCEL.md) (ثلاث طرق: CLI مباشرة، عبر GitHub، أو سحب وإفلات).

## بنية المشروع

```
src/
├── app/            # الواجهة الرئيسية (SPA بصفحة واحدة RTL)
├── components/     # المشاهد: الرئيسية، التدرج، الفصول، بنك التمارين، الاختبار، لوحة التقدم
├── data/           # المنهاج: التدرج الرسمي، الفصول (30)، بنوك التمارين بحلولها
└── lib/            # محرك KaTeX + مخزن التقدم (localStorage)
```
